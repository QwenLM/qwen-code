Managed Agent exposes a signed text-only API. Workspace tools are disabled.

Connect locally:
  kubectl -n {{ .Release.Namespace }} port-forward service/{{ .Release.Name }} 8080:8080

Run deploy/kubernetes/smoke.mjs with the signing key from Secret {{ include "managed-agent.secret" . }}.
See deploy/kubernetes/README.md for the command and upgrade procedure.

Uninstall retains the managed Secret and MySQL PVC. Back up both before upgrades.
Do not use automatic Helm rollback across database migrations.
