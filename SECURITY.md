# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately through one of the following channels:

1. **GitHub private vulnerability reporting (preferred):** open the [Security tab](https://github.com/QwenLM/qwen-code/security) and click **"Report a vulnerability"** ([direct link](https://github.com/QwenLM/qwen-code/security/advisories/new)). This requires only a GitHub account, and the report stays private until a fix is released.
2. **Alibaba Cloud portal:** [Report Security Issue](https://yundun.console.aliyun.com/?p=xznew#/taskmanagement/tasks/detail/151) (requires an Alibaba Cloud account).

> **Note:** These channels are strictly for reporting security-related issues. Non-security vulnerabilities or general bug reports will not be addressed here.

Please **do not** disclose vulnerability details in public issues, pull requests, or discussions. We sincerely appreciate your responsible disclosure and your contribution to helping us keep our project secure.
