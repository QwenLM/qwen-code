# Change overview scope tabs in Arabic

1. In Arabic Web Shell, open the artifact panel's Change overview with an uncommitted scope, a PR scope, and a commit scope.
2. Focus the rightmost scope. Press Left: selection, focus, and contents move to the chip visually on the left. Press Right: all three move back. At either end the next arrow wraps.
3. Confirm Home and End still select the first and last scopes; Alt+Right leaves scope selection unchanged.
4. Repeat in English and confirm Right advances left-to-right.

Baseline: no global `qwen` executable is installed on this host. The focused test with the Arabic provider and RTL container exercises focus and selection against the baseline and fixed source.
