## When you sync to a newer upstream ref

`scripts/sync-from-upstream.sh` diffs `.vendored-from`→`<new-ref>`. If `<new-ref>`
is **at or past the commit where one of these PRs merged**, that PR's changes are
already in the upstream delta, so:

1. The hunks will collide with the cherry-picked commit (expect `.rej` on the
   files above), and
2. Once reconciled, **remove the row from the active table** — it's no longer a
   local patch, it's part of the base.

If `<new-ref>` is still *before* a PR merges, that row stays; the cherry-pick
keeps carrying the fix.

The base remains `cua-driver-rs-v0.20.0`; this is a Qwen release version, not a new wholesale upstream snapshot. Selected MIT driver changes from upstream 0.35.4 were adapted to this fork. Native Wayland was removed. No upstream bench code is included.

The upstream base tag stays unchanged until a complete snapshot synchronization occurs.

### Additional Qwen acceptance repairs

These are fork repairs found while testing the adapted implementation, rather than additional whole upstream ports:

- Preserve a normal uncertain acknowledgement after an attempted AX semantic action; never replay an AX error through a pointer actuator. Apple Events save and Finder rename carry their actual background transport and independent readback evidence.
- Resolve exact native macOS window identity before keyboard delivery, establish its AppKit key-window state, and omit the separate titlebar activation click. The native focus records themselves produce internal NaN-location mouse events; they are distinct from the requested pointer action. This does not claim that pointer or menu window covering has been eliminated.
- Use byte lengths for AT-SPI text insertion and preserve character-based caret offsets. Keep MPX mappings and input ownership until native completion, including the uncertain timeout path; reject unsupported WM delivery before dispatch.
- Limit an isolated Windows uninstall to its selected runtime and owned task actions. Unknown or mixed non-Exec task actions preserve the shared task; legacy default-install cleanup retains its existing scope.
