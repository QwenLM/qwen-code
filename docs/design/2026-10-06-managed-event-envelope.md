# Managed Event Envelope (cross-node EventTransport v1)

[中文版](./2026-10-06-managed-event-envelope.zh-CN.md)

> **Status:** Proposed contract, shipped as schema + fixtures with a structural non-enablement gate (no production consumer). Part of the cross-node EventTransport design (`2026-10-04-managed-agent-event-transport.*`) — the deferred MQ/Redis transport scope of #12380. Nothing here is a claim that a transport exists.

## Problem

Every asynchronous capability on the Managed path is a durable resource plus a trigger intent, so a cross-node EventTransport distributes only committed facts — never Session truth, never a browser cursor, and an MQ offset is never recovery evidence. The shape every such fact travels in is the one contract all future transports must carry, whatever their vendor. Freezing it now pins the dedupe, ordering, and leak-guard semantics independent of the eventual transport, exactly as H0b pinned the Stage H record contract ahead of every slice that reads it.

## Decisions

1. **Committed facts only.** The envelope carries `tenantId`, `workspaceId`, `sessionId` (flattened from the row's `sessionKey`), a version (`v: 1`), `stream` (v1's only value: `authoritative_journal`), `sequence` (starts at 1), `eventId`, `kind` (the shared 17-kind vocabulary mirrored exactly from the record contract — the mirrored list is fixture-pinned, so drift in any mirror fails loudly), `occurredAt`, and a `payloadRef.digest`, never the payload body, which stays in the SQL record. The digest is SHA-256 over the canonical JSON of the single announced event as a one-element list — the same canonical form the commit marker's transaction-wide `eventsDigest` uses, but not that marker value: the two are equal only for a single-event transaction, so a multi-event transaction stores no column equal to it. The receiver verifies the announced fact by recomputing the digest over the single event it reads back.
2. **Time.** `occurredAt` is the writer's recorder timestamp committed with the event — the original event's time, not a commit time, and not a Session order. Ordering per Session is decided within one stream by `(tenantId, sessionId, stream, sequence)`.
3. **Dedupe key is tenant-scoped.** Identity-dedupe is exact-key equality on `(tenantId, sessionId, stream, sequence)` — `stream` is the parent design's source discriminator (§6 of `2026-10-04-managed-agent-event-transport.md`): the journal commit sequence and the public `managed_agent_event.sequence_id` reuse the same numbers for different facts. v1 names its only stream, `authoritative_journal`; a notice carrying any other stream value (`public_event` included) is refused at parse time by the closed stream vocabulary (fixture `stream-public-event`), so the journal-versus-public collision cannot reach the dedupe key today — parse refusal is the guarantee v1 ships, not the key's `stream` term, which is vacuous under a single-member vocabulary and becomes load-bearing only when a second stream is admitted; that change owes a discriminating dedupe fixture alongside it. A Session only ends identity inside its tenant (the journal head is keyed by `(tenant_id, session_id)`), so an identical session id under another tenant is another Session, and never redelivers (fixture `different-tenant-same-key` flips false to pin the boundary). Different surroundings with the same key still name one fact — and every dedupe row declares its operands' parseability, so a `false` always means refused-for-the-declared-reason rather than degraded past the comparison.
4. **No internal leaks.** A named forbidden-field set (`absolutePath`, `localPath`, `pid`, `pod`, `runtimeBindingId`, `runtimeEndpoint`, `secretHandle`, `sidecar`) is rejected by name before shape checks, each with a fixture; nothing in an envelope exposes Runtime internals, local paths, or credentials.
5. **Non-enablement by construction.** The contract adds no registry entry and is consumed by no runtime path — the structural gate (a source scan asserting that no production file imports the module) is the proof an early transport cannot consume it quietly until its own phase lands. The scan walks every workspace package's `src/`, or the package tree when it has none (that is what covers `packages/web-shell/client`), plus the root `scripts/` and `integration-tests/` trees, skipping only `node_modules/`, `dist/`, symlinks and test files, and it matches import/export/dynamic-`import()`/`require()` specifiers through the TypeScript AST rather than raw text, so comments, strings and interpolated templates can neither mask nor forge an import; a workspace that disappears fails the gate instead of being skipped. Its blind spots stay named, not implied: re-exports, computed or interpolated specifiers, symlinks (never traversed, so a directory link hides its target), and languages outside the scanned extension set — the parent design's deferred Java mirror is beyond this scan by construction.

## Record-of-pending-open (deliberately not frozen)

- `payloadRef` carries digest only; cross-version location references (a durable ref) are an open question for the design slice.
- Per-commit batch distribution (one notice per commit marker vs per event) is a sibling contract question, left open.

## Validation

- `npx vitest run src/managed-runtime/managed-event-envelope.test.ts` — 106/106, including: derivation-from-row cases with real digests; dedupe pairs (identical redelivery, differing surroundings, tenant boundary at false, unparseable operands) whose per-operand parseability is declared and asserted before each comparison, so a degraded row cannot pass silently; every forbidden field rejected; every kind of the 17 mirrored from the record contract in one valid envelope; accepting- and refusing-side rows at every declared limit (the `sequence` floor `sequence-one`/`sequence-zero` and safe-integer ceiling `sequence-at-max`/`sequence-max-safe`, the `occurredAt` ceiling `occurred-at-exactly-max`/`occurred-at-over-max`, and the stable-id ceiling in characters and UTF-8 bytes, `session-id-exactly-512-chars` and `session-id-exactly-512-bytes` against the four `*-over-512-bytes` rows), with the schema's `stableId.maxLength` and `occurredAt.maximum` literals pinned to `MANAGED_SESSION_LIMITS` in both directions; per-field UTF-16/NFC/byte-limit/control-character rows for all four id fields; the stream vocabulary pinned end to end (module constant, fixture `streams`, the schema's top-level `streams` const and the nested `envelope.properties.stream.enum`), with `public_event` refused at parse time — that refusal, not a dedupe row, is v1's journal-versus-public guarantee, and a discriminating dedupe row is owed when a second stream is admitted; the schema kind enum equal to the record's, not a superset; the literal idempotence key; deep-frozenness on both construction paths; the two-way schema-to-module agreement pin, with the beyond-schema rows named; the structural non-enablement scan.
