# Managed 侧栏运行状态

[English](managed-sidebar-status.md) | [简体中文](managed-sidebar-status.zh-CN.md)

## 问题与范围

Managed 工作区会话行目前只显示标题，尽管正文已知道运行阶段。列表快照还会在切走时丢失较新的当前会话状态，并且不接收后台完成状态。本次复用 daemon 侧栏的绿色呼吸点和右侧转圈，不修改 Java API、执行、权限或用户 Session。

## 行为

通过共享的阶段判断，将已接收、环境启动或等待、Agent 或工具执行、取消中视为运行状态。新建、完成、失败、已取消不显示运行指示。Java 已将恢复阻塞的 Turn 投影为失败。等待权限 Action 保留已有的活动 Turn 阶段，本次不新增审批状态或徽标。会话行保留阶段提示、键盘操作和当前选中标记。

将当前详情的 summary 保存在导航行中，使切到另一会话或本地后仍保留最后确认的阶段。目录及分页合并保留已确认的较新摘要，相同时间戳时也保留；切换选中会话后仍生效，晚到首屏之外的已知会话保持可达。重新应用当前详情摘要时通过对象身份判断避免重复更新。当前会话继续由已有详情轮询负责。

每三秒仅通过已有 provider 读取已知运行中的后台 Session，将成功返回、身份一致且不旧于当前数据的 summary 合并到已加载行。轮询轮次不重叠。使用排序后的稳定 ID，防止当前会话的详情轮询反复重置后台计时器。终态行停止轮询。作用域、选中会话、活动 ID 变化及卸载时取消请求，忽略晚到响应，读取失败时保留最后确认状态。不重置目录分页、不刷新工作区，也不为每个 Session 订阅全文。其他客户端新启动的空闲 Session 仍通过已有目录刷新和发现路径进入列表。

## 验证与本地更新

独立临时测试使用真实 daemon 组件作正对照，复现指示缺失，并在实际页面复现切换后状态回退及后台完成不更新。回归测试覆盖全部阶段、切换、晚到响应、完成/失败/取消终态、分页及后台读取停止。完成根目录构建、类型检查、相关测试、lint 和格式检查。用隔离的受控模型执行与实际浏览器验证构建产物：运行时显示相同绿点和转圈，切走后待任务完成，指示自动消失。本地预览仅发布前端资源，保留旧的哈希资源并原子替换 HTML 入口，使用户当前 Turn 和服务进程持续运行。
