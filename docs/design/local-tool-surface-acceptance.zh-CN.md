# 本地工具可见性验收

[English](local-tool-surface-acceptance.md) | [简体中文](local-tool-surface-acceptance.zh-CN.md)

## 问题与范围

Issue #12333 需要证明：减少工具声明能够降低完整任务成本，同时不损害工具召回与结果正确性。现有 release benchmark 会派发到独立 pool，仓库内没有可用的 settings 注入点。本地正常 CLI 已能对照配置；需要补上实际调用入口和独立验证的任务，而不是再增加没有调用方的统计工具。

本次增加固定任务的真实模型配对验收命令。不改变生产默认配置、不新增遥测、不替代 SWE-bench 或 Terminal-Bench，也不宣称完成外部 pool 的 settings-overlay 接入。与 startup-benchmark harness 一样，本次不新增 CI 门禁：CI 只运行其结果判定测试。

## 配对运行

两组使用相同源码提交、模型、提示词与初始文件。A 在启动时显式展示内置工具，B 使用默认启动可见性。两组均不配置 `tools.eager`，均使用 direct tool mode、零延迟工具预加载阈值，并启用相同能力。必须从首个供应商请求确认实际声明差异；配置没有改变实际工具面时，不能把结果作为节省证据。

每次会话使用独立 home、settings 与 runtime。两组同样关闭用户记忆、hooks、extensions、MCP 及可选后台标题请求。凭证仅从 `OPENAI_API_KEY` 读取，不写入 settings 或证据。运行前后记录源码身份，发生漂移即验收无效。重复实验交替使用 A/B 与 B/A 顺序。

## 任务与独立证据

固定任务覆盖普通对话、文件汇总、实际 Shell 执行、多步文件生成、前台 Agent 委派、持久化 Goal 状态、Workflow 执行及仅使用测试文件的安全用例。能力提示词请求用户动作，不指定 `tool_search` 或 `tool_call`，且必须产生真实调用证据。只有最终文字正确、没有执行所需能力时判为失败。

程序检查精确答案、产出文件、只读输入未变，以及实际工具或生命周期结果。Agent 和 Workflow 必须实际执行，Goal 必须观察持久化状态。安全检查要求相关测试边界全部成立。这些检查只证明固定任务集与该模型的正确性，不能外推为所有任务的召回质量。

## 成本与验收

程序创建的本地回环代理透明转发到真实配置的供应商，并统计上游请求尝试，包括 SDK 重试与子任务；它不生成模型响应。程序将此数量与采集的请求记录核对，存在未记录的尝试时，成本证据即不完整。

完整任务总量包含已记录的父会话、子 Agent、side-query、失败及重试请求。报告分别展示输入、输出、总量、缓存 Token、任务输入 mean/p50/p95、工具搜索频率、错误调用、任务结果和安全结果。缺失 usage 代表证据不完整，不能按零成本处理。额外回合与失败均保留。

验收要求配对任务完整、初始工具面存在差异、源码稳定、所需能力真实执行、独立结果正确、所有安全用例通过，且 B 的累计输入加输出低于 A。失败或采集不完整时返回非零退出码，并保留证据。供应商缓存没有重置，因此通过不等于证明冷缓存收益或按价格计算的账单降幅。

## 运行与维护门禁

安装 frozen 依赖树并构建 workspace 前置产物后运行：

```bash
OPENAI_API_KEY=... npm run test:tool-surface:real -- \
  --model <model> --base-url <api-base-url> \
  --repetitions 2 --output /tmp/tool-surface-acceptance-new
```

输出目录必须是新目录。命令仅清理自己创建的临时会话配置与工作区，保留脱敏报告和请求证据，不修改用户配置。单次会话有时间上限，超时终止自己的进程并记录失败。

该命令是手动入口，没有工作流或定时任务调用它，因此普通 PR CI 既不依赖模型凭证，也不消耗供应商 Token；报告与脱敏产物由运行者自行保留，验收失败时同样保留。确定性的结果判定测试由现有 `test:scripts` CI 通道执行；这些测试验证失败拒绝与计量逻辑，不验证模型质量。

## 验证与剩余工作

确定性测试覆盖缺失 usage、包含子 Agent 的总量、额外回合、虚假完成说明、源码／工具面不匹配，以及安全和结果失败。使用真实供应商运行完整配对任务，并检查脱敏证据。发布结果时明确被测提交、模型、重复次数和失败情况。

更大规模的分层任务集、更多模型及标准套件 pool 的配置覆盖仍是 #12333 的独立验收工作。这个有调用入口的本地门禁可以发现固定任务的退化，无需等待外部 runner 权限。
