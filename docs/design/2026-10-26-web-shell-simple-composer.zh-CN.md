# Web Shell 可配置简洁输入框

[English](2026-10-26-web-shell-simple-composer.md) | [简体中文](2026-10-26-web-shell-simple-composer.zh-CN.md)

状态：实现设计

日期：2026-10-26

Issue：[#15647](https://github.com/QwenLM/qwen-code/issues/15647)

## 问题与当前行为

Web Shell 的输入框目前将编辑区放在会话控制工具栏上方。宿主可以选择工具栏操作项、
定制占位文字，但无法选择 issue 移动端参考图中细长的单行输入框。窄嵌入面板和轻量
聊天场景需要一个静止状态下占用更少空间的输入区。

主聊天直接渲染 `ChatEditor`，分屏和侧任务聊天通过 `ChatPane` 渲染它，三者已共享
Web Shell 的 customization context。桌面编辑使用 CodeMirror，触屏设备使用已有的
textarea 后端。输入框已有附件摄入、提交、取消、语音能力检查和加号菜单。

## 目标与范围

- 通过两个公开组件入口提供可选的简洁输入框。
- 默认继续使用现有输入框。
- 显示由加号、编辑区和主要语音、发送或停止操作组成的胶囊形输入行。
- 简洁加号菜单聚焦附件和引用，高级模式保留原有次要控制项。
- 保持文本编辑、附件、输入法和会话行为。
- 主聊天、分屏面板和侧任务聊天采用一致的展示模式。

参考图仅适用于消息输入区。页面顶部、角色图片和底部导航不在本次范围内。本次不新增
daemon 配置、持久化设置、设置页控件或语音能力。

## 公开 API 与配置传递

在 `WebShellProps` 新增以下可选属性：

```ts
composerVariant?: 'default' | 'simple';
```

`WebShellWithProvidersProps` 继承该属性。不传或传入 `'default'` 时保持当前展示，
宿主通过以下方式直接启用：

```tsx
<WebShellWithProviders composerVariant="simple" />
```

通过现有 `WebShellCustomization` context 传递该值。主聊天和面板输入框从同一
context 读取，避免为分屏和产物面板组件建立不同配置路径。该属性控制展示，不改变
daemon 能力或权限。

已有工具栏操作项配置继续决定默认和高级展示中哪些可选操作可用。简洁模式提供受限的
加号菜单，不要求宿主额外在工具栏列表中加入 `'addMenu'`。切换至高级模式恢复原来
配置的工具栏，不强制启用额外操作。已有占位文字覆盖仍然生效。

## 输入框布局与交互

复用现有 `ChatEditor` 和 `useComposerCore` 实例。简洁模式不引入另一个编辑器后端
或提交路径。

静止状态下，轻量全圆角边框包围低高度输入行。左侧是加号，中间是可伸缩编辑区，右侧
是主要操作。编辑区必须为按钮保留足够的行内空间，文字不能渲染到按钮下方。长文本
可以增高为有高度上限的多行编辑区；附件可在输入区上方增加空间，不应被胶囊裁切。
简洁输入行的加号和麦克风采用相同的较大视觉尺寸，加号使用中性灰；高级模式保留
两者原有尺寸和颜色。

附件继续使用已有 flex 堆叠，简洁输入行单独限制高度。在较矮视口内，编辑区在剩余
高度内滚动，加号和主要操作始终位于胶囊内。输入行包装在默认和高级模式使用
`display: contents`，保留其原有布局。

触屏设备配置为 `'simple'` 时，`Settings2Icon` 设置按钮将同一个输入框直接切换至
高级模式，原地使用现有完整移动端展示。简洁输入行中的设置按钮位于语音／发送左侧。
高级模式仅在原有语音控件前增加 `PanelBottomCloseIcon` 返回按钮，让麦克风紧挨
发送，顺序为返回 → 麦克风 → 发送；其原有布局、
控件、操作行为和图标尺寸保持不变。两个按钮的标签分别为“切换至高级模式”和
“切换至简洁模式”。两种操作均不打开菜单或全屏编辑器对话框，也不修改 iOS 原生
编辑菜单。两次切换均保留文字、附件和编辑器 DOM 节点。返回简洁模式时退出 Shell
模式，让保留的草稿按普通聊天提交，无需访问已隐藏的 Shell 控件。`advancedMode` 仅为局部
展示状态，不持久化设置，也不修改 `composerVariant`。默认模式及桌面输入框不新增
此切换按钮。

简洁输入行有待提交内容时可使用发送控件。空内容时，在能力和配置允许的情况下复用
已有语音入口。语音不受支持或不可用时显示发送控件，在空内容的闲置状态下禁用，
不渲染麦克风占位入口。
此互斥行为及简洁模式中放大的麦克风仅在展示简洁布局时生效。高级模式恢复
原有语音和发送的显隐、尺寸及行为，包括原输入框提供的两者并存状态。保持已有准备中、
禁用、运行中、排队输入和停止语义。
会话或图片准备期间隐藏闲置麦克风，保留禁用的加载操作；正在进行的录音或转写继续可见。

简洁模式录音或转写期间，已有语音控件占据胶囊整行，暂时隐藏编辑区、加号、模式
切换和提交控件，但不卸载编辑器。录音控件需容纳波形、计时和停止操作，不受闲置
麦克风的固定 44px 宽度限制。语音活动结束后恢复普通简洁输入行，等编辑器重新可见
后再插入最终转写，让聚焦和 textarea 自动增高在可见元素上执行。textarea 高度回退
路径同样由 CSS 应用高度上限。高级和默认模式的录音／转写展示保持原样。

现有 CodeMirror 和触屏 textarea 路径保留键盘行为、中文输入法组合处理及多行编辑。
不能仅为切换可见操作而重新挂载编辑器。按钮保留无障碍名称和键盘焦点行为，窄屏上的
触控目标应保持可用。

## 次要控制项与加号菜单

复用 `AddMenu`，简洁展示仅包含以下八类操作：

1. 照片。
2. 拍照。
3. 添加文件附件。
4. 上传至工作区。
5. 引用文件。
6. 扩展。
7. MCP。
8. 技能。

各入口遵守已有平台及能力检查。没有可用的简洁操作时，显示已有的本地化空态说明，
避免弹出空白抽屉。简洁加号菜单不放入命令、历史、shell 模式、Plan、
实时语音或次要工具栏控件，不需要内部工具栏内容插槽。工作区、权限模式、模型、
上下文及宿主工具栏控件仍属于原有高级展示。

桌面加号菜单继续使用 `DropdownMenu`，触屏设备继续使用现有 `Drawer` 展示。默认
和高级菜单保留原有入口及配置行为，展开的控件和嵌套弹层继续使用 Web Shell 现有的
portal root 集成。

## 约束与风险

- 默认模式的布局和样式行为保持不变。高级模式仅在原有语音控件前新增返回按钮，
  简洁布局、录音及图标覆盖不能影响其原有控件。
- 保留公开 `data-web-shell-*` 钩子、主题变量和 portal 作用域。
- 操作状态继续由现有输入框及其会话作用域处理逻辑拥有；菜单不能切换到其他会话或
  工作区执行操作。
- 嵌套菜单控件可能意外关闭父菜单或丢失焦点。桌面和触屏均需验证选择、弹层打开、
  关闭及焦点恢复。
- 长文本、附件和语音活动会改变所需高度。必须验证这些状态，不能只依赖空输入截图。

## 验证与验收标准

1. `WebShell` 和 `WebShellWithProviders` 均接受 `composerVariant="simple"`；
   不配置及传入 `'default'` 时保持现有输入框。
2. 主聊天、分屏面板和侧任务聊天使用同一配置选择展示模式。
3. 空内容的简洁输入框为细长胶囊，包含加号、编辑区和可用主要操作，次要控制项不
   占据静止输入行。
4. 长文本和附件在可用空间内展开，不横向溢出、覆盖按钮或裁切预览。较矮视口配合
   大量标签时，两个操作按钮仍在胶囊内，草稿最后一行可通过滚动到达。
5. 文本输入、中文输入法组合、多行编辑、发送和附件通过现有编辑器和提交路径正常
   工作。
6. 准备中、禁用、运行中、排队输入和停止行为正确。空态语音、有内容发送的互斥规则仅
   在简洁布局生效；语音不受支持或不可用时，空内容的闲置输入框保留禁用的发送控件，
   不提供麦克风占位入口。高级模式保持原有语音和发送行为及尺寸。
7. 加号菜单及控件支持触屏和键盘交互，包括嵌套弹层、焦点恢复、无障碍标签和深浅
   主题。
8. 测试覆盖公开配置传递、模式特定渲染、提交及菜单行为。浏览器验证覆盖窄屏移动端
   和桌面布局，执行仓库要求的构建和类型检查。
9. 配置为 `'simple'` 的触屏输入框可通过 `Settings2Icon` 直接切换至现有完整移动端
   输入框，并通过 `PanelBottomCloseIcon` 返回，文字、附件和编辑器 DOM 节点保持
   不变。简洁模式设置按钮位于语音／发送左侧，高级模式返回按钮位于语音控件前，
   麦克风紧挨发送，其余高级控件保持不变。两种操作均不打开菜单或全屏对话框，
   也不修改 iOS 原生编辑
   菜单；默认及桌面展示不新增此切换按钮。
10. 简洁加号菜单仅包含定义的八类操作，并遵守平台和能力检查。命令、历史、shell
    模式、Plan、实时语音及次要工具栏控件不放入此菜单；默认和高级展示保持原来
    配置的行为。
11. 简洁录音／转写期间语音控件占据胶囊整行，波形、计时和录音停止操作不被裁切。
    编辑区、加号、模式和提交控件隐藏时编辑器仍保持挂载，语音活动结束后恢复。
    转写完成后编辑器获得焦点，原生与回退 textarea 高度路径均可正常增高。
    高级／默认模式的录音和转写保持原样。

以上是验证要求，不代表验证已经通过。实际结果记录在 E2E 报告和变更说明中。
