# 在共享输入框中选择托管审批策略

[English](2026-10-15-managed-approval-selector.md) | [中文](2026-10-15-managed-approval-selector.zh-CN.md)

## 问题与现状

本地 WebShell 提供审批策略选择器，托管任务创建界面却隐藏了它。托管模式已有持久化权限 Action 和共享 ToolApproval 卡片。Java 服务为每个会话固定审批策略，Harness 加载时核对该策略。页面选择必须改变真实准入，不能只修改文字。

## 行为与范围

新建绑定工作区的托管任务时，共享选择器只显示服务端返回的模式。内置 qwen-code Agent 的 Shell profile 支持 default 与 auto-edit，纯文件 profile 还支持 yolo。Hosted 执行不支持分类器 auto 和 plan，页面不提供这两项。Shell 始终需要权限审批。已保存 AgentDefinition 保留编译后的策略，选项只包含该模式。已有会话显示已固定的策略，需要新建任务才能选择其他策略。

本次不包含修改运行中会话策略、实现分类器、更改审批决定的语义、增加工具、覆盖 AgentDefinition 策略或修复既有 Writer 过期恢复问题。本地模式保留现有选项。

## 接口与准入

新增需要用户身份、按租户隔离的 WebShell 接口 `POST /api/agent/web-shell/v1/session-options/query`，接收 `agentId`，返回 `approvalMode` 与 `availableApprovalModes`。工作区发现接口通过 `approvalModeSelection` 宣告支持选项查询和创建协议。选项与创建使用同一套 Agent/profile 解析，不返回宿主路径或凭证。

WebShell 创建请求增加可选 `approvalMode`，仅用于绑定工作区的创建。省略时保留现有默认值和旧请求摘要；显式选择进入创建摘要并固定在待确认请求中，同一键改用其他模式会冲突。新准入根据已解析的 Agent 和工具 profile 校验模式，写入现有 `ma_session.approval_mode`，再沿现有 Harness 路径传递固定值。不支持的值以及未绑定工作区时显式指定策略均拒绝。AgentDefinition 准入不能静默覆盖已保存策略。本次不迁移数据库，也不更改公开 REST 创建协议。

WebShell 会话摘要为绑定工作区或固定 AgentDefinition 的会话返回持久化的 `approvalMode`。旧的未绑定内置会话由部署策略决定执行方式，因此省略该字段。旧 Provider 缺少此元数据时，页面不声称某个策略生效，也不暴露选择器。既有创建调用和已保存的待确认请求继续兼容。

## 页面接线

ChatEditor 增加可选模式列表，未传时仍使用本地模式的现有选项。托管创建按所选 Agent 加载有效选项，以服务端默认值初始化，并在空会话创建和首条消息创建中传递选择。更换 Agent/模型会刷新选项，保留草稿和工作区；过时的异步响应不能覆盖当前 Agent 的选择。能力已支持但选项仍在加载或无效时阻止创建；旧服务端未宣告能力时保留现有行为。

待确认会话创建记录在网络请求前固定策略，刷新后恢复同一选择。旧记录未保存策略时继续省略；服务端不再宣告能力时，没有已知会话 ID 的显式策略请求禁止重发，已有会话 ID 则只允许读回且必须核对策略一致。会话存在后，输入框显示服务端读回策略并禁用策略修改。已有审批 Action 继续使用共享卡片和持久化响应操作，批准和拒绝通过真实工具效果验收。

## 验收标准

1. 页面和服务端支持模式一致；auto/plan 被拒绝，构造请求也不能让 Shell 使用 yolo。
2. default 在写文件前请求审批，批准前目标文件不存在；拒绝后仍不存在，批准后生成精确内容。
3. auto-edit 对同类允许的文件写入不弹审批，Shell 仍产生权限 Action。
4. 刷新后会话策略保持，已有会话不能修改；待确认重试保留最初策略与幂等键。
5. 本地模式、模型/工作区选择、草稿、空会话创建、旧 Provider 和旧待确认记录保留既有行为；隐藏托管控件不接管本地交互。
6. 交付前完成构建、类型检查、针对性测试、双语文档、自审和独立审查；浏览器验收使用原生文件证据，不能只相信模型文字。

## 待定问题

受支持模式的范围内没有待定问题。扩展 Hosted 策略能力需要单独后端开发。
