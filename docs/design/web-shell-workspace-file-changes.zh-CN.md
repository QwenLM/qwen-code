# Web Shell 工作区文件变更

[English](web-shell-workspace-file-changes.md) | [简体中文](web-shell-workspace-file-changes.zh-CN.md)

## 问题与范围

已编辑文件卡片收集成功的 `write_file` 和 `edit` 调用，却不检查工作区和
Git 忽略状态。因此全局记忆、其他项目文件和被忽略的辅助脚本会增加文件数和
增删行统计。保留完整会话记录，仅过滤派生的文件变更展示。不根据文件名猜测
临时用途，不改变 artifact 发布，也不以当前 Git diff 代替每轮编辑记录。

## 行为

文件变更摘要及其评审仅显示会话工作目录内的路径，包含子目录。会话存在受管
worktree 时，以它作为工作目录；基础工作区仍是路由所有者。Git 已跟踪路径和
未被忽略的新文件继续展示；被 Git 忽略且未跟踪的文件不展示。非 Git 目录仅按
范围筛选。`.qwenignore` 不决定展示。显式 artifact 卡片和完整工具详情保持原有行为。
没有可见编辑时，不显示文件变更卡片。

## 实现

### 查询契约

`workspace_git_check_ignore` 宣告
`POST /workspaces/:workspace/git/check-ignore`。JSON 请求体为
`{ "paths": ["src/app.ts", "helper.log"] }`，路径相对工作区根目录。
每次最多 256 条，每条 1–4096 个字符；绝对路径、NUL、反斜杠和 `.`/`..`
路径段会返回 HTTP 400 和 `code: "invalid_paths"`。成功响应为
`{ "v": 1, "ignoredPaths": ["helper.log"] }`。
`WorkspaceDaemonClient.workspaceGitIgnoredPaths(paths, cwd?, sessionId?)` 使用
REST，并传递可选执行目录及所有者会话以复用受管 worktree 校验。未知、不可用
及不可信 runtime 的错误保持现有失败语义。
本地 Git 执行失败返回 HTTP 503 和 `code: "git_ignore_unavailable"`。

在指定工作区的 Git 路由中新增有界、只读的批量 Git 忽略查询，提供 SDK 方法和
能力标记。解析选中的可信 runtime，复用现有 Git 路由规则校验会话 cwd，绝不
回退主 runtime。直接调用 Git `check-ignore`，不使用 `--no-index`，从而保留
Git 索引、嵌套规则、否定规则、全局忽略和 linked worktree 的真实语义。限制
子进程时间和输出，清理环境变量，并禁用可执行 Git 配置。
每个请求最多进行 32 次 Git 探测，并共享截止时间（本地 5 秒、SSH 30 秒）。
遇到不支持的符号链接／子模块路径，或预算不足时，保留已知结果；未完成判定
的路径继续展示。请求断开时取消本地子进程。

通过共享 Web Shell hook，在主聊天、次级聊天面板和子代理详情中筛选每轮 selector
输出。规范化相对与绝对路径，排除路径越界和相邻同前缀目录。对范围内的去重路径
批量查询，不读取文件内容或扫描整个目录树。文件数、增删行统计和评审数据使用
同一可见子集。工作区、会话或输入变化后，丢弃过期异步结果。
首次分类完成后才显示文件卡片。刷新期间保留已分类文件；新路径等待自己的
判定。工作区外的编辑不使工作区查询失效，连接恢复后重新查询。恢复的评审也
等待分类。当前会话内存中已包含目标编辑时，复用内存转录；仅在缺失时分页读取
持久历史。可见性或连接变化后重新分类已打开的评审，并保留原始 diff 快照。
恢复时使用独立会话的输出目录；根目录未知时保留编辑，不变成内容丢失错误。
虚拟子代理通过真实父会话解析 worktree，执行元数据与会话详情的
显示偏好分离。执行元数据未知时，不将基础工作区的忽略规则当作权威判定。
无工作区会话仅按自己的输出目录筛选，不发送工作区查询。
执行元数据等待期间不显示文件卡片；查询失败后降级为仅按目录范围筛选，并在
连接恢复后重试。Windows 路径规范化会保留盘符根目录，避免 `..` 越过根目录
时丢失绝对路径身份。
旧版当前会话评审标签页缺少工作区标识时，从已连接会话及其已广告的可信
所有者补齐；已有的显式标识继续接受校验。

## 兼容性与风险

旧版 daemon 或查询不可用时，忽略状态无法确认的工作区内编辑继续展示；未知
不能作为文件已被忽略的依据。编辑输入变化时重新查询，本次不为历史卡片增加
文件系统监听。SSH 查询必须在远程 runtime 执行，绝不使用本地路径代替。
宿主提供的 transcript 数据保持原样。
路径比较保留大小写，不解析文件系统别名；仅大小写不同的同一绝对路径可能
被遗漏。`~/...` 家目录相对路径不会被当作工作区相对路径。

## 验证与验收

- 真实 Git 测试覆盖匹配忽略规则的已跟踪文件、被忽略及正常的新文件、嵌套规则、
  否定规则、全局忽略和非 Git 目录。
- 路由测试覆盖选定 runtime、会话 cwd 校验、非法输入、不可信／未知／关闭的
  工作区，以及请求期间 generation 关闭。
- 前端测试覆盖路径范围、统计、全部隐藏、异步竞态和旧 daemon 降级；历史展示
  不得依赖当前 Git 脏文件集合。
- 浏览器 E2E 使用模拟 daemon 验证卡片和打开的评审，明确区别于真实 Git 验证，
  捕获截图并目视检查。
- 完成构建、类型检查、打包、针对性测试、格式检查及两轮干净的 diff 自查。

## 开放问题

本次范围内没有未决问题。工作区内未被 Git 忽略的文件仍展示，即使它是临时脚本。
