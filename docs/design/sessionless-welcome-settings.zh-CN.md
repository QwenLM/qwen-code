# 无会话欢迎页设置

[English](sessionless-welcome-settings.md) | [简体中文](sessionless-welcome-settings.zh-CN.md)

## 问题

Web Shell 在创建对话前显示欢迎页。欢迎页可能发布目录中不存在的已保存模型，
而认证时会回退到已配置的聊天模型。当前切换 UI 语言通过发送斜杠提示词实现，
会创建对话并重新应用失效模型。没有配置任何连接的用户也必须能够切换 UI 语言。

## 决策

保留现有 Core 认证回退和持久化策略。目录中找不到模型时，欢迎页通过相同的 Core
同步逻辑解析预览，不执行认证、网络请求或配置写入。保留显式手动连接，以及
已注册模型现有的端点选择行为。

UI 语言切换改用无会话接口。复用进程全局的用户语言接口；新增受信任、归属于
所选工作区的语言接口，只保存该工作区并同步其已经运行的通道。不启动冷运行时，
后续启动时读取已保存配置。两条路径均保留输出语言和模型选择，保留 generation
及客户端归属校验。无法解析的工作区不得回退到主工作区。

SSH 工作区的设置和 agent 运行时仍归属于本地注册的工作区锚点，与现有工作区设置
接口一致。允许语言接口通过 SSH 边界，不写入远端项目文件。

Web Shell 设置选择器和本地 `/language ui` 命令共用此路径。保留用户/工作区作用域、
宿主语言控制权和错误回滚。仅在会话已经存在时刷新会话命令元数据。
Live 会话的工作区 UI 语言沿用设置 provider 绑定的工作区，与其他设置项一致。
无法解析目标时拒绝写入；输入框的工作区解析仍不为 Live 和 standalone 会话提供
普通项目目标。
作用域参数可以放在 UI 语言前后，与 CLI 一致；同时提供 `--project` 和 `--global`
仍然无效。写入成功后采用响应中的实际生效语言，并保留显式宿主语言的控制权。
实时同步部分失败时显示警告，不回滚已保存的选择。工作区校验分别报告语言和
不支持的同步参数错误，提供错误说明，并在语言无效时返回可用语言。

## 验收

- 保存模型已失效且目录只有 preview 时，欢迎页与首次对话选择一致，不改写
  `model.name`。
- 已注册模型及其端点保持不变；手动配置的运行时连接不会被无关目录模型替换。
- 无模型、无会话时可以切 UI 语言；不创建对话、选择模型、请求模型接口或改变
  输出语言。
- 用户级写入用户配置；工作区级仅写入解析出的受信任工作区，包括次工作区。
  无效或已移除的工作区应失败，不能修改主工作区或用户配置。
- Live 会话的设置页工作区语言选择器和项目级语言命令使用相同的绑定工作区，
  不创建会话或发送提示词。Standalone 会话仍拒绝项目级命令。
- UI 语言命令接受作用域参数的两种位置；被覆盖的选择采用返回的实际生效语言。
  部分同步失败时警告，不回滚已保存的值。
- 测试固定工作区 strict 写入、所选工作区的设置读取、语言事件、同步期间
  generation 关闭，以及较晚启动的 Managed 通道在首个会话前重放工作区作用域。
- 桌面和当前 VS Code 的 Web Shell 宿主共用行为。原生安装包验收与 fixture 测试
  分别报告。
