# Agent 通信 PR 边界

[English](2026-09-27-agent-communication-pr-split.md) | [简体中文](2026-09-27-agent-communication-pr-split.zh-CN.md)

## 决策

#11206 保留本机协作基础。把 A2A 从 #12582 拆成同样基于本机协作基础的独立 PR。#12582 保留 Runtime 加入、程序绑定、心跳、租约领取、进度和结果回传；A2A 保留 JSON-RPC 传输、Agent Card、调用方授权、幂等外部请求、分享 UI 和对应测试。

A2A 通过持久化线程调用已有本机调度器，不需要远端主机身份、执行位置或租约。两个后续 PR 均须独立构建并通过各自验收。本机协作合入后，分别更新到 main 并重跑 CI，两者没有必须先合入另一项的依赖。

## 保留行为与验证

移动已有行为，不新增抽象、不修改协议。本机会话释放时保留授权的修复随 A2A 移动；重领租约的消息投递修复及工作区移除后的领取修复留在远程 Runtime。分享使用自己的复制/完成翻译键，避免依赖 Runtime UI。

验证独立 build/typecheck、定向存储/路由/UI 测试和真实 HTTP 验收。A2A 分支应提供分享且没有主机路由；Runtime 分支应提供主机执行且没有 A2A/分享路由。保留拆分前的完整实现作为比较基准，并审查所有提取变更。

## 后续工作

Runtime 移除/密钥撤销及真实双机、Claude、Codex 验收仍属于 Runtime PR。A2A 保留现有只读权限上限和轮询传输。拆分不改变本机基础的预算或历史保留策略，也不表示远端 CI 已完成。
