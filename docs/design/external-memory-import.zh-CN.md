# 外部记忆导入

[English](external-memory-import.md) | [简体中文](external-memory-import.zh-CN.md)

## 问题与边界

外部客户端需要将 Codex 知识迁移到 Qwen 原生记忆，无需安装收集器，也无需向云端运行时开放本地文件系统。本功能仅属于 Qwen，不包含 DataAgent/OpenCode 界面或独立工具。直接把 Markdown 列表项转为原生记忆会丢失上下文，也无法可靠处理历史知识与已有记忆的关系。

## 设计

版本化来源集合包含相对 Markdown 路径和 UTF-8 内容。离线解析器返回来源章节、稳定内容标识、项目归属提示、引用和警告。章节保留所属标题与元数据。无法确定的归属保持待分配。来源路径只是溯源信息，不是服务端目标路径。不接受原始会话、凭证、配置和技能。只有选中章节成为不可变的保留资源。

每个提交批次属于一个可信工作区。调用方明确将选中章节映射到该工作区的项目级或用户级范围；其他项目组可提交到其他工作区 ID。未知、不可信、已移除、SSH 和正在退出的运行时均拒绝，不回退。`memory_import_v1` 能力标识公布此契约。HTTP 沿用 daemon 认证和严格变更保护。

预览确定性执行，不调用模型，不写入记忆或任务记录。确认后先持久化选中资源和任务，再返回。后台通过无工具的结构化旁路查询使用目标工作区模型。历史来源是数据，不是指令。模型只能看到选中章节及同范围的已有记忆；可提出新记录、识别重复或标记冲突，不能编辑现有记录。所有写入之前由运行时验证。

任务状态、不可变资源及提交意图位于私有运行目录，独立于原生扫描根目录。确定性标识和持久化记录防止重复导入恢复已编辑或遗忘的输出。提交串行执行，模型完成后复查已扫描记忆版本。校验后的输出先记录提交意图再发布；恢复过程区分未发布意图与已完成输出。取消阻止后续提交。服务激活时恢复持久化任务；模型失败需显式重试，避免无界付费重试。

导入的项目文档使用独立私有根目录，以真实 Git common directory 为标识。主检出与 linked worktree 共享，clone/fork 不因 remote 相同而共享。普通项目记忆继续按 worktree 隔离。原生扫描、搜索、全文获取、召回与遗忘覆盖导入层。来源快照不进入原生扫描，不向原生写入代理开放任意来源访问权限。

## 接口

限定工作区的 HTTP 路由提供预览、批次提交、列表、状态、来源查看、取消与重试。请求使用来源/章节 ID、显式范围选择和客户端幂等键，不接受目标路径。CLI `memory import codex --source <directory> --dry-run --json` 离线复用同一解析器。确认后的 CLI 导入使用同一任务服务及本地工作区模型配置。JSON 响应带有 `version: 1`，区分预览、任务与结果计数；来源章节数不等于最终记忆数。

## 验证与交付

仅使用合成来源及隔离 HOME/runtime/目标目录。验证离线预览、选择边界、无效路径、范围映射、同仓库 worktree、真实原生搜索/全文、模型输出拒绝、重复、冲突、编辑、遗忘、取消、部分失败、并发与重启恢复。使用独立客户端及确定性模型服务验证 HTTP。替代 PR 前完成构建、类型检查、包内定向测试、完整 diff 隐私审查和两轮干净自审。不提交用户记忆、预览、截图或本地报告。替代 PR 创建后才关闭旧 PR。持续同步与跨实例同步不在范围内。
