# 外部记忆导入

[English](external-memory-import.md) | [简体中文](external-memory-import.zh-CN.md)

## 问题与边界

外部客户端需要将 Codex 知识迁移到 Qwen 原生记忆，无需安装收集器，也无需向云端运行时开放本地文件系统。本功能仅属于 Qwen，不包含 DataAgent/OpenCode 界面或独立工具。直接把 Markdown 列表项转为原生记忆会丢失上下文，也无法可靠处理历史知识与已有记忆的关系。

## 设计

版本化来源集合包含相对 Markdown 路径和 UTF-8 内容。离线解析器返回来源章节、稳定内容标识、项目归属提示、引用和警告。章节保留所属标题与元数据。无法确定的归属保持待分配。来源路径只是溯源信息，不是服务端目标路径。不接受原始会话、凭证、配置和技能。只有选中章节成为不可变的保留资源。解析前通过保守的换行与行内标记上限限制 Markdown 复杂度；重复祖先正文计入 8 MiB 预览展开上限，超限来源需拆分。

每个提交批次属于一个可信工作区。调用方明确将选中章节映射到该工作区的项目级或用户级范围；其他项目组可提交到其他工作区 ID。未知、不可信、已移除、SSH 和正在退出的运行时均拒绝，不回退。`memory_import_v1` 能力标识公布此契约。HTTP 沿用 daemon 认证和严格变更保护。

预览确定性执行，不调用模型，不写入记忆或任务记录。确认后先持久化选中资源和任务，再返回。后台通过无工具的结构化旁路查询使用目标工作区模型。历史来源是数据，不是指令。模型只能看到选中章节及同范围的已有记忆；可提出新记录、识别重复或标记冲突，不能编辑现有记录。所有写入之前由运行时验证。

任务状态、不可变资源及提交意图位于私有运行目录，独立于原生扫描根目录。确定性标识和持久化记录防止重复导入恢复已编辑或遗忘的输出。提交串行执行，模型完成后复查已扫描记忆版本。校验后的输出先记录提交意图再发布；恢复过程区分未发布意图与已完成输出。取消阻止后续提交。服务激活时恢复持久化任务。恢复失败会记录日志，导入任务请求返回 HTTP 503 和 `Retry-After: 1`，下一次任务请求重新尝试恢复；并发请求共享恢复过程，恢复成功后缓存结果，预览不触发恢复。模型失败需显式重试，避免无界付费重试。未知重试 ID 不创建任务目录。每把锁仅向依赖它的工作传递丢失通知；检测到丢失后，旧持有者不能替换记录或发布暂存文档。其他任务继续运行，显式用户取消仍可持久化取消状态。

HTTP 区分无效请求（400）、不存在的批次（404）、不可用的运行代（503 和 `Retry-After: 1`）及意外服务或存储故障（500）。提交或重试成功持久化后，即使运行时随即关闭也返回 202 回执；发布仍受运行时检查保护，读取在返回正文前再次检查访问权限。客户端保留幂等键和批次 ID，以在结果不确定时核对原任务，避免创建另一次导入。

导入的项目文档使用独立私有根目录，以真实 Git common directory 为标识。主检出与 linked worktree 共享，clone/fork 不因 remote 相同而共享。普通项目记忆继续按 worktree 隔离。原生扫描、搜索、全文获取、召回与遗忘覆盖导入层。来源快照不进入原生扫描，不向原生写入代理开放任意来源访问权限。

导入发布目前要求记忆根目录不是软链接。发现软链接根目录时，在扫描已有正文或预扣模型预算前将对应条目标为失败，原因明确提示改用非软链接布局后再重试。已有记忆和链接保持不变；普通原生扫描仍支持用户记忆根目录软链接。私有导入状态目录的软链接守卫保持不变。通过外部根目录发布的支持留待后续。

## 分批整理与成本限制

每个运行时按确认的 scope 和原始项目组分组，按内容 ID 排序，每次模型请求最多包含 8 个章节和 64 KiB 来源。响应必须为每个来源 ID 返回恰好一个通过原生校验的决定。继续保留逐来源身份和发布台账；首次写入前持久化整批响应与基线文档哈希。后续提交接受基线加同一任务在该范围内所有分组已验证的写入；保留基线中原有的哈希，外部编辑、删除或新增均产生冲突。尚未发布的 intent 若因发布前检查冲突而失效，会清理台账与暂存文件；中断后发现此类失效 intent 时，新任务可按当前记忆重新整理。已经发布的文档继续使用编辑与遗忘保护，不回滚或重新生成。重启复用已保存的响应。模型响应保存前先校验范围；旧记录若含范围无效的条目，重试只丢弃该条目的响应，在剩余预算内重新整理，保留同批其他决定、基线和发布记录。

元数据索引直接使用原生解析器识别并规范化的字段。模型收到该有界索引和相关文档全文，不再逐条复制全部已有正文。本地仍扫描完整快照以保护编辑和遗忘。索引按上下文预算有界，放不下的仅有索引条目会被省略。相关证据超限时返回可操作的上下文限制结果，不静默丢弃相关证据。明确标记只有索引的条目；无法排除的内容重叠必须返回冲突。相关性逐条比较选中来源，复用原生召回的分脚本分词（最多保留头尾 64 个词元，包含 CJK 双字词元）。正文完整匹配或包含至少两个词元的标题／描述完整匹配时保留全文；否则至少两个共享词元须覆盖标题与关键词词元的一半。仅描述或使用场景中的通用词重合不会展开全文，这些字段仍保留在元数据索引中。这仍是词法启发式，不保证语义完整，也不会为满足预算将超限的相关证据降级为索引。

跨来源的编辑和遗忘保护仅在暂存目录仍存在且原生目标不存在时忽略 intent。已经完成 rename 的 intent 即使尚未更新 committed 台账，也保留保护；删除或编辑已发布内容不得导致其被重建。

离线预览按来源项目组估算调用和输入／输出 token，并预留最大已有上下文，因为预览不读取原生记忆。待分配组在明确映射前仅供估算。这不是供应商账单报价。每个任务最多 32 次逻辑模型调用、512,000 个预留 token 单位；预留量包括请求字节数（提示词与 schema）和每次 8,192 个输出 token。调用前持久化扣减；失败、取消和重试均不退还或重置预算。耗尽后保留未完成条目，不再调用模型。限制模型输出并关闭导入请求的后台外层无限重试。供应商内部重试及分词开销意味着该限制不等于实际计费 token 或金额硬上限。

仓库身份解析采用有界缓存，接入已有记忆根目录缓存清理；运行时路径独立解析。没有 imported-project-memory 目录的运行时完全跳过导入仓库解析。导入写入前重新校验 Git 身份，避免缓存授权过时目标。每次命中缓存都会检查已记录的文件系统依赖，包括尚不存在的 Git 标记、指针文件、linked worktree 注册及项目符号链接。依赖变化后重新解析身份；无效注册会拒绝返回旧的导入根目录。未变化的条目仅检查元数据，不重复搜索祖先目录、解析 realpath 或读取 Git 元数据正文。依赖检查不是原子文件系统快照。普通项目记忆的缓存与隔离保持不变。

用户导入仍保存在用户记忆根目录的保留子树 `imported/` 中。有限用户扫描和索引生成优先保留该子树以外的原生条目，维持原生条目的时间排序以及现有 200 文档、200 行和字符上限。原生长链接保留导入前可用的空间，导入条目只使用剩余容量。未进入有限目录的导入内容仍可通过原生搜索和明确引用读取。项目和团队记忆的排序保持不变。

## 接口

限定工作区的 HTTP 路由提供预览、批次提交、列表、状态、来源查看、取消与重试。请求使用来源/章节 ID、显式范围选择和客户端幂等键，不接受目标路径。CLI `memory import codex --source <directory> --dry-run --json` 离线复用同一解析器。确认后的 CLI 导入使用同一任务服务及本地工作区模型配置。JSON 响应带有 `version: 1`，区分预览、任务与结果计数；来源章节数不等于最终记忆数。

## 验证与交付

仅使用合成来源及隔离 HOME/runtime/目标目录。验证离线预览、选择边界、无效路径、范围映射、同仓库 worktree、真实原生搜索/全文、模型输出拒绝、重复、冲突、编辑、遗忘、取消、部分失败、并发与重启恢复。使用独立客户端及确定性模型服务验证 HTTP。替代 PR 前完成构建、类型检查、包内定向测试、完整 diff 隐私审查和两轮干净自审。不提交用户记忆、预览、截图或本地报告。替代 PR 创建后才关闭旧 PR。持续同步与跨实例同步不在范围内。
