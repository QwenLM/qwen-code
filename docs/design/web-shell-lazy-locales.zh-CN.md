# 按需加载 Web Shell 语言资源

[English](web-shell-lazy-locales.md) | [简体中文](web-shell-lazy-locales.zh-CN.md)

## 当前行为

Web Shell 启动时会一起求值英文、简体中文、繁体中文和俄语词典。即使页面只显示一种语言，也会承担四套词典的开销。

## 设计

- 英文保留同步加载，用于初始渲染和翻译缺失时兜底。其余三套主词典改用显式动态导入。已有的多语言功能文案模块仍可能与首屏 JavaScript 共享代码。
- 独立 Web Shell 根据 URL、已保存偏好或浏览器语言确定初始语言，在认证启动期间并行加载，词典可用后再渲染。后续收到守护进程的语言偏好或用户切换语言时，加载对应词典。React 订阅者在等待期间使用英文，目标词典就绪后更新。同一语言的并发加载共享一个 Promise，已加载的词典在当前页面生命周期内复用。
- 会话导出构建使用静态词典和现有的导出替代词典，保持同步且自包含。这样可以保留原有的语言覆盖范围，导出的 HTML 也能离线打开。

## 验证

分别用四种语言冷启动页面，检查生产构建请求的 JavaScript。确认页面显示目标语言，且仅请求当前选中的非英文主词典。切换语言并确认较晚返回的请求不会覆盖当前选择。验证翻译缺失或分块加载失败时回退到英文，并确认独立的会话导出产物仍包含预期翻译。
