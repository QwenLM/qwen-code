# 感知上下文窗口的压缩后恢复

[English](window-aware-post-compaction-restoration.md) | [简体中文](window-aware-post-compaction-restoration.zh-CN.md)

## 问题

摘要成功后，恢复最近访问的文件可能使下一轮会话再次超出较小的上下文窗口（#15487）。现有的 50,000-token 文件内容预算不随窗口大小变化。图片恢复有数量限制，但没有总 token 预算。仅检查候选历史是否比原历史更小，无法防止这种溢出。

## 行为

压缩服务为恢复的文件内容分配 `min(50_000, floor(effectiveWindow / 4), floor(autoThreshold / 2))` token 的预算。当被拒绝请求的路由与当前主路由一致时，有效窗口采用服务端报告的较小输入或总窗口上限，包括使用独立模型生成摘要的情况。摘要生成的输出预算遵循自身的路由与上限规则。自动压缩阈值包含用户配置的比例。为摘要和其他上下文预留阈值的一半，使较低阈值下仍能部分恢复文件，包括 40K 窗口的默认阈值。

组合器先按配置的单张图片 token 成本为实际恢复的图片预留空间，再将剩余预算分配给文件内容。文件内容及其恢复大小采用与摘要估算相同的 CJK 字符范围和倍数。其他文字继续使用基于字符数的估算。单文件读取器的字符大小上限和文件数量限制继续生效。超出内容预算的文件保留为路径引用，优先考虑最近访问的文件。直接调用恢复逻辑且未传入预算的调用方使用 50,000-token 默认值。

溢出检查计入摘要、恢复内容、现有不可见上下文和待提交工具结果。自动压缩的现有返回计数已包含待提交工具结果。门禁为本地估算的文本追加 CJK 校正差额，包括缺少摘要 usage 或采用缓存共享计数时的摘要与确认消息。服务商报告的摘要输出计数继续作为权威值。字符估算和 CJK 校正共用同一套 Part 遍历，文本校正排除媒体和包装元数据的预留量。

恢复目标为 `min(autoThreshold, max(0, effectiveWindow - 3_000))`，使用已有的硬阈值缓冲为请求开销预留空间。16K 窗口下的默认目标为 13,000 token。当恢复了文件正文或图片，且校正后的候选计数达到目标，则重新组合历史，移除全部恢复文件块、路径引用和图片。纯路径引用或纯提醒历史保留首次组合结果。返回计数与膨胀保护继续使用原有的字符估算历史差额，并以原始总计数为锚点。移除附件时按相同基准扣除差额，保留摘要及不可见系统／工具上下文的计数。调试日志记录移除的块数、恢复目标、CJK 校正差额，以及移除附件前后的计数。

第二次组合仍保留计划模式提醒、运行中的后台代理提醒，以及与待提交结果配对所需的末尾工具调用。它不会再次请求摘要，也不会再次触发压缩 hook。现有的载荷超限恢复限制和托管场景文件恢复排除规则继续生效。

## 范围与限制

本修复只处理恢复阶段。压缩请求准入（#9455 / #15936）和后续请求计数（#15486）保持独立。本地 token 计数是近似估算；这些限制不保证每个服务商都能精确接纳请求，也不能让过大的摘要自动适配窗口。现有的空摘要、输出截断和计数膨胀失败处理保持不变。

## 验证

- 使用五个真实文件和已完成的模拟摘要验证 16K 恢复预算及组合历史大小。候选计数位于 13,000 恢复目标与 13,600 自动压缩阈值之间时，必须移除嵌入正文。
- 验证 16K 和 32K 窗口仅保留预算容纳的文件内容，其余文件保留为引用。
- 验证低于 200K 时的窗口四分之一限制。128K 下的 32K 预算应嵌入八个 20,000 字符文件中的六个，其余两个保留路径。200K 下的 50K 预算应嵌入全部八个。在 1M 窗口、提高文件数量限制时验证 50K 上限。
- 覆盖文件内容剩余预算为零的情况，并在超过恢复目标时保留纯路径引用历史。
- 覆盖服务端报告的总窗口上限、仅输入上限、独立摘要模型和路由不匹配情况。
- 验证 40K 窗口以及较低的用户配置阈值下仍能部分恢复文件。
- 验证 CJK 内容消耗文本 token 预算、其他文字保留原有估算，且缺少 usage 元数据时实际缩小的 CJK 历史仍能成功压缩。
- 验证实际恢复的图片先按配置的 token 成本预留空间，再分配文件内容预算。
- 验证 ASCII 待提交工具结果只计入一次、CJK 待提交结果获得校正，并在移除附件后的报告计数中保留较大摘要的体积。
- 对比用户配置和默认自动压缩阈值，并检查附件移除的调试日志。验证缺少 usage 的中文摘要触发附件移除，服务商已报告的摘要 usage 无需追加校正。
- 分别在有、无摘要 usage 元数据时，让恢复的文件和图片超出恢复目标；验证附件被移除，不可见上下文计数、提醒和待提交工具调用配对得到保留。
- 运行现有压缩、附件和 token 估算测试。服务级测试将该阶段与压缩请求准入隔离，不代表真实服务商的端到端验证。
