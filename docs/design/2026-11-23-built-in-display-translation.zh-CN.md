# 内置显示翻译

[English](2026-11-23-built-in-display-translation.md) | [简体中文](2026-11-23-built-in-display-translation.zh-CN.md)

状态：已实现。本文新增一个设置，把模型的回复和展开的思考翻译成简体中文或英文显示，在 #13749 跟踪。翻译复用 [Web Shell 中的 Mod 回复行](2026-11-18-mod-rows-in-web-shell.zh-CN.md) 和 [Web Shell 中的 Mod 思考行](2026-11-20-mod-thinking-rows-in-web-shell.zh-CN.md) 描述的回复行和思考行。

## 问题与现状

Mod 已经能改写回复块和展开的思考的显示，在 Ink、OpenTUI 终端和 Web Shell 中都能用。用户指南给出了一个基于此的翻译 Mod。使用它需要四步：

- 打开 `experimental.mods`；
- 信任工作区；
- 写三个文件；
- 把它们安装为扩展。

不做这些，唯一的翻译就是 Web Shell 的翻译按钮。它在每段思考旁边，打开一个弹层，显示翻译成界面语言的译文。它不覆盖回复，终端里也没有。

`general.outputLanguage` 不能替代它。它让模型用某种语言回答，这会改变模型写的内容和之后回合读到的内容。有些用户希望模型继续用它自己的语言工作，只想用自己的语言阅读结果。

## 目标与非目标

目标：

- 一个设置，在 Ink、OpenTUI 终端和 Web Shell 中把回复和展开的思考显示为简体中文或英文。
- 该设置无需 `experimental.mods`、无需安装任何东西，在不受信任的工作区中也能用。
- 只改显示。存储的对话、模型读到的内容、`/copy` 和 Web Shell 的复制按钮保持原文。
- 已经是目标语言的块和只有代码的块保持原样，不产生费用。

非目标：

- 其他目标语言。
- 移除或修改 Web Shell 的翻译按钮。它会另行逐步下线。在此之前，被翻译改写过的思考上它保持隐藏，与任何 Mod 改写时的现有行为相同。
- 翻译工具输出、用户的 prompt、折叠的思考行、子代理视图、会话预览、导出的对话记录或 headless 输出。它们都不是回复行或思考行。
- VS Code companion，它不绘制 Mod 行。

## 设计决策

### 设置

`general.displayLanguage` 是一个枚举，取值为 `off`、`zh-CN` 和 `en`，默认 `off`。它的标签是 "Language: Display Translation"，与 "Language: UI"（`general.language`）和 "Language: Model"（`general.outputLanguage`）并列。额外的模型调用由用户或系统设置控制。工作区设置不能设置这个键。

目标语言在会话开始时读取，并在该会话内保持不变，所以该设置需要重启。行的缓存答案以行的 component 和 props 为键，不包含目标语言，所以会话中途改变目标语言，会让缓存用旧语言回答这些行。Web Shell 把改动应用于改动之后启动的会话，与 `experimental.mods` 相同。它也不跟随 Web Shell 自己的界面语言：界面语言不同的两个标签页共享同一个会话和它的缓存。

### Mod 渲染后的内置翻译

CLI 在已安装的 Mod 渲染完毕后翻译行。翻译复用行请求、串行调度、30 秒期限和会话缓存。不占用 Mod 名额，模型请求也不进入处理提示和工具的队列。

宿主绘制 `AssistantMessage` 或 `Thinking` 行时才会翻译。Web Shell 请求翻译时，由会话验证行来自自己已完成的回复或思考，包括可见的工具准备事件之前的回复，以及 Insight 卡片两侧拆出的正文。发起模型调用和返回译文前都会重新校验当前历史分支。刷新页面、第二个标签页或再次展开思考时可以使用缓存。

用户指南中的翻译示例现在为这两种语言指向该设置，并继续作为构建此类 Mod 的示例保留。

### 开关条件

已安装的 Mod 运行第三方代码，所以需要 `experimental.mods` 和受信任的工作区。用户启用内置翻译后，翻译可以在不受信任的工作区中运行，也可以在 `experimental.mods` 关闭时运行。

其他开关条件仍然适用于它。它们描述的是管理员或用户关闭了 hook，或者 Mod 无法运行、没有可绘制内容的会话：

- `disableAllHooks`；
- 受管 hook；
- bare 模式；
- 安全模式；
- 沙箱；
- 执行环境；
- 由工作区 agent 运行的会话。

翻译失败时保留行原有的内容。已安装 Mod 的初始化行为保持原样。

### 哪些块会被翻译

语言检查读取 Markdown 正文，跳过围栏代码、缩进代码和行内代码。对于由汉字和拉丁字母组成的正文，汉字数不少于拉丁单词数的块算作中文。含其他文字系统字母的正文可以翻译。只有代码的块保留原样。

- 目标 `zh-CN`：简体中文块保持原样，繁体中文正文可以翻译。
- 目标 `en`：对于拉丁单词数多于汉字数的拉丁字母正文，语言检查保留原样。

这里用字比较词，是因为中文句子常带英文标识符。如果像指南示例那样比较字母，`useState` 会算作八个英文符号，对比的只是一个中文词。目标为中文时这只会多几次调用；目标为英文时，这样的中文句子就不会被翻译。

### 模型调用

翻译通过 Mod 模型服务使用 `haiku` 别名，选择会话的 fast model，未设置时使用会话模型。调用不请求思考，超时为 25 秒，在行的 30 秒期限之内，输出上限为 8,192 个 token。提示要求返回完整译文并附固定结束行。如果答案为空、缺少结束行、带有宿主的截断标记，或改变显示的代码，行保留原有的内容。代码块必须保持顺序。行内代码、数学公式、行内 HTML 以及链接和图片的地址可以随译文语序移动位置，但每一项都必须保持不变。比较裸露地址时忽略末尾的全角或中文标点，因为 GFM 可能把它们解析为地址的一部分。Web Shell 的译文将标点保留在链接外，如果分隔标点会改变链接地址，整块保留原文。显式 Markdown 链接和尖括号自动链接要求地址完全一致。主机名、路径、查询参数或 `mailto` 收件人发生变化时，行保留原始回复。裸露地址后若紧贴会被 GFM 读进地址的中文文本，同样保留原文。在终端里，Ink 从原始文本中识别出的链接（CommonMark 可能把它们当作转义文本或 HTML）也必须保持地址不变。

调用会把每个被翻译的块的文本发送到 fast model 的端点。fast model 与会话模型使用不同的提供方时，该提供方会收到这些文本。替换录制会话的分支会取消该分支的翻译请求，包括仍在等待模型路由或凭证的请求。

## 验证与验收

单元测试：

- 设置：只有 `zh-CN` 和 `en` 会开启翻译。工作区的值不会覆盖用户设置。
- Mod 会话：
  - 只启用用户设置时，不受信任的工作区也可以翻译。已安装的 Mod 仍需要单独启用和工作区信任。
  - bare 模式和 `disableAllHooks` 会让它保持关闭。
  - 翻译在已安装的 Mod 之后运行，保留 32 个已安装 Mod 的名额，等待翻译模型响应期间可以提交提示。
  - 不绘制回复行或思考行的宿主不会翻译。
- 翻译：
  - 每个目标语言都跳过已是该语言的块和只有代码的块。简体目标可以翻译繁体中文。
  - 其他块通过 fast model 别名翻译。
  - 保留代码，调用未得到回答时保留原文。

`qwen-serve-mod-rows` 集成测试只开启该设置，用模拟模型翻译会话的回复行和思考行。会话里没有的行不会触发翻译调用。

在真实的 Web Shell 以及 Ink、OpenTUI 终端中，分别在设置和不设置 fast model 的情况下检查两个目标语言：

- 英文输出显示为中文，中文输出显示为英文。
- 已是目标语言的块和只有代码的块不变。
- 复制按钮复制原文。
- 思考被翻译后，它的翻译按钮隐藏。

2026-11-23 使用 deepseek-v4.1-flash 检查，fast model 为关闭思考的 deepseek-v4-flash-0731：

- Web Shell，目标 `zh-CN`，设置了 fast model：英文回复和展开的思考显示为中文，思考的翻译按钮隐藏，复制得到英文原文，刷新后仍显示译文。
- Web Shell，目标 `en`，未设置 fast model：中文回复显示为英文，复制得到中文原文。模型用英文思考，所以思考保持原文，并保留翻译按钮。
- Ink 和 OpenTUI，目标 `zh-CN`：英文回复显示为中文，存储的对话保持英文。

验收：只设置 `general.displayLanguage`、不改其他任何东西时，新会话在三个界面中都把已完成的回复和展开的思考显示为目标语言，存储的对话保持原文。

## 风险与待定问题

- 每个已完成的块和每段展开的思考，每个会话各花一次模型调用。恢复的会话会再次翻译它显示的行。
- 会思考的 fast model 或较慢的模型可能错过 30 秒期限。这样的块保留原文。
- 块在答案到达时从原文切换为译文，高度可能变化。
- 在 Ink 中，历史保存在终端回滚缓冲区时（`ui.useTerminalBuffer` 关闭，或使用屏幕阅读器），已打印的行无法改变，不会被翻译。
- 两种语言大致各占一半的文本，语言规则可能判断错误。这样的块要么被翻译，要么保留原文，都不会丢失内容。
