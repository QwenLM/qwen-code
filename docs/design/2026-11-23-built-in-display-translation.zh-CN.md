# 内置显示翻译

[English](2026-11-23-built-in-display-translation.md) | [简体中文](2026-11-23-built-in-display-translation.zh-CN.md)

状态：已实现。本文新增一个设置，把模型的回复和展开的思考翻译成简体中文或英文显示，在 #13749 跟踪。翻译以内置 Mod 的形式提供，作用于 [Web Shell 中的 Mod 回复行](2026-11-18-mod-rows-in-web-shell.zh-CN.md) 和 [Web Shell 中的 Mod 思考行](2026-11-20-mod-thinking-rows-in-web-shell.zh-CN.md) 描述的回复行和思考行。

## 问题与现状

Mod 已经能改写回复块和展开的思考的显示，在 Ink、OpenTUI 终端和 Web Shell 中都能用。用户指南给出了一个基于此的翻译 Mod。使用它需要四步：

- 打开 `experimental.mods`；
- 信任工作区；
- 写三个文件；
- 把它们安装为扩展。

不做这些，唯一的翻译就是 Web Shell 的翻译按钮。它在每段思考旁边，打开一个弹层，显示翻译成界面语言的译文。它不覆盖回复，终端里也没有。

`general.outputLanguage` 不能替代它。它让模型用某种语言回答，这会改变模型写的内容和之后回合读到的内容。有些用户希望模型继续用它自己的语言工作，只想用自己的语言阅读结果。

## 目标与非目标

目标：

- 一个设置，在 Ink、OpenTUI 终端和 Web Shell 中把回复和展开的思考显示为简体中文或英文。
- 该设置无需 `experimental.mods`、无需安装任何东西，在不受信任的工作区中也能用。
- 只改显示。存储的对话、模型读到的内容、`/copy` 和 Web Shell 的复制按钮保持原文。
- 已经是目标语言的块和只有代码的块保持原样，不产生费用。

非目标：

- 其他目标语言。
- 移除或修改 Web Shell 的翻译按钮。它会另行逐步下线。在此之前，被翻译改写过的思考上它保持隐藏，与任何 Mod 改写时的现有行为相同。
- 翻译工具输出、用户的 prompt、折叠的思考行、子代理视图、会话预览、导出的对话记录或 headless 输出。它们都不是回复行或思考行。
- VS Code companion，它不绘制 Mod 行。

## 设计决策

### 设置

`general.displayLanguage` 是一个枚举，取值为 `off`、`zh-CN` 和 `en`，默认 `off`。它的标签是 "Language: Display Translation"，与 "Language: UI"（`general.language`）和 "Language: Model"（`general.outputLanguage`）并列。它的描述说明了与另外两个的区别：模型照常回答，只翻译显示。

目标语言在会话开始时读取，并在该会话内保持不变，所以该设置需要重启。行的缓存答案以行的 component 和 props 为键，不包含目标语言，所以会话中途改变目标语言，会让缓存用旧语言回答这些行。Web Shell 把改动应用于改动之后启动的会话，与 `experimental.mods` 相同。它也不跟随 Web Shell 自己的界面语言：界面语言不同的两个标签页共享同一个会话和它的缓存。

### 内置 Mod

翻译是一个源码随 CLI 发布的 Mod，因此它走与已安装 Mod 相同的路径：

- 各界面对行的请求；
- 一次一个的行队列及其 30 秒期限；
- 会话的行缓存，它为刷新页面、第二个标签页或再次展开的思考作答；
- 使用 fast model 的 `$.model.complete`。

没有界面新增绘制代码。Web Shell 只要 daemon 提供行就会请求，所以它的消息组件不变，导出包也不会变大。

这个 Mod 以目标语言为选项，注册一个监听 `AssistantMessage` 和 `Thinking` 的 `ui.render` hook。只有宿主至少绘制其中一个站点时，它才会加入会话的 Mod。headless 运行不绘制任何站点，不会启动它。

它在所有已安装的 Mod 之后运行，处于 hook 链的最内层，所以它翻译的是其他 Mod 最终确定的文本。

用户指南中的翻译示例现在为这两种语言指向该设置，并继续作为构建此类 Mod 的示例保留。

### 开关条件

已安装的 Mod 运行第三方代码，所以需要 `experimental.mods` 和受信任的工作区。内置 Mod 只在模型自己的输出上运行 Qwen Code 自己的代码，两者都不需要：它在不受信任的工作区中、`experimental.mods` 关闭时也会加载。已安装的 Mod 仍然只在两者都满足时加载。

其他开关条件仍然适用于它。它们描述的是管理员或用户关闭了 hook，或者 Mod 无法运行、没有可绘制内容的会话：

- `disableAllHooks`；
- 受管 hook；
- bare 模式；
- 安全模式；
- 沙箱；
- 执行环境；
- 由工作区 agent 运行的会话。

只加载了内置 Mod 时，它启动失败会记录日志，会话照常运行，不做翻译。已安装 Mod 的失败仍像现在一样停止会话的 Mod，因为内置 Mod 与它们共用运行时。

### 哪些块会被翻译

只有缩进代码的块保持原样。其他块只看正文，去掉以反引号或波浪号闭合的围栏代码和行内代码，与指南中的示例相同。比较其中的汉字数和拉丁单词数。汉字数不少于拉丁单词数的块算作中文。两者都没有的块保持原样。

- 目标 `zh-CN`：中文块保持原样。
- 目标 `en`：非中文块保持原样。

这里用字比较词，是因为中文句子常带英文标识符。如果像指南示例那样比较字母，`useState` 会算作八个英文符号，对比的只是一个中文词。目标为中文时这只会多几次调用；目标为英文时，这样的中文句子就不会被翻译。

### 模型调用

hook 用 `haiku` 别名调用 `$.model.complete`，它运行会话的 fast model；没有设置时运行会话的模型。调用不带 `effort`，因此不请求思考；超时为 25 秒，在行的 30 秒期限之内；输出上限为 8,192 个 token。system prompt 要求翻译时保留 Markdown 结构、代码、路径、URL、命令和标识符，并在末尾加上固定的结束行。没有这一行的回答被截断了，例如达到了 token 上限。宿主为适应 Mod 载荷而只保留首尾的回答带有宿主的截断标记。两者都不完整，因此与未得到回答或回答为空一样，块保留原文，并写一行 debug 日志。

调用会把每个被翻译的块的文本发送到 fast model 的端点。fast model 与会话模型使用不同的提供方时，该提供方会收到这些文本。

## 验证与验收

单元测试：

- 设置：只有 `zh-CN` 和 `en` 会开启翻译，它或 `experimental.mods` 任一开启都会启动会话的 Mod。
- Mod 会话：
  - 只开该设置时，内置 Mod 会加载，包括在不受信任的工作区中。没有 `experimental.mods` 时或在不受信任的工作区中，已安装的 Mod 不加载。
  - bare 模式和 `disableAllHooks` 会让它保持关闭。
  - 两者都开时，内置 Mod 在已安装的 Mod 之后运行。
  - 不绘制回复行或思考行的宿主不会启动它。
  - 只有内置 Mod 时启动失败，会话仍继续运行。
- 内置 Mod：
  - 每个目标语言都跳过已是该语言的块和只有代码的块。
  - 其他块通过 fast model 别名翻译。
  - 调用未得到回答时保留原文。
- 变异检查：对语言规则、答案处理、开关条件、加载顺序和失败处理做的 19 个变异，每个都会让测试失败。

`qwen-serve-mod-rows` 集成测试新增一个用例：不安装扩展、打开该设置，回复行和思考行都由假模型的译文作答。

在真实的 Web Shell 以及 Ink、OpenTUI 终端中，分别在设置和不设置 fast model 的情况下检查两个目标语言：

- 英文输出显示为中文，中文输出显示为英文。
- 已是目标语言的块和只有代码的块不变。
- 复制按钮复制原文。
- 思考被翻译后，它的翻译按钮隐藏。

2026-11-23 使用 deepseek-v4.1-flash 检查，fast model 为关闭思考的 deepseek-v4-flash-0731：

- Web Shell，目标 `zh-CN`，设置了 fast model：英文回复和展开的思考显示为中文，思考的翻译按钮隐藏，复制得到英文原文，刷新后仍显示译文。
- Web Shell，目标 `en`，未设置 fast model：中文回复显示为英文，复制得到中文原文。模型用英文思考，所以思考保持原文，并保留翻译按钮。
- Ink 和 OpenTUI，目标 `zh-CN`：英文回复显示为中文，存储的对话保持英文。

验收：只设置 `general.displayLanguage`、不改其他任何东西时，新会话在三个界面中都把已完成的回复和展开的思考显示为目标语言，存储的对话保持原文。

## 风险与待定问题

- 每个已完成的块和每段展开的思考，每个会话各花一次模型调用。恢复的会话会再次翻译它显示的行。
- 会思考的 fast model 或较慢的模型可能错过 30 秒期限。这样的块保留原文。
- 块在答案到达时从原文切换为译文，高度可能变化。
- 在 Ink 中，历史保存在终端回滚缓冲区时（`ui.useTerminalBuffer` 关闭，或使用屏幕阅读器），已打印的行无法改变，不会被翻译。
- 两种语言大致各占一半的文本，语言规则可能判断错误。这样的块要么被翻译，要么保留原文，都不会丢失内容。
