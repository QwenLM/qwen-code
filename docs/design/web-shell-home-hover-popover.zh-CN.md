# 收起状态下的首页悬浮弹层

[English](web-shell-home-hover-popover.md) | [简体中文](web-shell-home-hover-popover.zh-CN.md)

## 问题与范围

导航栏收起后，悬停首页只显示文字提示。用户需要在不永久展开侧栏的情况下访问首页完整内容。侧栏已展开时，保留现有首页文字提示，包括当前打开其他页面的情况。只有首页的布局以及紧凑抽屉保持现有行为。

## 预期行为

复用侧栏现有悬浮面板和支持 portal 容器的共享 Popover，展示完整首页栏：品牌、新建任务、自定义导航、项目与会话、自定义页脚。在首页右侧显示，与导航栏保留 8 px 间距，使用已保存的二级栏宽度，并限制在视口可用高度内。保留共享 Popover 描边，不叠加第二层边框。同一时刻只渲染一份首页内容。在内联与 portal 呈现之间切换可能重新挂载子组件，与现有收起会话面板一致；父组件持有的搜索和会话状态继续共享。

当前选中频道或 Live 时，悬停临时呈现首页内容。悬停不得导航、持久化展开状态、创建会话或改变输入草稿。点击首页沿用现有导航和展开行为。离开触发器和内容后，使用现有宽限时间关闭；焦点和嵌套菜单应能正常操作。Escape 和外部交互可关闭弹层。布局、页面和收起状态变化时清理预览。

## 实现与决策

仅修改 Web Shell 侧栏呈现、样式和测试。扩展内部侧栏悬浮面板，支持现有外部首页锚点和完整栏呈现，复用焦点、嵌套浮层与关闭逻辑。保留 portal 容器和兼容 React 18 的 ref。不新增 daemon 路由、包 API、依赖或其他导航预览。

## 验证与验收

定向侧栏单元测试覆盖收起预览、展开时文字提示不变、完整内容、导航与收起偏好不变以及状态清理。浏览器 E2E 覆盖鼠标移动、搜索与菜单、关闭、草稿保留、首页/频道/Live 呈现、自定义内容、紧凑布局回归，以及模拟 daemon 下的深浅色截图。截图仅证明 UI，不证明真实 Git 或后端操作。运行仓库构建、类型检查和 bundle，并运行定向测试。先尝试全局 CLI 基线；如已安装 CLI 无法提供此源码 UI，改用浏览器测试入口。无未决设计问题。
