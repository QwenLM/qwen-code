# Web Shell 会话内搜索

[English](2026-09-19-web-shell-conversation-search.md) | [简体中文](2026-09-19-web-shell-conversation-search.zh-CN.md)

## 问题与范围

Issue #12231 要求在置底按钮旁提供搜索弹框，并直接定位命中内容。#10261 / #10612 的侧边栏搜索查找会话，每个会话只返回一段摘要，不能定位单条消息。#6824 和 #11111 涉及其它会话搜索界面。本次搜索当前 Web Shell 会话的用户和助手正文，包括 Markdown 和代码；不改动跨会话搜索、工具、思考内容或模型请求。

## 设计

在 `WebShellProps` 增加 `conversationSearchThreshold`，默认 10。用户和助手消息数严格超过阈值时显示搜索图标，不依赖置底按钮是否可见。图标位于左侧会话时间轴下方，采用 14px 图标与 20px 宽按钮，适配窄导航栏；时间轴刻度隐藏时同步隐藏搜索入口。各嵌入入口继承此配置。

复用 `DialogShell`、本地化文案、语义颜色和 portal root。打开时聚焦输入框；搜索防抖，展示高亮摘要，支持选择结果、上一个/下一个结果，Escape 关闭。保留输入草稿，不干扰进行中的回复。

通过会话所属的 turn-navigation client 分页扫描持久化 transcript，每页独立投影。最多保留 200 条命中摘要，不把完整会话载入 live store。展示当前可用结果数量及截断状态。空查询结合 `stopAfterMessages` 用于探测显示阈值，无需扫描整个历史。按字面量进行大小写不敏感匹配，支持中文。

结果携带持久化 record 身份，以及从 turn index 获得的所属 turn ordinal。渲染消息 ID 在不同投影之间不稳定。定位复用历史浏览窗口：先定位轮次，必要时继续向后分页，将持久化 record 映射到当前 block/message，展开折叠内容、居中并短暂高亮。历史页继续遵守现有 LRU 缓存预算。实时消息从当前 transcript 快照搜索，按 source 身份与持久化结果合并。

## 生命周期与限制

关闭弹框、修改查询或切换会话会使未完成搜索失效。定位拒绝过期会话或修订版本的结果，并核对持久化轮次身份。部分回放和请求失败必须明确展示并支持重试，不能误报为已搜完且无结果。不支持 turn navigation 的旧 daemon 只能搜索已加载消息，界面明确提示范围受限。不新增 daemon API、全文索引或设置持久化。

## 文件与验证

实现涉及 Web Shell 入口 props、搜索组件、i18n、turn-navigation store、历史浏览 hook/handle、README 和同目录测试。仅使用合成会话数据。

验证 10/11 条边界和自定义阈值；live window 之外的旧消息；用户/助手/代码及中英文正文；多条命中消息；空查询/无结果；过期请求与会话切换；折叠与虚拟列表定位；草稿保留及流式回复连续性。覆盖浅/深主题、中/英文、桌面/移动端与 portal 行为。基线和本地构建 E2E 证据与单测/build/typecheck 结果分开记录。
