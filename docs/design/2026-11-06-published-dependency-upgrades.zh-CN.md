# 发布包依赖升级

[English](2026-11-06-published-dependency-upgrades.md)

## 范围

Issue #16434 关注 SDK 与 Web Shell 使用者安装的依赖，以及内嵌在产物中的代码。
仓库根目录的 overrides 不会改变使用者的依赖树。修复应保留现有表格预览和数学
渲染行为，同时移除受影响的随包依赖。

## 实现约束

- 不可信输入包括 SDK 选项、ACP 消息、Markdown 数学公式、Mermaid 图表和上传的
  表格。依赖清单不能证明预构建浏览器包已经包含修补后的代码。
- 升级 SDK、内嵌 CLI 入口及其工作区依赖中的 Zod。保留当前 ACP 协议版本，使用
  畸形请求验证 Zod 错误分类。无效输入必须在调用处理器前被拒绝。验证失败应为
  参数无效错误，而不是服务器内部错误。
- 保留现有 Markdown 和 Mermaid 解析器。打包适配器，并保留已修补的 KaTeX
  运行时依赖，避免下游安装恢复适配器所声明的旧 KaTeX 范围。保留 Mermaid 的
  当前主版本，以维持浏览器支持、布局和外观。
- 保留 ExcelJS 的现有工作簿解析器与预览限制。从源码和修补后的依赖构建浏览器
  入口，替代上游不透明的预构建包。ExcelJS 改为构建依赖；仅适用于 Node 的归档
  依赖不得进入发布的 worker 或使用者依赖树。
- 保留 KaTeX 默认不信任模式，以及表格 worker 的错误响应和限制。不引入新的
  解析实现、放宽限制的回退逻辑或公开配置项。

SDK MCP 工具 schema 及其公开 TypeScript 类型改用 Zod 4；传入 Zod 3 schema
的调用者需要迁移。ACP 现有 Zod 错误处理生效后，畸形参数响应从 `-32603` 改为
`-32602`。打包版权说明包含 Browserify 提供的浏览器运行时垫片。

## 验证

对比已发布版本和本地打包版本的干净使用者安装：检查实际解析的 Zod、KaTeX、UUID、
inflight 和 minimatch 版本、生产依赖审计，以及浏览器和 CLI 产物。回归 SDK
选项验证与 MCP 工具类型推导、畸形 ACP 消息、行内/块级及 Mermaid 数学公式、
KaTeX 信任限制，以及表格 worker 现有值、格式和边界处理。执行仓库构建、类型
检查和定向测试；无法运行的检查须明确记录。不得通过提高产物体积预算掩盖回归。

实现与发布是不同步骤：PR 不能证明新的 npm 版本已交付使用者。正常发布流程完成
后，需要记录版本并再次执行干净使用者安装检查。
