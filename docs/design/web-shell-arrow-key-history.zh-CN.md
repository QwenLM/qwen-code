# Web Shell 方向键历史寻回设置

[English](web-shell-arrow-key-history.md) | [简体中文](web-shell-arrow-key-history.zh-CN.md)

## 问题

在 Web Shell 输入框中，按上、下方向键可能会寻回历史输入，替换编辑器中当前显示的内容。希望用方向键编辑文本的用户需要一个关闭此快捷操作的入口。

## 设计

在 Web Shell **设置 → 界面**中添加**用上下键寻回历史消息**开关。浏览器按来源保存此偏好，同一来源下的工作区共用该偏好。没有保存过的偏好时默认开启。切换后在当前 Web Shell 中立即生效。

普通会话、分屏和托管会话的 Web Shell 输入框都会读取此偏好。关闭开关后，上、下方向键仍可移动光标和导航补全菜单。Shell 命令历史、主动搜索历史消息和移动端输入历史列表仍可使用。

嵌入宿主可向 `WebShell`、`WebShellWithProviders` 或独立的 `ManagedAgentWebShell` 传入 `disableArrowKeyHistory={true}`，关闭对应实例的方向键寻回。如果设置面板显示该开关，开关将处于关闭且不可编辑的状态，并说明由宿主控制。浏览器已保存的偏好会保留，省略该属性或传入 `false` 时恢复生效。

## 验收标准

- 默认设置下，按上方向键可寻回历史输入，按下方向键可恢复草稿。
- 用方向键浏览历史时关闭开关，会立即恢复原草稿。
- 关闭开关后，上、下方向键保留草稿内容。刷新后仍处于关闭状态，重新开启即可恢复方向键寻回。
- 上、下方向键仍可移动光标和导航补全菜单。主动搜索历史输入和移动端输入历史列表仍可寻回历史输入。
- 即使已保存的偏好为开启，传入 `disableArrowKeyHistory={true}` 也会立即关闭方向键寻回。可见的开关显示为关闭且不可编辑。移除该属性或传入 `false` 后，已保存的偏好立即恢复生效。
