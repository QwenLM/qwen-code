# Web Shell 方向键历史寻回设置

[English](web-shell-arrow-key-history.md) | [简体中文](web-shell-arrow-key-history.zh-CN.md)

## 问题

在 Web Shell 输入框中，按上、下方向键可能会寻回历史输入，替换编辑器中当前显示的内容。希望用方向键编辑文本的用户需要一个关闭此快捷操作的入口。

## 设计

在 Web Shell **设置 → 界面**中添加**用上下键寻回历史消息**开关。选择会保存在当前浏览器中，刷新页面后仍然生效。没有保存过的偏好时默认开启。切换后在当前 Web Shell 中立即生效。

普通会话、分屏和托管会话的 Web Shell 输入框都会读取此偏好。关闭开关后，上、下方向键仍可移动光标和导航补全菜单。Shell 命令历史、主动搜索历史消息和移动端输入历史列表仍可使用。

## 验收标准

- 默认设置下，按上方向键可寻回历史输入，按下方向键可恢复草稿。
- 关闭开关后，上、下方向键保留草稿内容。刷新后仍处于关闭状态，重新开启即可恢复方向键寻回。
- 上、下方向键仍可移动光标和导航补全菜单。主动搜索历史输入和移动端输入历史列表仍可寻回历史输入。
