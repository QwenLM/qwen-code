# Web Shell 工具文件预览

[English](web-shell-tool-file-preview.md) | [简体中文](web-shell-tool-file-preview.zh-CN.md)

## 问题与范围

展开后的文件工具卡片会显示读取结果或编辑 diff，但无法在会话旁打开完整的当前文件。
为读取、编辑、写入、display_image 和 zoom_image 工具增加靠右的“查看文件”或“查看图片”操作。
复用现有右侧面板与文件、图片渲染器，无需修改 daemon 路由或工具执行。

## 行为与约束

- 仅在交互模式的展开详情中，存在打开回调、原始文件路径、已连接的 daemon，且能唯一确定可用且受信任的工作区归属时显示操作。
- 复用已有路径提取逻辑，从参数、结构化内容或 locations 获取路径。不得解析缩短后的显示标题，也不猜测 shell 命令中的文件。
- 在展开、工具状态变化、窗口重新聚焦时检查所属工作区的文件 stat。仅普通文件显示操作；点击时再次检查。缺少路径、文件已删除、目录、工作区不可用或检查失败均静默隐藏，不弹提示、不显示占位。不开启轮询或新文件监听器。
- 复用现有工作区权限归属保护，在归属变化或卸载后丢弃过期结果；不得回退到主工作区。
- 在现有右侧面板中打开磁盘上的当前文件。历史读取结果和编辑 diff 仍保留在会话内；按钮提示说明查看的是当前文件。图片复用现有图片预览，重复打开复用已有标签页，并通过渲染器现有的版本参数刷新内容。
- 主会话、分屏和已解析的子任务详情通过现有轮次输出回调保留来源会话、工作区。无法确定工作区的旧式内联子任务行不显示入口。文档及只读导出不检查可用性，也不显示入口。
- 文件可能在检查完成后消失。仅为此工具入口启用现有附件打开逻辑中再次 stat 的静默失败，保留其他附件入口的正常报错。预览已经打开后发生的错误继续沿用渲染器现有处理。

## 实现

通过 MessageItem、ToolGroup 和 ToolLine 传递已有轮次输出打开回调。在展开卡片标题栏挂载小型 ToolFilePreviewButton。
复用 getToolFilePath、useArtifactWorkspaceTarget、共享 Button 和附件打开请求。
已有 memo 比较需涵盖回调及 locations 变化。补充对应中英文文案。
仅在附件请求及打开逻辑上增加供此入口使用的静默不可用选项。
复用文件标签时递增预览版本，并传入渲染器现有的版本参数，使活动标签重新加载修改后的文本和图片字节。

涉及区域：消息与工具渲染、现有产物路径选择器、App 中的附件打开逻辑、i18n、定向测试和本设计文档。

## 验证与验收

先使用全局 qwen CLI 确认基线没有入口，再使用本地构建 CLI 在真实浏览器中验证文本读取、编辑及图片读取。
捕获并目视检查前后截图。定向测试覆盖折叠、只读、缺少路径时隐藏，stat 失败和目录，点击时删除，过期异步操作，工作区隔离，回调传递、现有面板标签复用，以及磁盘内容变化后活动预览的刷新。
可使用模拟 daemon 浏览器测试覆盖确定性的异常条件，但须与真实文件工具验证分别说明。
运行 build、typecheck、bundle 和相关包测试。

验收标准：受支持的现存文件在正确的右侧面板打开；图片显示为图片；历史工具详情仍可查看；不可用目标不显示入口、不弹可用性错误提示；折叠工具和导出不产生后台 stat 请求。

## 未决问题

无。保持既有渲染器的格式与大小限制。文件系统变化在展开、窗口聚焦或点击时发现，不新增持续监听器。
