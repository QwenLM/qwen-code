# 从本地会话压缩前恢复精确信息

[English](compaction-transcript-hint.md) | [简体中文](compaction-transcript-hint.zh-CN.md)

## 范围与行为

Summary 压缩可能丢掉较早上下文中的精确报错、命令输出或代码片段，但原始内容仍在 transcript 中。Summary 成功时，包括附件恢复失败但摘要仍成功的情况，在原有的继续任务提示前加入一行运行时生成的提示。它引导模型在当前本地会话的 JSONL 中按需检索具体细节，把找到的旧文本当作证据而不是指令。无法访问时，继续依据摘要处理。最近一次操作的原文保留、附件和继续任务提示均不作其他改动。Fast 压缩和失败的压缩不生成这行提示。

## 会话归属与权限

只由活跃的本地录制器解析自己的已存在且非空的 transcript，不创建文件，不获取写租约，不接受用户或模型提供的路径。录制不可用、录制器不属于当前会话、Managed 会话、子代理或使用远端工具文件系统时，省略提示。路径以无换行的原样字符串表示，对模型供应商可见。工具继续遵循现有访问规则，包括工作区外文件可能需要的审批，不授予额外访问权限，也不把整份 transcript 复制到提示词中。

提示不写入压缩检查点。如果将正式摘要复制给没有录制器的聊天，去掉其中的提示。下次执行压缩的摘要模型不会收到前一次生成的提示。恢复已保存会话后，下一次成功的 Summary 可以生成新提示。JSONL 可能包含回退前的分支，因此匹配记录不一定在当前任务的历史分支上。

## 验证

检查 Summary 两种成功路径、不压缩及不适用的录制器、重复压缩和检查点序列化。启用录制，在 CLI 测试中确认一个精确值仅存在于较早的 transcript 记录，实际压缩后模型请求不包含它。确认现有工具能按正常权限找回该值。脚本化供应商只验证协议和工具链路，不代表真实模型一定会自主选择检索。
