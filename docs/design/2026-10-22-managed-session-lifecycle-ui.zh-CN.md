# Managed 会话生命周期与阅读导出

[English](2026-10-22-managed-session-lifecycle-ui.md) | [简体中文](2026-10-22-managed-session-lifecycle-ui.zh-CN.md)

## 问题与现状

Java 已负责持久化的关闭、归档、恢复归档和删除操作。Managed Web Shell 尚无这些入口，适配器丢弃了会话生命周期状态，并将归档会话混入普通历史。公开 items 已支持不可变且逐页授权的快照分页。普通 CLI 导出器读取本地私有记录，不能用于 Managed 浏览器。

## 行为与归属

关闭可靠结束会话并保留可读历史。归档接受已关闭会话；恢复归档恢复为关闭、只读的历史。删除退休会话资源，不删除共享 Workspace 文件。活动会话可通过两个顺序执行、分别幂等的命令关闭再归档。运行中的 Turn 必须显式停止；已有服务端准入保持最终权威，包括恢复阻塞状态。

现有 Managed 导航增加普通/归档视图和行/详情共享菜单。关闭、关闭并归档、删除需要确认。关闭后保持选中；归档或删除当前会话后在同一 Workspace 打开草稿。恢复归档后在普通历史选中恢复的会话。其他选择与草稿保持完整。复用有作用域的 UI primitives、portals 与本地化文案。

## 契约与恢复

WebShell 列表请求增加 `archiveState`（`unarchived`、`archived`、`all`）；省略时保持当前 `all` 行为。在 SQL keyset 分页前筛选。新 cursor 绑定筛选条件；旧 cursor 仅在 `all` 下有效。Public 列表行为保持不变。

WebShell 生命周期 capability 纳入当前 actor 权限。批量查询的可选 `lifecycleOperation` 投影提供当前未结算操作的身份、种类、状态和失败码；已结算会话省略此投影。每页因此增加一次有界批量查询：仅凭会话状态无法区分 failed 与 recovery-blocked，也无法在另一浏览器恢复操作身份。生命周期请求增加仅用于追踪的 `requestId`。同时更新 canonical OpenAPI、生成浏览器类型、路由注册和契约测试。不需要数据库结构迁移。

浏览器在提交前按 provider 身份 scope 持久保存每个会话的冻结意图。HTTP 202 表示准入，不表示完成。响应丢失时重放原 key。pending/running 继续查询；recovery-blocked 等待对账。仅明确 failed 后用户主动重试才创建新 key。关闭并归档保存两个 key 和当前阶段，刷新后继续。如果关闭成功而归档失败，明确显示已关闭及归档未完成。归档被明确拒绝且尚无已受理操作时，刷新仅恢复失败状态并等待主动重试，不能自动重新提交。切换选择不丢操作；身份变化中止旧请求。

原 Turn 的恢复证据独立于会话生命周期。单会话响应同时保留 `recovery` 和未结算的 `lifecycleOperation`；添加恢复证据不能丢失刷新后观察操作所需的身份。原生执行已就绪不能覆盖关闭或归档会话的发送能力。恢复重查不代表生命周期操作完成，也不会重新打开会话。组合契约为 1.83.0，接续恢复功能的 1.82.0。

## 阅读导出

新增读取授权的 `POST /api/agent/web-shell/v1/sessions/export/query`，将已有不可变快照分页适配为 WebShell items。捕获会话水位，最多等待 30 秒直到已发布快照覆盖水位，再仅使用该快照的 cursor。cursor 过期、水位变化或读取失败时中止导出。不能拼接不同快照或静默遗漏尾部。

HTML 与 Markdown 使用同一份公开快照数据：标题与时间、用户/助手文本、独立标注的公开思考内容片段、工具标签及已发布的结果预览，以及公开附件。当前工具投影不发布调用参数，应明确标注参数未包含在快照中；结果预览缺失时同样标注，不能暗示包含完整工具输出。不能通过读取可变工具详情或私有 journal 填补这些缺口。保留截断提示；完整 Artifact 单独下载。采用 32 MiB 预算。

HTML 为静态文档，内联 CSS、转义内容并嵌入安全的光栅图片；不执行会话脚本，不请求远程资源。

Markdown 是供其他编辑器或渲染器使用的、未做安全净化的会话源文本，保留不可信消息和工具输出中的原始 HTML 及远程图片引用。下载文件不会在 Web Shell 中渲染或执行它；允许脚本或远程请求的外部渲染器可能执行这些 HTML 或加载图片。阅读者必须使用禁用脚本和远程请求的渲染器。行/详情共享导出菜单在选择前以中英文说明两种格式的边界。需要独立文件的离线阅读保证时，应选择 HTML。

嵌入库与 React 一起从宿主解析 `react-dom/server`，保持 React 18/19 渲染器兼容。合成下载点击不能进入嵌入宿主的委托链接处理器，并在完成后释放 object URL。不导出凭证、恢复引用或内部存储地址。

## 验证与边界

覆盖生命周期菜单、权限、多页筛选、响应丢失、刷新、显式重试与等待恢复、组合操作中断及其他会话/Workspace 文件隔离。覆盖完整不可变导出分页、水位追赶、HTML 离线、注入、Unicode、代码、图片、截断结果与预算错误。验证 Markdown 原文保留及桌面/窄屏下两种语言的可见格式说明。运行前端及 Java 定向测试、build/typecheck/bundle、Maven verify 和独立 MySQL 集成测试。真实浏览器/后端证据与受控 transport 测试分开记录。

在同一变更内先实现和验证生命周期/导航，再实现和验证导出，使关闭历史的衔接可以端到端审阅。生命周期/恢复和快照/安全检查分别进行。提供 E2E 计划和同步的中英文文档。本次不包含重新打开、导入恢复、批量操作、Workspace 删除或数据库迁移。无待决产品问题。
