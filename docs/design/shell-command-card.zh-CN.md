# Shell 命令卡片

[English](shell-command-card.md) | [简体中文](shell-command-card.zh-CN.md)

运行态沿用相同布局，显示旋转状态图标与已运行时间。仅将结构化 rawOutput 中识别到的 ANSI 快照还原为带样式的文字；普通 JSON 输出保持原文，未知实时结构回退完整 JSON。结构化结果直接区分空输出与真实 `(empty)`，不检查文本内容。传入的超时放入执行详情；行数与字节数来自下文所述的实时帧快照，在传输链路投递之前保持隐藏。复制使用展示的纯文本。沿用 SDK 对仅有心跳的 ACP 事件的过滤，折叠卡片也不会丢失输出；无法识别的文本保留原文。仅当读者停留在底部附近时跟随输出更新。运行态参数预览不作为输出。当前 ACP 不转发普通实时输出，SDK 会过滤心跳元数据，因此真实命令可能一直显示“等待输出”直到完成；前端耗时依据工具开始时间，不冒充后端心跳指标。

## 问题与范围

Web Shell 重复展示工具名、描述和命令，再将面向模型的结果文本作为一个浅灰区块展示。初始展示改动由[结构化 Shell 结果](structured-shell-results.zh-CN.md)扩展；保留面向模型的输出、审批界面和其他工具行为。

## 设计

复用现有语义摘要与卡片样式。展开的 Shell 卡片保留本地化工具标题与执行状态。分类按“命令”“输出”“执行详情”排列，命令和输出默认展开，并保留清晰的 ANSI 文本样式。命令、输出和执行详情统一使用适配主题的轻底色与小圆角，不加边框。分类标题加深，分类间距为 16px。每个内容区最高 200px，超出时内部滚动；分类标题及复制按钮留在滚动区外。收起分类后只显示标题。文档导出不限制内容高度。命令和输出的标题行各放一个纯图标复制按钮，内容使用完整卡片宽度。命令复制保留原文；输出复制展示的文本，不包含 ANSI 样式。各按钮复制成功后独立短暂切换为勾号，沿用现有复制反馈。成功和失败状态配对应图标。目录、退出码和 PGID 放进原生 details。前台命令另显示明确传入的超时毫秒值，运行中也可查看；未提供时标识“使用默认值”，不推断后端配置。后台命令不展示前台超时设置。执行失败与终止信号在折叠区外保持可见；不属于错误的退出码仍可在详情中查看。

已结束的前台执行直接使用带版本的结构化 rawOutput 获取输出、状态和执行元数据，不再使用文本外壳正则解析。历史文本及未知版本保留原始回退文本，不猜测元数据。退出状态未知时标识“已完成”，不能显示成功。运行和取消状态保留原有生命周期含义。文档导出模式展开折叠区，保证内容可见。

## 文件与决策

调整 ToolGroup，增加专用 ShellToolOutput 组件和测试，复用 ToolChrome CSS、共享 Button、剪贴板工具和复制反馈 hook。增加中英文标签，使用现有模拟 daemon 的浏览器测试框架补充回归测试。不增加依赖。配套结构化结果设计覆盖生产端和传输链路改动。

## 验证与验收

验证成功输出与元数据分离，命令在展开主体中只出现一次。覆盖非零退出、错误、信号、多行命令、原文回退、空输出、ANSI、复制和文档展示。使用全局 CLI 验证基线，并通过模拟 daemon 的浏览器测试验证展示；浏览器测试不代表真实命令执行验证。执行 build、typecheck、针对性测试和两轮无新增问题的自审。

## 风险与开放问题

历史记录没有结构化元数据，保留原文。这可能继续显示较多信息，但避免从命令输出猜测字段。无待定产品决策。

Shell outcome 沿用现有退出错误策略：grep/rg/diff/test 的退出码 1 表示已完成但结果为否，不属于执行失败。Web Shell 遵循结构化 outcome，数字退出码仍显示在详情里。PostToolUse 和 PostToolBatch 通过共享归一化保持字符串展示字段；UI/历史继续保留结构化数据。运行耗时显示在状态旁，默认可见。

导出文档仅有旧格式文本时，展示命令与完整回退文本，不显示分类折叠区或推断执行元数据。结构化目录值为解析后的实际执行路径。取消、超时和信号终止的命令不展示退出码，仍展示其状态与信号。
