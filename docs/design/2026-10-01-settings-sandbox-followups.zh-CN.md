## 问题与当前状态

PR #13119 已使设置替换具备原子性。剩余启动路径对损坏的 operator 设置报错不一致，布尔参数解析会丢失具名沙箱选择，而恢复元数据仍指向 User 设置，尽管现在只有 Workspace 设置可能恢复。沙箱命令等待背压，却可能在最后一次缓冲写入完成前退出。两种后端的 relay 都会提前读取共享普通文件 stdin，并可能在 payload 结束后继续阻塞于闲置命名 FIFO。

## 目标与范围

保留 operator 策略，提供可操作的拒绝信息，报告实际边界，并保持普通命令的输入输出语义。保留现有沙箱策略和原子发布算法。补充 BOM 重新加载、私有保存目录事件与失败、原生 Windows 替换的回归覆盖。这是缺陷修复，不增加沙箱配置接口。

## 设计

Operator 读取和解析失败使用现有致命配置错误契约（退出码 52）。入口只报告一次错误，不输出堆栈或参数帮助。修复说明指出原文件；User 保留副本不代表允许清空 operator 设置。Workspace 恢复保持独立，通过精确匹配的 Workspace 路径将元数据传递给重启流程和现有对话框。快照和保留损坏文件的调用方仍遵守原有拒绝语义。

在 yargs 布尔转换前规范化显式沙箱选择，遇到 `--` 停止。保留裸布尔选择和位置提示词。沙箱检查器分别报告继承的 whole-CLI 标记与工具隔离。迁移检查规范化两个环境标记。将 npm 显示为未探测，并在模型提示中加入已准入的命令网络策略。

等待 stdout 和 stderr 写入完成，包括低于背压阈值的最后一次写入。保留下游错误处理器直到完成，并维持 EPIPE 取消行为。

对普通文件和命名 FIFO，通过私有管道转发字节，不暴露宿主文件描述符。原生辅助程序监督后端：普通文件使用按位置读取，运行期间不改变共享偏移；子进程结束后，以已写字节减去私有管道中仍排队的字节推进偏移。同时轮询非阻塞 FIFO 输入与子进程结束，闲置写端不会延长退出。直接继承的匿名管道、socket 和字符设备仍属于调用方显式授予的能力。关闭网络禁止新建普通 IP 连接，不撤销已有标准流能力。

## 约束与风险

两种后端 relay 使用输入辅助程序；其他 Linux 架构保留直接继承管道/TTY 的执行能力，但没有支持的辅助程序时拒绝宿主文件类 stdin；状态传输、payload 执行证明和取消行为必须保持不变。捆绑的 Linux x64 和 arm64 辅助程序必须用固定编译器可复现地构建。普通文件偏移统计针对操作系统描述符已消费的字节，不针对应用层解析器消费量。不支持多个并发读者共享 stdin 的偏移统计。不得隐式授予 linked worktree 外部 Git 元数据的写权限。后端探测成功说明已准入，不保证每种 TMPDIR 或环境设置下完整会话都可运行。

## 验证与验收

使用隔离的全局 CLI 作为基线，再用构建后的 CLI 重复交互、headless、MCP、serve 和 ACP 启动测试。要求只输出一次可操作拒绝、非零退出，损坏的 operator 文件不变。覆盖具名参数、别名、布尔参数与 `--` 后的字面量；BOM 重新加载与 Workspace 恢复；真实慢速管道中的 stdout/stderr 尾部字节；下游关闭；普通文件零读取与部分读取；写端仍打开时 FIFO 退出；已连接描述符继承；原生 Windows 共享冲突时原文件保留。Linux 内核边界测试与假后端传输测试分开执行。必须完成构建、类型检查、定向单测、独立验证和评审。平台测试只有在对应平台执行后才算已验证。
