## 独立发现与关联

每个实际列 predicate 都独立以 OR 发现所有状态。这是待实现查询契约，不是可执行/已 qualified SQL。宽候选不授权成员关系：核完整原身份或证明其他 owner。错误 tenant/workspace/hash/binding/generation/harness/parent、缺失/不可解析关联、overflow/page gap 保持 BLOCKED。

不能 INNER JOIN、只筛 ACTIVE/accepted/latest 或只用已找到 parent ID 删除候选。独立枚举 part/ref/publication child/ACK/recovery work/secondary ledger。JSON-only 关联须独立有界分页完整 field/table/tenant，并严格完整解析；substring matching 仅用于发现。

automation command/channel delivery 无 Session 列：独立有界 tenant 分页，以完整 schedule/result/request 或 claim/native-record/resource 所有权证明其他归属；未明 orphan 为 BLOCKED。共享 definition/default/grant/tenant parent 和同 Workspace 的 channel 配置不能自动当原 work。

使用下表最终 PK keyset 排序；原 V12 切换后 RuntimeSession=(scope_key,runtime_session_id)，execution=execution_call_id_hash。同 Connection 重查完整当前成员/bytes。排序 FOR UPDATE 本身不证明 phantom exclusion/空集插入 fence；明确行/分页/总 byte 上限、binary identity 和 overflow 行为须实际实现/RC/RR qualification。

## 必要 prefix 与真实 producer gate

P=broker tenant placement，R=retention tenant，G=当前 TRUE 私有 predicate（generated profile OR retained runtime_request_key），不是缓存 profile。generic G 拒绝 private；native consumer 核原 persisted pin/progress，不用 G 授权。

待 qualified 的必要 cut prefix：P→R→按 request_key 的全部 slot→按 request_key/binding_id 的全部 binding→索引上的当前 private pin/context→registration→physical holder→不可变 intent→同 intent progress；随后完整 head/journal/resource/ref→RuntimeSession 成员→execution→其余明确表按固定声明表/key 顺序。无独立 activation 表。这是待实现义务，不声称全部当前 producer 已遵守。

把活动原 Connection 和已验证 authority/progress 传给窄 consumer；仅 same DataSource 不够。cut 锁内不得 nested transaction/REQUIRES_NEW，不得持后代 B/head 后补 P/R，不得 RPC/物理 IO。若 fence control 字段，binding-only claim/renew/release 必须 B 前取新 prefix。每个可能阻塞锁组后和修改前重查新鲜 sameConnection DB time、固定 deadline、精确 identity/version/stage/head/resource 成员。

FROZEN 关闭 fresh native renew/resource/recovery/commit/read/execution/control 写入。唯一 pre-cut terminal 例外消费持久化精确完整 frozen request 和原完整 predecessor。postcut exact retry 在 live assertion/acquire/renew 前走 persisted 只读观察；terminal 历史验证不能原样复用 active-only NativeHead。空集需真实 accepted producer fence/qualified range；不能虚造 unsupported 行或从 any-row 拒绝推导物理 IO join。
