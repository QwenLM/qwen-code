# Web Shell 响应速率

[English](./2026-10-15-web-shell-response-speed.md)

## 问题

Issue #14226：Web Shell 设置页已有 `ui.showResponseTokensPerSecond`，但流式状态没有读取该设置。

## 设计

从现有 Web Shell 设置资源读取 App 当前的有效偏好，统一应用于单会话状态和所有分屏面板，默认关闭。每个状态组件使用自身已有的输出 token 估算值和当前轮次计时，以 `t/s` 显示平均速率，沿用终端的舍入规则。仅在正在接收响应内容且耗时大于零时显示；空闲、等待及设置关闭时隐藏。不增加设置项或后端字段。

## 验证

检查开关、低速和高速格式、等待和空闲状态，以及新一轮的计时。通过 Web Shell 浏览器夹具验证从真实设置到显示的路径，包括分屏。在基线和候选代码上运行相同的开启场景，确认基线缺少指标而候选显示指标。

## 限制

数值基于已有 token 估算和整轮耗时，不代表服务端上报的瞬时生成速度。设置沿用 Web Shell 已有的工作空间及用户有效值解析。
