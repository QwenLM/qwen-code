# 短终端中的技能对话框

[English](short-skills-dialog.md) | [简体中文](short-skills-dialog.zh-CN.md)

## 决策

搜索同时包含可在工作区切换的技能和锁定技能。bare 模式保留隐藏的查询，但筛选和键盘操作忽略该查询。

对话框优先为框架和可操作行分配高度预算。剩余行用于只读的锁定匹配区域，包括标题和必要的间距。计数说明未能显示的锁定匹配数；它属于总数或匹配数的一部分，不是额外的技能数。有副标题时在那里显示计数；bare 模式使用剩余的列表行。如果没有可操作技能匹配，且预算不足以显示锁定明细，列表显示一行锁定匹配计数。

没有高度限制时，显示所有匹配的锁定技能。锁定判断及原因使用共享设置逻辑，包括扩展的原始名称和无法在此切换的工作区限制。

## 不变量

- 有高度限制的对话框渲染行数不超过给定预算。
- 存在匹配的可操作项时，至少显示一行。
- 锁定项匹配时不会错误地显示无匹配提示。
- 只读区域中的锁定技能无法切换或选取。
- bare 模式保留隐藏查询，扩展高度后恢复搜索。
