## 1. 总体结果与基线

**相对固定主干快照，Core 测试代码从 673,272 行降至 449,685 行，
累计减少 223,587 行（33.21%），Core 生产实现保持不变。**

| 指标                                    |   主干快照 |   最终候选 |                  变化 |

| S1：测试行数，含辅助代码、快照、fixture |    673,272 |    449,685 |   −223,587（−33.21%） |
| S2：同一文件集合的字节数                | 23,538,737 | 16,307,779 | −7,230,958（−30.72%） |
| 可运行测试源文件                        |        812 |        662 |                  −150 |
| Core 生产代码行数                       |    400,027 |    400,027 |                     0 |
| 测试／生产代码行数比                    |       1.68 |       1.12 |                 −0.56 |

版本口径固定为：

- **总体基线**：主干快照 `9e60263fdeff8cb5bf5fc49287a2d20cef0dbe2e`。
- **最终测试代码**：`460151af0c6ec2a19d7a4d736aadda023a696527`。
- **最后一组能力实验的基线**：`a270907e5f3fd6ebe26ef7d17ea7da3e92c2773a`，
  此时前期压缩已完成，S1 为 490,301；其后减少的 40,616 行是总收益的一部分。

S1/S2 已用同一份 `size.mjs` 在上述主干与最终提交的干净 Core 目录重新测量。
Git 对比中 Core 共改变 555 个测试或辅助文件，增加 147,244 行、删除
370,831 行；所有非测试 Core 路径保持不变。可复核数值、Git tree 标识、
工具哈希和阶段引用见[机器结果](../../scripts/test-loc/evidence/final/results.json)。

原始 417 个提交基于更早的 `ab61e04161`，当时是 659,618 → 477,908 行。
本结果已整合到上述主干并保留期间新增的上游测试；总体百分比统一使用
673,272 作为分母。最初 Core 至少减量 40% 的探索目标仍未达到。

## 3. 放宽标准的实验结果

最后一组采用明确预算：历史故障检出保留；固定样本中原有 Killed mutant
损失不超过 1%；原有已覆盖行损失不超过固定可检测行分母的 0.5 个百分点。
新增检出和新增覆盖均不抵扣损失。安全、权限、数据完整性检查接受单独审查。

以下候选均相对 `a270907e`，行覆盖分母为 257,159。

| 候选                       |     剩余 S1 |   本组减量 | 已覆盖行损失，百分点 | 结论                                          |
| -------------------------- | ----------: | ---------: | -------------------: | --------------------------------------------- |
| 历史检出关系引导的探索候选 |     445,134 |     45,167 |               0.3982 | 用于形成最终方案；当时 C1/C2 仅有历史关系预测 |
| 约 5 万行删减              |     440,160 |     50,141 |               0.4577 | 2 个新增全套失败；未采纳                      |
| 约 10 万行删减             |     390,249 |    100,052 |               3.1094 | 超出覆盖预算；未采纳                          |
| 约 15 万行删减             |     339,088 |    151,213 |              10.5285 | 超出覆盖预算；未采纳                          |

探索数据见[删减规模实验](../../scripts/test-loc/evidence/round7/results.json)。
各探索候选为替代方案，减量不相加；它们也未完成独立 C1/C2 配对验证。

一个决定方法选择的结果是：早期候选保留了训练语料的全部 95 个故障检出，
却漏掉后来加入的全部 8 个故障；用量计费的行覆盖不变，但损失了 10/32
个原有 mutant 检出。因此最终方案补回相关回归测试，并实际回放验证。
这 8 个样本随后成为修复依据，最终检出结果属于已观察样本上的修复验证。

### 4.2 最终候选的检出能力

- **C1**：95 条训练观测由 10 条最终候选新回放和 85 条经执行范围、源码哈希
  核对后的复用观测组成。补充 8 条由首轮 7 条和超时后单独补测的 1 条组成。
  两条历史故障同时产生收集错误，其检出依据是另外实际执行的新失败断言；
  原始收集诊断与超时记录均保留。
- **C2**：用量计费 32/32、工作流预算 77/77、XML 恢复 147/147、文件缓存
  129/129 个原有 Killed 得到保留；XML 另新增 6 个 kill。文件缓存基线的
  2 个 Timeout 保持未确定，排除在原有 Killed 和新增检出之外；有界损失预算
  通过，严格全样本比较仍未通过。
- **C2 范围**：四个完整生产模块、全部算子及静态 mutation。XML 与文件缓存
  使用修订后的函数覆盖关联测试范围；XML 原完整导入关联范围保持未完成，
  另三个预选模块未执行。

在 Linux arm64 VM 上停止能力测量负载后，以相同配置、每侧 2 个 worker
顺序执行 Core 原生全套与 V8 覆盖。对照仍为 `a270907e → 460151af`。

| 版本     | 测试文件 |   通过 | 失败 | 待执行 |

| 本组基线 |      812 | 31,164 |    1 |     10 |
| 最终候选 |      662 | 28,256 |    1 |      3 |

两侧的唯一失败均为
`dryRunGitWorktreePrune counts any link in the admin directory against the prune`。
新增失败、保留用例新增待执行、收集错误、执行异常和预期之外的用例清单变化
均为 0。原始套件健康状态保留为 false。34 个相关文件的 271 个定向用例、
build、typecheck 和 ESLint 均通过；最终源码完成两轮无新问题的审查。

### 4.4 已接受的代价

- 最后一组原有覆盖损失 782 行，新增 1 行单列。局部损失包括
  memory discovery 的 43/428（10.05%）和流式工具调用解析的
  34/339（10.03%）；包级预算仍需结合局部检查解读。
- 精确匹配的 V8 分支中有 415 个失去覆盖，另有 897 个结构变化和
  119 组重复位置；分支分母改变，无法据此宣称分支覆盖保留。
- **C4 诊断**：主干到结构压缩的回放保持中位 1 个失败文件、4 个失败用例，
  82/92 个检出故障在同名相邻测试中失败。Schema 合并的一个故障失败标签
  从 50 降至 31；较早的失败可能遮住后续断言。最终删除阶段没有新的全包
  C4 汇总。
- 部分输出格式、诊断、错误输入，以及召回质量和扫描延迟评测已删减。
- 最终候选未测 A/A 覆盖波动或重复运行时间收益；跳过的平台与真实模型用例
  在本次 Linux 观测范围之外。早期阶段的未定因间歇失败仍在归档中。

从包含上述提交的本任务 checkout 执行以下命令，可独立复现总体规模；
临时目录由 Git worktree 管理，测量无需安装依赖：

```sh
testloc_root=$(git rev-parse --show-toplevel)
testloc_repro=$(mktemp -d)
git worktree add --detach "$testloc_repro/main" \
  9e60263fdeff8cb5bf5fc49287a2d20cef0dbe2e
git worktree add --detach "$testloc_repro/final" \
  460151af0c6ec2a19d7a4d736aadda023a696527
node "$testloc_root/scripts/test-loc/size.mjs" \
  "$testloc_repro/main" packages/core --json
node "$testloc_root/scripts/test-loc/size.mjs" \
  "$testloc_repro/final" packages/core --json
git diff --stat 9e60263fdeff8cb5bf5fc49287a2d20cef0dbe2e \
  460151af0c6ec2a19d7a4d736aadda023a696527 -- packages/core
git worktree remove "$testloc_repro/main"
git worktree remove "$testloc_repro/final"
rmdir "$testloc_repro"
```

完整能力复现需要各阶段清单和原始报告。Git 内保存压缩计划、结果摘要、
manifest 与哈希；较大的原始报告位于忽略目录
`.qwen/testloc-evidence/{historical,round5,round6,round7,round8}-raw.tar.gz`，
移交任务时需要一并携带。各阶段 README 给出解包、路径映射及比较命令。

## 6. 最终结论

本任务交付了一版累计减少 **33.21%** 测试代码、保持 Core 生产实现不变的
候选，以及可复核的设计、工具和分阶段证据。结构压缩贡献主要收益；放宽
用例与覆盖标准后，进一步采纳了 **40,616 行**有明确代价的删减。

现有证据支持这个候选在所述预算和样本范围内的采纳决策。最大可删规模、
Core 40% 减量目标以及主干到最终版本的完整能力配对测量仍是后续工作。
