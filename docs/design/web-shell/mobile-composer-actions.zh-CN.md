# 移动端输入框操作

[English](mobile-composer-actions.md) | [简体中文](mobile-composer-actions.zh-CN.md)

## 问题与范围

触屏输入框展示最多 18 个操作和 6 个键盘按键组成的网格。
多个操作与导航、设置重复；Tab 在 textarea 路径中不执行任何动作。
运行中的会话只要有草稿，停止按钮就会消失。按钮偏小，添加菜单的横向子菜单也不适合手机。

本次仅修改 Web Shell UI。桌面编辑、daemon 路由、权限、附件限制及宿主工具栏开关
保持现有约定。移动端沿用触屏 textarea 的判定，包括 URL 覆盖；窄桌面窗口继续使用桌面编辑。

## 设计

### 工具栏与编辑

移除旧的 18 项触屏操作网格和模拟 Tab、Esc 按键，在输入框上方保留常驻单行的 6 个编辑
快捷键：向上（`↑`）、向下（`↓`）、向右 / 采纳建议（`→`）、输入斜杠（`/`）、收起键盘与
展开编辑。底部工具栏保留添加、模型、审批、语音输入及发送控件；触屏下隐藏宽度切换，
保留宿主启用的上下文占用控件。

工作区与 Git 控件按输入框容器宽度三档自适应，确保顶部编辑行绝不折成两行：

- **宽档（`≥ 560px`，iPad 横屏/宽分屏、手机横屏）**：工作区选择与完整 Git 控件
  保留在顶部单行左侧，长名称单行省略，与右侧 6 个编辑键同行展示。
- **中档（`420px–559px`，iPad 窄分屏、折叠屏）**：工作区选择保留在顶部左侧并短截断，
  Git 控件切换为紧凑图标态，与 6 个编辑键继续保持单行。
- **窄档（`< 420px`，手机竖屏、iPad 侧拉窄屏）**：顶部编辑行专供 6 个编辑快捷键
  （左侧 `↑ ↓ → /`，右侧收起键盘与展开编辑）。当 `contextChipPlacement` 非 `header`
  （如新会话页）时，工作区与 Git 移至输入框外侧下方单行不换行条，在失焦时展示（分支选择
  弹层打开期间保持挂载）、聚焦弹出软键盘时自动收起；当 `contextChipPlacement` 为
  `header`（已有会话页）时，不再在输入框下方重复展示工作区。宽度 `≤ 320px` 时下方条自动
  折叠文字标签，保留图标与冲突状态点。

宽档/中档保留内联上下文行实测高度对输入框高度上限的补偿；上下文控件与编辑控件不重叠，
并保留宿主自定义工具栏插槽。

底部工具栏维持 44px 触摸区域，模型与模式按钮允许省略截断以避免长模型名提前导致底部折行；
顶部单行编辑条视觉高度收紧为 36px，并通过 `::before` 透明扩展热区维持触控友好度。
工具栏图标在触控区域内居中，移除移动端工具栏各组内部的额外间距（包括上下文占用按钮）。
Plan 保持开启状态标签；任务运行时，有草稿也同时提供停止和发送，停止不清空草稿。
语音录制继续使用现有精简工具栏，并隐藏上下文行与编辑操作行。

顶部编辑行在所有宽度下保持严格单行（`flex-wrap: nowrap`），在 240px 极窄视口下
自动等比收窄且不引发整页横向溢出，开启 Shell 模式时退出按钮与 6 键继续同行显示。
收起键盘保留尾端占位，聚焦变化不引发按钮位置跳动，点击只取消聚焦、不被输入框外壳点击处理
重新聚焦。宿主未启用 Add 时保留历史与 Shell 兜底入口。展开编辑通过模态界面编辑同一受控
草稿，返回时保留选区，关闭不发送消息。完成和键盘控件使用触摸尺寸。Shell 模式有明确退出
操作。切换会话、工作区或禁用输入时关闭展开编辑。

### 触屏添加菜单

保留桌面下拉菜单。触屏使用共享的、支持 portal 的底部 Drawer，
一次只显示一页，提供返回和关闭按钮。复用已有搜索源、可用性判断、附件去向、
技能前置插入和会话/工作区失效处理。

明确提供照片、拍照、消息文件附件、上传到工作区操作。
照片选择器只接受图片；拍照请求后置摄像头。取消系统文件选择保留草稿。
系统选择器如何呈现拍照由浏览器和设备支持决定。

文件引用、扩展、MCP server 引用和技能使用可滚动的独立页面。
文件搜索仍覆盖整个工作区。Plan 保持勾选行。
增加输入历史和可搜索命令页：选择命令会将调用文本前置到现有草稿，供用户检查，
不自动执行。Shell、Goal 及低频会话命令仍可用，不再占独立快捷按钮，也不覆盖草稿。
带文字的实时语音入口移入抽屉，通话进行时工具栏仍显示状态入口。

## 实现与约束

涉及 ChatEditor、AddMenu、对应 CSS 和测试、Git 浮层尺寸、共享粘贴处理、LiveVoiceButton 及中英文文案。
复用现有 Dialog、Drawer 和 Web Shell portal root，不新增依赖或公开自定义 API。
添加控件仍由宿主显式开启。宿主显式开启命令按钮时，移动端在非 Shell 模式仍可打开命令选择器。
未启用 Add 的宿主在编辑操作行保留 Shell 和历史搜索入口；该兜底不会启用文件接收或引用。

历史搜索必须有可见关闭操作，并能通过触摸使用。
面板从输入框向上展开，高度同时受输入框与可见聊天区域顶部之间的空间限制；连最小高度都放不下时，
面板覆盖输入框顶部，而不是钻到标题栏下面。软键盘打开时，搜索框和关闭操作仍在屏幕内。
同一定位规则也适用于桌面历史搜索：窗口较矮、输入框上方空间不足时，面板覆盖输入框顶部，
确保搜索框可见。桌面编辑和键盘快捷键保持现有行为。
上界是所有裁剪溢出内容的祖先中位置最低的顶边。若宿主自己的标题栏覆盖在 shell 之上但并不裁剪它，
宿主必须声明 `--web-shell-popover-safe-top`；该变量也是宿主选择退出默认净空的途径，
显式声明的 `0px` 会被保留，而不会被当成未声明。
文件选择必须由用户手势直接触发，延迟插入必须在抽屉释放焦点后执行。
展开编辑使用共享输入状态，保留附件和引用，兼容输入法组合输入。
图片和文件粘贴复用现有接收通道；长文本粘贴根据当前编辑器选区判断是否折叠为附件。

展开框挂载期间，所有外部文本插入与聚焦都使用展开框。对话框保留输入提示及移动端文本属性，
显示共享附件/图片数量；关闭后恢复焦点时不抢占新打开的审批对话框。关闭空闲实时语音时返回 Add。

命令页复用共享补全的标签、分区、优先级、参数提示和子命令结果（最多 50 条），
归一化前导斜杠和首尾空白，并保留按描述搜索的兜底。滚动时搜索框保持可见。
Shell 模式不提供命令和技能；技能目录加载完成后才能播报空目录。

## 验证与验收

先尝试全局 qwen CLI 基线，再使用仓库浏览器夹具进行确定性 UI 验证。
可用时验证本地打包 UI。实际运行环境限制与模拟浏览器结果分别记录。

- 手机宽度下不再显示旧 18 项操作网格和模拟 Tab/Esc 按键；顶部编辑行保持严格单行
  6 个常驻快捷键（`↑`、`↓`、`→`、`/`、收起键盘、展开编辑），窄屏（`< 420px`）下工作区与
  Git 在失焦时移至输入框下方单行条（已有会话不重复展示工作区），中档（`420px–559px`）与
  宽档（`≥ 560px`）iPad 宽度下保留在顶部同行。工具栏可达且无横向溢出，桌面工具栏行为保持。
- 在较矮桌面窗口（1280x300）中，Ctrl+R 打开后搜索框保持可见并获得焦点，必要时面板覆盖输入框。
  Escape 保留草稿并将焦点交还编辑器。空间充足时，面板仍位于输入框上方。
- 在 Pixel 7 键盘高度（约 412x450）下打开软键盘且显示上下文行时，附件仍可达；
  历史搜索框和关闭操作在标题栏下方可达。视口高度低于约 430px 时，输入框已达到
  高度上限，附件条会被压缩成一条细缝。
- 存在草稿时仍可停止，且草稿保留；发送仍可排队。
- 收起键盘取消聚焦；展开、编辑、完成保留文本、选区、附件和引用。
  切换会话不会泄漏展开草稿。
- 抽屉支持点击、返回、关闭；照片、拍照、文件使用正确去向；取消不影响文本。
  搜索错误和禁用状态准确呈现，Plan 每次仅切换一次。
- 命令和技能保留原有草稿与标签；历史可打开、选择、关闭；实时语音仍可达。
- 历史搜索可恢复选中的输入和草稿焦点，不自动发送。在 1024px、480px、390px、345px、
  320px、310px 和 240px 宽度下，6 个常驻编辑键均严格保持单行且留在视口内，无整页横向溢出。
- 运行定向单元和浏览器测试、构建、类型检查、打包，再完成两轮干净自审和独立审查。
