# 移动端输入框操作

[English](mobile-composer-actions.md) | [简体中文](mobile-composer-actions.zh-CN.md)

## 问题与范围

触屏输入框展示最多 18 个操作和 6 个键盘按键组成的网格。
多个操作与导航、设置重复；Tab 在 textarea 路径中不执行任何动作。
运行中的会话只要有草稿，停止按钮就会消失。按钮偏小，添加菜单的横向子菜单也不适合手机。

本次仅修改 Web Shell UI。桌面编辑、daemon 路由、权限、附件限制及宿主工具栏开关
保持现有约定。移动端沿用触屏 textarea 的判定，包括 URL 覆盖；窄桌面窗口继续使用桌面编辑。

## 设计

### 工具栏与编辑

移除旧触屏操作网格和模拟键盘按键。保留添加、模型、审批、语音输入及发送控件。
触屏下隐藏宽度切换和重复的上下文控件。工作区选择和 Git 控件放到独立上下文行，
保留在指定工作区、分支中开始任务的能力。保留宿主自定义工具栏插槽。

触摸区域为 44px；极窄视口允许换行，不裁剪控件。Plan 保持开启状态标签。
任务运行时，有草稿也同时提供停止和发送；停止不清空草稿。
语音录制继续使用现有精简工具栏。

增加小型编辑操作行，提供展开和输入框聚焦时的收起键盘按钮。
收起键盘只取消聚焦，不被输入框外壳点击处理重新聚焦。
展开编辑通过模态界面编辑同一受控草稿，返回时保留选区，关闭不发送消息。
完成和键盘控件使用触摸尺寸。Shell 模式有明确退出操作。
切换会话、工作区或禁用输入时关闭展开编辑。

### 触屏添加菜单

保留桌面下拉菜单。触屏使用共享的、支持 portal 的底部 Drawer，
一次只显示一页，提供返回和关闭按钮。复用已有搜索源、可用性判断、附件去向、
技能前置插入和会话/工作区失效处理。

明确提供照片、拍照、消息文件附件、上传到工作区操作。
照片选择器只接受图片；拍照请求后置摄像头。取消系统文件选择保留草稿。
系统选择器如何呈现拍照由浏览器和设备支持决定。

文件引用、扩展、MCP server 引用和技能使用可滚动的独立页面。
文件搜索仍覆盖整个工作区。Plan 保持勾选行。
增加输入历史和可搜索命令页：选择命令会将调用文本前置到现有草稿，供用户检查，
不自动执行。Shell、Goal 及低频会话命令仍可用，不再占独立快捷按钮，也不覆盖草稿。
带文字的实时语音入口移入抽屉，通话进行时工具栏仍显示状态入口。

## 实现与约束

涉及 ChatEditor、AddMenu、对应 CSS 和测试、Git 浮层尺寸、共享粘贴处理、LiveVoiceButton 及中英文文案。
复用现有 Dialog、Drawer 和 Web Shell portal root，不新增依赖或公开自定义 API。
添加控件仍由宿主显式开启。宿主显式开启命令按钮时，移动端仍可打开命令选择器。

历史搜索必须有可见关闭操作，并能通过触摸使用。
文件选择必须由用户手势直接触发，延迟插入必须在抽屉释放焦点后执行。
展开编辑使用共享输入状态，保留附件和引用，兼容输入法组合输入。
图片和文件粘贴复用现有接收通道；长文本粘贴根据当前编辑器选区判断是否折叠为附件。

## 验证与验收

先尝试全局 qwen CLI 基线，再使用仓库浏览器夹具进行确定性 UI 验证。
可用时验证本地打包 UI。实际运行环境限制与模拟浏览器结果分别记录。

- 手机宽度下不再显示旧操作网格和键盘按键；工具栏可达且无横向溢出。桌面行为保持。
- 存在草稿时仍可停止，且草稿保留；发送仍可排队。
- 收起键盘取消聚焦；展开、编辑、完成保留文本、选区、附件和引用。
  切换会话不会泄漏展开草稿。
- 抽屉支持点击、返回、关闭；照片、拍照、文件使用正确去向；取消不影响文本。
  搜索错误和禁用状态准确呈现，Plan 每次仅切换一次。
- 命令和技能保留原有草稿与标签；历史可打开、选择、关闭；实时语音仍可达。
- 运行定向单元和浏览器测试、构建、类型检查、打包，再完成两轮干净自审和独立审查。
