# 浏览器通知内容与会话导航

[English](web-shell-browser-notification-details.md) | [简体中文](web-shell-browser-notification-details.zh-CN.md)

基础版合入 #11398 后，本次增强让用户直接辨认通知对应的会话、查看本轮回复摘录，并点击返回对应会话。浏览器开关、权限、后台触发和去重规则沿用基础版，不增加 daemon 路由或公共 SDK 字段。

## 内容与图标

标题显示 QwenCode · 会话标题。新会话标题尚未生成或已清空时，使用本轮问题首行；两者均缺失时显示 QwenCode。正文保留回合状态，完成时附本轮最后一段主助手回复的纯文本摘录，不额外调用模型生成摘要。摘录严格匹配终态 promptId，排除工具、思考、后台子代理和内部 insight 消息；无匹配文本时不借用旧轮回复，失败时不展示部分回复或错误详情。

提取发生在 live/replay transcript 投影完成后。标题使用所属 session 的状态及 owner 匹配的 connection 元数据。主聊天会抑制本人 user SSE 回显，本地 optimistic user block 不一定带 promptId，因此观察器通过已有 admission 的 promptId/label 保存标题兜底，live pending 启动事件也可提供该文本。标签仅保留在未结束回合的内存 Map，消费、移除或最后观察者退出时清理。

正文同时包含本轮用户提问，在状态之后使用本地化的“提问”和“回复”标签。独立于会话标题，提取与终态 promptId 匹配的第一段非空主用户文本。本地 optimistic block 没有 promptId 时，在 pending Map 中保留完整的已有 admission label（或 live pending 事件文本）作为兜底，只有标题兜底取其首行。不借用其他轮次的提问，也不将会话标题当作提问。失败时可附提问，但不包含部分回复或错误详情。提问或回复缺失时省略对应行。

标题最多保留 60 个 Unicode 码点，提问摘录最多 80 个，回复摘录最多 120 个，超长时以省略号结尾。摘录移除常见 Markdown 格式、链接地址和 HTML 标记并合并空白，截断不拆开 Unicode 码点。不增加配置或模型调用。浏览器或系统布局可能进一步截短整体正文。

通知携带项目现有 128×128 PNG 标志的本包副本，由 Vite 解析和打包图片 URL。标题与正文不额外拼接 IP、端口或跳转地址；Chrome 自带的站点来源和 macOS 上的 Chrome 标志由浏览器及系统控制，业务图标不能替换它们。通知内容可能显示在通知中心或锁屏上，设置说明告知会展示标题、提问和回复摘录。共享存储仍仅记录去重哈希，不保存正文、标题或导航目标。

## 点击打开会话

内部 owner 绑定时捕获 sessionId 和产品上下文：workspace 使用已解析 owner.workspaceCwd，standalone/live 不携带内部工作目录。目标仅保留在通知的内存闭包。点击时尝试聚焦原窗口，将显式目标传给已有 qwen:open-session 入口，再关闭通知；浏览器拒绝聚焦时仍尝试导航。

App 复用现有会话加载流程处理设置页、分屏、草稿上下文、异步导航与失败报告。没有显式上下文的旧会话链接保持原行为；畸形或冲突的显式上下文直接拒绝，不回落到当前或主工作区。目标已经是当前健康会话、上下文一致且没有待分配草稿意图时，只显示聊天并关闭面板，避免重复加载干扰下一轮。分屏通知统一打开主聊天，加载成功后既有回调同步更新地址栏。

范围限于原页面仍打开且主 App 导航监听仍挂载的情形。过期会话、已移除工作区和加载失败复用既有错误反馈，不自动创建会话或切换到另一工作区。关闭页面后的通知、Channel、Service Worker 与 Web Push 不属于本次增强。

## 验证范围

单元测试覆盖 live/replay 内容投影、admission 标题兜底、精确回合及主助手过滤、Unicode 截断、失败与空内容兜底、图标参数、捕获目标、跨工作区及 standalone/live 导航、设置页与分屏退出、同会话避免重复加载、旧链接兼容和聚焦失败。

页面验证使用独立 runtime 与 Chrome：真实提交产生终态后捕获通知，切换到另一会话并打开设置，再调用捕获通知的点击回调，检查原会话及 URL 恢复、设置退出与通知关闭。Notification stub 和模拟失焦只证明浏览器参数与导航链路，不代表 OS 横幅或图标实际展示。图标另外核对生产资源的 HTTP 状态、PNG 签名和尺寸。详细测试计划及结果记录在本地 .qwen/e2e-tests/。
