# Web Shell 高级表格控件

[English](web-shell-advanced-table-controls.md) | [简体中文](web-shell-advanced-table-controls.zh-CN.md)

## 目标

让高级 Markdown 表格符合更新后的 Web Shell 设计，同时保留单元格选择、统计、
筛选、排序、调整列宽、行详情、完整值弹框、复制和首列冻结。

## 设计

- 紧凑工具栏左侧保留行数和选区统计，选区复制紧邻统计，右侧集中放置密度、
  列自定义和可见表格复制。
- 仅通过专用表头图标排序，筛选浮层只包含筛选控件。
- 用一个基于 shadcn 的浮层管理表格列的可见性和顺序。
- 在同一浮层中独立管理行详情字段；详情字段保留源顺序，不支持拖拽。
- 同时最多展开一行，详情面板仅包含选中的详情字段。
- 重置恢复源列顺序及初始表格列、详情字段选择。
- 密度与复制使用相同的下拉菜单定位、样式和键盘交互；密度保持单选，并以勾选标记
  显示当前选项。
- 「复制」提供当前可见行和列顺序的文本（制表符分隔）与 Markdown。Markdown 保留表格结构及
  单元格字面文本，不保留行内格式和链接目标；转义 Markdown 标点和类似 HTML
  的文本，将 CRLF、CR 和 LF 编码为单元格换行。
- 工具栏宽度不超过 500px 时，复制及展开文本仅显示图标，保留可访问按钮名称。
  复制成功通过 polite 状态区域播报。
- 保留单个排序图标，通过颜色和透明度共同标识方向，避免仅依赖颜色。
- 拖选在边缘自动滚动，覆盖左侧操作列和冻结列。记录初始指针位置；仅在选择
  期间监听移动，仅在边缘可以滚动时运行动画帧。
- 保证 Shadow DOM 内工具栏菜单的键盘进入及焦点恢复可用。

## 兼容性

底层 Markdown 表格数据和公开自定义 API 不变，保留源 GFM 单元格对齐。
表格状态仍局限于 `EnhancedMarkdownTable`，复制使用共享剪贴板工具。
无需修改 daemon 或持久化。
异步 Clipboard API 不可用时仍可复制。

## 验证

- 单元测试覆盖字面 Markdown 复制、CR/LF、空单元格、筛选、隐藏列、重排列、
  复制反馈和选区清除。
- 异步 Clipboard API 不可用时，验证内联和 Shadow DOM 全屏菜单的原生兼容复制
  路径，检查实际剪贴板读回值。
- 使用模拟 daemon 的浏览器测试验证窄屏控件、非颜色排序线索、Shadow DOM
  键盘进入、静止边缘按下、经过操作列时选区增长以及释放后停止。
- 构建、类型检查并目视检查截图；更新刻意设置的构建体积警戒线前先实测
  transcript 入口及 HTML 导出渲染器大小。
