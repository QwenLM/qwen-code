# 可选的子窗口截图

[English](cua-optional-child-window-capture.md) | [简体中文](cua-optional-child-window-capture.zh-CN.md)

## 范围与基线

实现起点是 base `0ab64d5066fb467646b02a7309bc48632055d6e4`，随后变基到 main `fc4e01b9fc381952c15592ead9e0cf170754dd8d`，后者的 CUA driver 与该 base 相同。调用方可以在一次 App 或精确窗口观察中请求 `includeChildWindows: true`；省略或 false 保留 base 捕获策略。参数仅扩展视觉观察，原生 App 目标选择、AX 投影与编号、键盘路由和指针授权沿用原有行为。

此前 Freeform 实验发现，包含子窗口后，画笔色板出现在主窗口截图中且位置不变。在应用前台条件下，截图坐标点击成功。原生 AXPress 则在 SDK 之外仍然失败。这些结果不证明后台输入或所有应用的兼容性。

## 实现

在类型化观察契约中添加可选 `include_child_windows`，生成绑定，并在 Computer Use 观察选项中提供 `includeChildWindows`。封装层校验布尔值，在非 macOS 平台拒绝 true；Windows/Linux 原生请求同样明确拒绝 true。

macOS 上，true 创建一次性的 ScreenCaptureKit 显示器过滤器，限定只捕获目标窗口并开启子窗口捕获。显式源矩形按该窗口的屏幕边界裁切，输出尺寸使用同一边界和显示器比例。这样可以避免独立窗口捕获把越界的附属窗口组缩放进主窗口原有的图片大小。主窗口范围外的子窗口像素会被裁掉，因此不提供扩大的坐标画布。它不读写默认计划缓存，也不使用无法保证子窗口策略的 shell fallback。通过读回原生配置中的设置拒绝不支持的系统版本。已有附属窗口组的显示器裁剪保留默认路径；该路径下 true 报告截图不可用，因为不能承诺子窗口覆盖。新模式要求 Metal、窗口在屏幕上且完全位于单个显示器内；不支持的配置不返回图片。默认的附属窗口裁剪及无 Metal 兼容路径保持不变。

图片保留被请求窗口的坐标框架及已有尺寸/比例校验，因此默认和 true 观察复用现有坐标换算，不增加输入模式或自动重试。仅凭 PNG 尺寸不能证明内容几何正确。AppKit 越界弹窗实验已复现第一版候选将 60×60 标记缩成 41×42，却仍返回名义有效的 620×492 图片。修正后的裁切必须保留这些标记的位置和尺寸；Freeform 和窗口内弹窗的验收还要求根据刚检查过的图片实际执行一次坐标操作。

该选项不持久化。下一次观察省略它就使用 base 捕获，包括不向调用方返回图片的观察。保留已有 AX revision/token 行为。扩展截图不受支持时，保留真实 AX 数据以及已有的截图无效/不可用诊断。观察文本也会给出长度受限的失败原因并提示用 false 重试，使 App 调用方在保留 AX 操作能力的同时理解缺少图片的原因。即使辅助功能捕获同时不完整，最小 512 字符文本预算也会为该提示保留空间。失败的观察会使上一张截图失去坐标输入资格。

## 验证与验收

- 类型序列化和封装测试覆盖省略、false、true、无效值及不支持的平台；新观察保留相同的原生语义目标和输入路由。
- 默认截图保留缓存行为，扩展截图绕过该缓存。在同一个存活的 Freeform 色板上交替 true 和省略参数，检查选项没有持久化。
- 在新的候选进程中，依次默认、true、再默认截图同一 Freeform 画板/色板，保留同一窗口并记录边界、图片尺寸、AX 和实际图片。
- 根据扩展后的主窗口截图，只点击一次可见画笔色块，验证真实颜色和色板关闭。记录额外前台设置，并与普通 App 行为区分。验证 Fill 控件和关闭仍可用。
- 将 AppKit 窗口内弹窗、越界弹窗、模态 sheet 及移动/缩放后的窗口与 base 对照。检查固定像素标记、目标与 AX 控件以及明确的不支持诊断。受支持的窗口内弹窗坐标点击必须使独立的测试计数器递增。
- 构建 SDK/原生库和本地 CLI，运行定向测试及仓库构建/类型检查，审查完整差异并做独立 review。这一版不代表已完成通用无退化验收。

## 限制

只请求平台认定属于目标窗口的子窗口内容，排除无关窗口。现有坐标范围之外的内容会被裁掉。本地 Freeform/AppKit 检查不能证明 GTK 窗口组、混合 DPI、旧版 macOS/无 Metal 环境或后台弹窗输入的兼容性。不传选项的精确窗口消费者保持 base 实现。缺少环境的项目必须标为未测试；定向检查不代表完整的标准 GUI 矩阵或通用无退化保证。
