# Web Shell 回复选区复制

[English](2026-10-10-web-shell-selection-copy.md) | [简体中文](2026-10-10-web-shell-selection-copy.zh-CN.md)

## 问题与范围

回复复制目前复制整条 Markdown 原文。阅读长回复时，用户需要只复制选中内容，并明确选择可见纯文本或 Markdown。浏览器原生复制没有此选择，也可能夹带代码和表格操作控件。

本次为交互模式下单条 assistant 回复正文增加选区浮层。不改变整条回复复制、原生快捷键复制、用户消息、思考块、文档导出或移动端选区菜单。写入的是文本，不是 HTML 富文本。

## 预期行为

在单条回复内用鼠标完成选择后，在选区附近显示 **复制纯文本** / **复制 Markdown**（英文：**Copy plain text** / **Copy Markdown**）。操作浮层时保留原选区。选区清空或移到外部、正文变化、滚动、Escape、点击外部和复制成功时关闭。剪贴板写入失败时保留菜单供重试。

选区两端必须属于同一正文。从正文内开始拖选、选区仍在正文内时，即使在正文外松开鼠标也显示菜单。跨消息选择沿用浏览器行为。流式回复在结束前不显示菜单。键盘选区保留原生复制行为，不打开此菜单。触摸选择保留浏览器原生菜单。

从高级表格内开始的拖选继续使用原有矩形单元格选区、工具栏动作和原生复制快捷键，不弹出正文划词菜单。从表格周围正文开始并跨过表格的原生文本选区仍可由正文菜单复制。

## 实现与决策

复用已封装的 Radix popover、虚拟选区锚点、作用域 portal 容器和剪贴板降级助手。小组件负责选区生命周期，并在菜单聚焦改变选择前保存复制内容。在 document 捕获阶段通过事件的组合路径跟踪鼠标手势归属，支持正文外松开，也避免把 portal 菜单点击视为新选区。对 ShadowRoot 选区 API 做能力检测，拒绝正文外的 Range。

只克隆与选区相交的 DOM 节点，裁剪边界文本并保留祖先结构，使标题、粗体、列表或代码块内的局部选择仍带对应格式。明确排除代码头部、表格工具栏、操作列、隐藏占位单元格和展开行详情面板。祖先列表项自身内容未被选中时，省略其列表标记，保留选中的嵌套子项。清理后的语义树通过块前后的边界转为纯文本，通过仓库已有版本的 Turndown 转为 Markdown，并在 Web Shell 中直接声明依赖；补充 GFM 表格、任务列表勾选状态和删除线规则。Markdown 规范化语法，不承诺原文语法逐字一致。不引入源码偏移映射：渲染转换、排序和过滤后的可见表格应忠于用户实际选区。

保留代码缩进和语言，安全闭合代码围栏，转义表格竖线，将局部表格行补齐为有效 Markdown 表格。未选中表头时生成空表头，绝不补入未选中的数据。缺少标准语义 HTML 的自定义渲染器和已渲染图表只能提供 DOM 中存在的语义，还原其原始源码不在本次范围。

选中图片时，Markdown 保留图片，纯文本使用图片的替代描述。完整选中的 KaTeX 公式只提取一次已有 TeX annotation：纯文本包含表达式源码，Markdown 补上行内或块级公式分隔符。局部公式只复制选中的可见文本，不补入未选中的源码。剪贴板降级操作先聚焦所选菜单动作，并保持在其 Radix 层内，包含 ShadowRoot 内的层以及 ShadowRoot 外的宿主弹窗；失败时恢复原选区供重试。

## 影响文件

Web Shell assistant 渲染、代码/表格复制排除属性、选区菜单组件和转换工具、中英文界面文案、针对性单元与浏览器测试、包依赖和锁文件。transcript 构建使用普通正文容器替换交互式选区组件，因此导出文档入口不包含菜单与 Turndown。不涉及 daemon 或 core。

## 验证与验收

先用全局 qwen Web Shell 验证基线，再用本地构建的 Web Shell、固定模拟 daemon 回复和真实浏览器剪贴板验证。覆盖鼠标局部选区、两种复制结果、局部粗体/链接/标题/列表/代码/表格、嵌套列表子集、紧凑 DOM 块边界、键盘不触发菜单、重新选区后的菜单定位、ShadowRoot 与宿主弹窗内的真实降级复制、transcript 包体积、跨段落、重复文本、界面控件排除、关闭行为和剪贴板失败、整条回复复制、中文文案及作用域 portal 渲染。检查 React 18 兼容的 ref 路径，执行构建、类型检查、相关测试，并完整审阅两遍 diff。

只复制选中内容；Markdown 可正确解析并保留所选格式；纯文本保留合理换行；原有复制继续可用。截图仅证明模拟前端行为，不证明真实模型或 Git 操作。

## 未决问题

无。用户要求的“带格式的内容（markdown）”解释为 Markdown 文本；HTML 富文本复制是另一项功能。
