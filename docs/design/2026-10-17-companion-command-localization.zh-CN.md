# Companion 命令标题本地化

[English](2026-10-17-companion-command-localization.md) | [简体中文](2026-10-17-companion-command-localization.zh-CN.md)

## 问题与范围

Issue #13967 请求扩展 Companion 的本地化。维护者明确欢迎独立提交扩展清单的改进：十二个命令标题中九个仍硬编码英文，三个复制命令已经使用 VS Code 原生 NLS 键。

本次覆盖现有英文与简体中文语言文件中的命令标题，并确保这些语言文件进入扩展安装包。通知、配置描述、其他语言、Webview 文案、语言优先级和共享 CLI 翻译来源留待后续处理。

## 方案与约束

沿用现有 `<command>.title` 键和 `%key%` 清单引用。保持所有命令 ID、英文回退标题、菜单、快捷键及激活事件不变。VS Code 根据其显示语言解析清单 NLS，不涉及运行时翻译层或 CLI 设置。

已安装的 vsce 3.9.2 在当前白名单下列出的打包文件不包含两个语言文件。在 `.vscodeignore` 中显式放行 `package.nls*.json`，并验证实际安装包，而非只检查规则文本。

涉及 Companion 清单、两个 NLS 文件、打包白名单、现有清单测试及 VS Code 集成指南。无需修改依赖或公开 API。主要风险是语言文件缺失或键不匹配；其他语言的英文回退保持不变。无需迁移。

## 验证与验收

- 十二个命令标题引用均能解析为非空英文和简体中文文案，英文标题与基线一致。
- vsce 文件列表及生成的 VSIX 压缩包均包含两个语言文件。
- 定向清单测试保留聚焦聊天命令的语义断言和现有可见性检查。
- 尝试隔离的 VS Code 显示语言验证；若语言包或宿主不可用，明确区分真实宿主证据与安装包级检查。
- 执行仓库构建、类型检查、bundle、Companion 检查、格式检查及完整 diff 审查，明确记录未执行或受阻的检查。

Command Palette 证据：[修改前](../verification/issue-13967/before-zh.png)和[修改后](../verification/issue-13967/after-zh.png)。截图来自真实 VS Code 1.142.0 窗口，使用隔离的清单及语言文件副本和空激活模块，展示的是命令标题本地化，而非完整 Companion 激活或命令执行。
