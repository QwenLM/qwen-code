# 在助手正文底部复制 Markdown

[English](web-shell-copy-markdown.md) | [简体中文](web-shell-copy-markdown.zh-CN.md)

## 问题与范围

助手正文底部已有通用复制按钮，实际复制的是原始 Markdown。用户需要在它
旁边增加明确的 Markdown 入口，并区分两种格式：复制内容输出渲染正文的纯文本，
复制 Markdown 输出完整原始源码。保留剪贴板降级、流式输出限制和导出的会话
文档行为。最后一轮已完成回复的底部操作图标保持显示。

## 方案与决策

在 `AssistantMessage.tsx` 的复制按钮后紧接增加 Markdown M↓ 图标，使用独立的
`assistant.copyMarkdownSource` 作为本地化提示和无障碍名称，避免与选区菜单的
`assistant.copyMarkdown` 重名。第一个操作使用独立的
底部文案键，标为 Copy content / 复制内容，通过局部 Range 复用现有选区复制
序列化逻辑的纯文本入口，提取整段渲染正文，不改变用户选区。保留段落和代码换行、公式源码
及图片描述，排除控件文字和 Markdown 格式标记。第二个操作复制精确的原始
`content`。两者均通过现有剪贴板工具写入，保留 HTTP 降级和失败报告。每个按钮各用一份
`useCopiedFlash` 状态，仅被点击的按钮显示成功。复用现有底部样式，在已有底部图标
旁定义一个小型内联 SVG，不增加基础组件、依赖、公共选项或 daemon 路由。

## 验证与验收

更新 `AssistantMessage.test.tsx`，检查渲染纯文本与原始 Markdown 的不同输出、
用户局部选区保留、独立成功反馈、
本地化、定时器清理、降级和显示条件。增加聚焦的浏览器测试，使用现有模拟
daemon 验证相邻按钮、真实剪贴板内容、键盘操作并截图。此验证覆盖 UI 和
剪贴板行为，不代表真实模型或 Git 后端验证。
执行构建、类型检查、相关单元测试和浏览器 E2E。剪贴板失败必须沿用现有
警告行为，不显示成功。无待决问题。

## 最后一轮的显示

最后一轮已完成的助手回复，其内置底部操作图标无需悬停即可显示。将已有的
最终回复轮次标识与最近一个产出最终助手回答的轮次比较，通过 MessageItem
传递显示标志（包括其 memo 比较），并应用局部 CSS 类。历史轮次保留悬停和焦点显示；
发送新的用户消息后，取消上一轮底部操作栏的常显。流式输出、后台任务和文档
模式已有的显示限制仍然生效。在浏览器和聚焦的 MessageList 测试中验证多个
轮次、历史轮次悬停和下一条用户消息的切换。

## 底部 Tooltip 与新对话文案

五个图标操作（复制内容、复制 Markdown 源文、满意、不满意和新建对话）统一使用共享
Tooltip 的 provider、trigger 和 content，移除原生 title 属性，保留无障碍
名称，提示浮层通过共享组件进入 Web Shell portal root。复用原生 button
作为子节点，确保 Radix ref 在 React 18 和 19 下正常。新对话操作使用 Lucide
Split 图标，文案为 “New chat from here” / “从此处新建对话”，请求和等待中
的行为保持不变。Split 使用 13px 尺寸、2.4 线宽并顺时针旋转 90 度，与相邻图标
保持协调。验证键盘聚焦、鼠标悬停、本地化、portal 位置和现有复制及
新建对话交互。

时间戳在最新回复中也仅于悬停或聚焦时显示。触屏设备保留原有时间戳常显行为。

TooltipContent 支持传入 `variant="black"`，显示黑底白字并同步箭头颜色。省略该
属性时保留现有主题色。这五个底部提示启用黑色版本；颜色覆盖仅在提示内容内
生效，不影响其他 Tooltip 或宿主主题。验证默认/黑色两种模式的 ref 传递，
以及真实浏览器中的文字、背景和箭头颜色。

黑色版本的主体外圈和箭头描边使用同一种不透明深灰色，箭头偏移设为零，
使深色主题下也能看清边缘，并避免箭头与主体衔接时出现异色接缝。默认版本
保留原有外圈、箭头描边和偏移。除颜色功能断言外，还需检查高 DPI 局部截图。
