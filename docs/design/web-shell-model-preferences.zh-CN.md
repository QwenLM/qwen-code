# WebShell 设置中的模型默认值

[English](web-shell-model-preferences.md) | [简体中文](web-shell-model-preferences.zh-CN.md)

## 行为

在「设置 → 模型」中，可以为每个模型设置思考开关、思考强度和上下文窗口的默认值。daemon 提供可用的对话模型和各模型支持的控件。上下文窗口接受整数 token 数，并显示该模型的上限。关闭思考后保留已选强度，重新开启时可以继续使用。

用户设置和工作区设置各有草稿。工作区可以按字段覆盖用户设置，也可以按字段恢复继承。保存会先校验整批修改，然后写入变更的字段。保存失败时保留草稿。

## daemon 和设置

工作区绑定的偏好接口将设置存入 `model.preferences`，并返回生效值、字段来源和模型上限。模型标识沿用由认证类型、模型 ID 和实际端点生成的路由标识。偏好字段为 `contextWindow`、`reasoning.effort` 和可选的 `reasoning.enabled`。供应商编辑入口继续负责供应商的窗口上限。

daemon 在创建任务、恢复任务、切换模型，以及保存后的下一轮前，解析任务所选模型的当前默认值。空闲任务在保存生效后读取新默认值。正在执行的轮次使用启动时的设置。daemon 已能识别的任务显式覆盖继续优先。重开任务时从磁盘读取最新设置。更新偏好时，任务继续使用已选模型。

## 交付范围

此改动交付原生 WebShell 的设置面板。DataAgent 的初始化和重置可以保留两级设置后，宿主设置面板可以接入同一个接口。会话选择器和 `/effort` 的行为变更单独提交。

## 验证

用 200K 窗口和低强度启动任务。该任务执行中保存 128K 和高强度，验证该任务下一轮及新任务的请求。验证空闲任务读取新默认值、保存时保留已选模型，以及 daemon 重启后再次打开历史任务能读取已保存的值。核对实际供应商请求和 daemon 使用的窗口上限。在两个工作区验证按字段继承和整批校验，在桌面和窄屏浏览器验证数字输入。
