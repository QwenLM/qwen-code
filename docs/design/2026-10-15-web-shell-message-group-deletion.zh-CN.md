# Web Shell 消息组删除

[English](2026-10-15-web-shell-message-group-deletion.md) | [简体中文](2026-10-15-web-shell-message-group-deletion.zh-CN.md)

## 状态

已实现。范围为普通本地 daemon 会话；明确不支持 Managed 权威存储和 SSH 工作区。hosted harness profile 不广告消息删除能力。

## 问题与当前行为

Web Shell 无法删除指定对话轮次。回退会移除后缀并在 JSONL 中保留废弃记录，无法满足任意整组物理删除。前端本地命令还会产生临时展示消息。

## 行为

一组包括用户提问及全部回答、思考、工具调用、结果、错误和取消消息，或一次斜杠命令及对应展示输出。消息操作栏只显示复制和竖向三点入口。悬停三点展开使用共享组件和 Web Shell portal 的菜单，包含当前可用的工具调用、编辑和删除操作；移入菜单保持展开，离开入口和菜单后短暂延迟关闭。保留点击、触屏及键盘打开方式。进入删除模式默认选中当前组；消息行最左侧的 checkbox 联动整组选中或取消。用户消息保留各自的 checkbox；每组回复只在「已处理」栏左侧放一个 checkbox，没有状态栏时放在首个回复行。展开思考或工具步骤不会增加 checkbox。可以非连续选择入口前后的所有组，入口只决定默认选中组，保留未选组。选择删除模式期间，菜单中的删除消息入口保持可见但禁用。空选择禁用删除。确认操作说明历史不可恢复、摘要保留、命令效果和项目文件不变。

删除唯一组或全部组后保留会话和必要元数据。可见消息为空时，摘要上下文仍可能生效。仅允许空闲会话修改历史；服务端拒绝执行中、排队中和后台轮次。选择状态归属于会话，切换会话清除。

## 设计决策与理由

使用两个哈希：选择快照忽略迟到的指标和自动标题，避免无害的后台写入使选择失效；完整文件哈希保护原子替换，防止任何并发修改。单一哈希无法同时满足两种行为，版本计数器则要求所有现有写入者维护另一份权威状态。

归属不明确时拒绝操作，而不是仅删除可识别的片段，因为部分删除可能在保留的压缩上下文中留下原文，或破坏工具调用与结果的配对。摘要始终原样保留；删除原始消息不会撤回已经进入摘要的信息。快速压缩在摘要前缀未变化时继承已有摘要边界。

会话忙碌时拒绝删除，而不是排队。bridge 队列能串行化操作，但在运行中的轮次结束后执行旧的破坏性选择，会改变用户确认时看到的历史。会话门禁还会在替换期间阻止自动任务和后台轮次。

列举 legacy 转录时仅与当前写入串行化，不取得租约或改变写入模式。只有删除操作才升级到租约写入。telemetry 按明确的 prompt/tool 身份归属，包括迟到事件；属于已删除组的事件在替换期间及之后都会被丢弃。

快照冲突后清空选择，要求用户基于新快照重新选择，绝不自动重试删除。已持久化但上下文安装失败时，返回已删除身份及重新打开会话的要求，刷新发起客户端，并阻止旧上下文接收新工作，但释放操作锁以允许关闭。之后请求返回不含已提交标记和旧删除身份的新错误；重新打开时从 JSONL 安装最新上下文，成功后恢复准入。历史重载失败时保留未删除的已保存消息与本地命令，并明确提示删除已完成、需重载。本地命令的位置和 ID 在重新加载及加载失败时均保留。

删除后一轮时，单独保留前一轮原本的文件差异终点，不将其作为可回退轮次。保留被删快照作为轮次会使回退序号错位，直接使用下一个保留快照则会把被删轮次的修改算到前一轮。终点备份需持久化，并参与校验、备份版本分配与保留，使重启、分支、后续修改和清理后仍得到相同差异；不恢复文件，也不保留被删轮次的身份。

## 持久化与模型上下文

服务端列表返回稳定的所属记录 UUID、关联 daemon prompt ID、记录 ID，以及仅排除 system/ui_telemetry 和 titleSource=auto 的 custom_title 记录的 SHA-256 snapshot。迟到的后台统计及自动标题更新不使选择失效；原子替换仍在 writer lease 内独立校验当前完整 JSONL 的 SHA。在历史锁和 writer 锁内校验 snapshot 与完整所选组。由 lease 持有者通过临时文件原子替换，删除原始记录，沿被删祖先修复 parentUuid，不复活废弃分支；空历史也保留非消息事务锚点。同步更新 recorder 状态与后续写入证明。

全部已有摘要保持不变；删除不调用模型、不重新生成摘要。所选原文从当前上下文及 compressedHistory 的原文尾部副本中移除，包含成对工具结果，新检查点记录生成的摘要及恢复内容前缀长度，保持前缀内容不变。缺失或部分身份导致无法区分摘要与保留原文时，删除在写入前明确失败；若所选工具调用或结果副本仍处于无法归属的压缩区间，也会拒绝。因此，完全进入摘要的轮次只改变展示和持久化原文；仍参与原文上下文的轮次影响后续模型输入。保留项目文件、命令效果、模型绑定、标题、审批状态与压缩检查点。

## Runtime 与客户端集成

GET /session/:id/message-groups 和 POST /session/:id/messages/delete 为 live-session-owner 路由，不能回退到主 runtime。ACP 操作持有历史修改锁；bridge 与 prompt 串行化，在持久化和上下文更新后发布 session_messages_deleted。必须失效旧回放缓存，避免重载恢复被删消息。所有连接客户端刷新消息、导航与搜索状态。仅存在前端的消息直接本地删除，不新增持久化。

## 涉及范围

Core 分组、压缩尾部清理、ChatRecordingService 与 SessionWriterLease；CLI ACP 会话控制与 owner daemon 路由；ACP bridge 和能力声明；TypeScript daemon SDK；Web Shell 消息投影、选择控件与会话刷新；相关测试与浏览器 E2E。

## 约束与风险

不提供撤销、命令回滚、文件恢复、后续回答重生成、摘要编辑，或其他保留回复中的引用擦除。身份不明确、损坏历史和过期 snapshot 明确失败。Managed 追加存储需要独立权威修改契约，本次不支持。原子替换必须更新 writer 身份和 hash，并保留安全文件权限。持久化后若内存更新失败，不能允许旧上下文继续处理 prompt。

## 验证与验收标准

定向测试覆盖唯一组、全部组、非连续删除、工具与思考、压缩前后及原文尾部，验证摘要相等；覆盖斜杠展示与效果、废弃分支、过期 snapshot、writer 冲突、继续写入与恢复。Owner 路由测试覆盖忙碌与工作区隔离。浏览器测试覆盖回复状态栏的 checkbox 位置、展开步骤前后的数量不变、checkbox 联动、空选择、取消、确认、失败、本地命令、其他客户端失效通知和重载。要求 build、bundle、typecheck、变更文件 lint 和连续两轮干净自审。UI 截图明确使用模拟 daemon；持久化后端证据使用真实 daemon、ACP 进程与 JSONL，模型为确定性的本地模拟服务。后者验证过期 snapshot、工具整组物理删除、后续模型请求、压缩摘要相等、命令展示删除、全部删除及重开续写。

## 开放问题

约定行为无待定问题。不支持的 runtime 明确报告能力限制，不能静默退化为只删除前端展示。
