# Web Shell 加载文案设置

[English](web-shell-loading-phrases.md) | [简体中文](web-shell-loading-phrases.zh-CN.md)

## 问题与范围

终端支持 `ui.accessibility.enableLoadingPhrases`，但 Web Shell 的设置接口会
过滤该配置，主聊天始终启用加载文案。嵌入宿主可以通过 `loadingPhrases`
自定义文案，也可以返回空数组隐藏文案。用户需要在关闭现有设置时覆盖宿主的
自定义文案。

## 设计

从设置路由的终端专用排除列表移除该键。复用 Web Shell 其他 UI 偏好使用的
现有有效设置资源，仅当有效值严格等于 `false` 时，向主聊天加载状态传入
`showPhrase={false}`。缺失值保持当前默认行为。

| 有效设置      | 宿主解析器       | 结果         |
| ------------- | ---------------- | ------------ |
| `false`       | 任意             | 隐藏轮换文案 |
| `true` 或缺失 | 非空文案         | 显示宿主文案 |
| `true` 或缺失 | 空数组           | 隐藏轮换文案 |
| `true` 或缺失 | 未提供或返回空值 | 显示内置文案 |

现有状态组件在 `showPhrase` 为 false 时已经会停止文案轮换计时器。
加载动画、耗时、token 指标、取消提示和后台任务标签保持不变。
分屏面板原本就隐藏文案，继续保持。

该设置继续使用布尔类型、默认值 `true` 和现有重启元数据，保留终端行为。
为新增设置行补充 `setting:loading-phrases` 展示别名及中英文标签。

## 归属与约束

不新增 daemon 路由。`/workspace/settings` 继续属于 legacy-primary 范围，
`/workspaces/:workspace/settings` 继续属于 selected-runtime 范围，沿用现有
信任、环境、持久化和失败处理。Web Shell 主界面使用现有设置资源；本次变更
不将其他 UI 偏好迁移为会话所选工作区设置。配置优先级仍由 daemon 现有合并
逻辑决定。

## 影响范围

- 设置 API 允许列表及路由测试。
- Web Shell 主聊天加载状态接线及应用测试。
- 设置展示别名、翻译和嵌入文档。

## 验证与验收

运行相关路由、应用、加载状态和设置别名单元测试。使用宿主自定义文案验证
配置关闭、开启、缺失及回复过程中更新的行为。验证用户和工作区值的读取，
以及写入沿用现有作用域处理。执行构建、类型检查和打包。

先使用全局 daemon 确认当前接口排除了该设置。再通过模拟 daemon 的浏览器
E2E 验证实际加载界面，捕获开启与关闭截图。另行验证本地 daemon 的真实设置
读写路径；模拟界面证据不代表验证了真实模型或 Git 操作。

没有待定设计问题。
