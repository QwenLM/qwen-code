# OpenTUI 直接 marketplace 插件选择

[English](2026-10-31-opentui-extension-plugin-choice.md) | [简体中文](2026-10-31-opentui-extension-plugin-choice.zh-CN.md)

## 问题与范围

对自有双插件 Claude marketplace 的公开无后缀安装，在全局 Ink 与两个候选 Ink 配置中打开选择器；一次 Escape 无写入取消并自然退出。原生运行在选择器出现前因缺少根 qwen-extension.json 失败，未进入选择或转换。实现前已读取独立报告 e325dc21；原始原生失败及全部对照继续保留。

## 设计

在原生 shell 注册当前 Config 扩展管理器的选择回调。导出并原样复用现有 Source 插件选择组件。选择请求与确认、设置输入共用 FIFO，各自拥有独立 ID 和 resolve/cancel promise。活动模态框卸载 composer。每个组件按请求 ID 设置 key，连续选择重置选中项和结算状态。普通重渲染保留请求；Config 替换与卸载中止请求，捕获的旧回调拒绝，迟到选择不能结算后继请求。清理不恢复无操作回调，也不覆盖其他所有者的回调。

本改动只是 CLI 回调桥，不修改 Core 转换器、源缓存、hook、设置、provider 或审批策略。Source 获取明确传入的行为保持不变。只读 fixture 验证转换前打开和取消。另一个自有可写 fixture 验证选择 Beta 后拒绝确认，保留原始源文件且只允许已记录的派生子树。批准安装仍未验证。

## 验证

实现已通过正常 build、typecheck、lint、bundle、原生布局检查，以及六个整文件测试（328 项）。所有者回归覆盖选择值、取消、稳定重渲染、替换/卸载、旧回调、连续选择，以及与设置/确认共用 FIFO；已有 Source 组件和真实 voice-shell 测试仍包含在内。

Node/Ink、Bun/Ink 和严格 Bun/OpenTUI 各执行四个公开整案：直接选择取消、设置保存并冷启动读取、设置取消、直接确认拒绝。12 次执行全部通过，共有 15 次自然退出0/signal0，模型请求为零，使用同一构建候选入口。保存的映射保留精确权限、安装产物与相应源守卫。原始原生失败另行保留。

额外的 Beta→No 整案在上述三个候选配置，以及独立的已安装全局 Ink 基线上均通过。每次选择非首项 Beta、显示精确的 Beta 确认、拒绝，保持安装状态不变，并自然退出且模型请求为零。每个新建自有可写源保留五个原始文件及已有目录类型/权限，仅新增已记录的派生子树（三个目录、两个 Beta 文件）。全局程序是产品源未知的独立基线，不是另一份候选构建。

合计候选通过 15 次执行、五个独立整案，18 次自然退出且模型请求为零；全局 Beta 基线另计一次通过与自然退出。

这些检查验证公开选择器取消，以及选择值传递到确认/拒绝；不验证批准、成功安装、完整转换、hook、任意原始用户源目录修改语义、已安装候选、最终合并 main 或整体迁移完成。

## 2026-11-14 边框宽度修正

此前六项 shell 到控件断言只证明终端80/120/200列时内容预算为72/96/96，没有证明外层边框。随后以真实 Native RootRender 重放精确直接 shell 分支和真实控件，choice/setting 六案全部失败：边框 x0、宽80/120/200，而不是 x2、宽76/100/100。约束失败前已捕获四个真实边框角点。这是隔离无关 shell hook 的原生分支重放，不是完整 CLI 运行。原始失败与此前各自范围的通过均保留。

本次只给这两个直接挂载加入现有两列缩进和 dialog-area-width 容器，保留控件内容宽度上限、区域高度、请求 key 和生命周期行为。已有六项单测同时断言该结构父边界，但不替代原生几何验证。修正后的正常 build、五个 CLI 整文件测试（248项）、typecheck、全范围零 warning ESLint、六文件格式检查及 bundle 均通过。原样原生分支重放的六个边框案全部通过。另一个完整 strict Bun/OpenTUI tmux CLI 整案也通过六个真实绘制边界、公开选择器取消、确认及精确110字符设置保存，随后一次 exit0/signal0 自然退出，模型请求0且无强制清理。这些运行结果对应文档后续更新之前冻结的 aa02+6cd 源和 entry3ac63a1d；它们是本地 macOS 证据，不是已安装候选、最终 main 或跨平台资格。不修改队列、控件、Core 或政策。
