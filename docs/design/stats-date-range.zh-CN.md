# Token 用量的自定义日期范围

[English](stats-date-range.md) | [简体中文](stats-date-range.zh-CN.md)

## 问题与范围

`/stats daily` 和 `/stats monthly` 只能查询一个日历分桶，仪表盘仅提供预设周期。它们都不接受用户指定的起止日期，例如从 2025 年 9 月 9 日到 2026 年 7 月 11 日。

新增 `/stats range <YYYY-MM-DD> <YYYY-MM-DD>`，支持交互、无头和 ACP 模式。起止日期均包含在内。该命令统计已持久化的 token 用量，不包含历史工具调用、生成时序或会话时长。本次不增加仪表盘日期选择器或范围导出语法。

## 设计

在现有 token 用量服务中新增 `queryTokenUsageRange(startDate, endDate)`。复用现有日历校验逻辑验证两个日期，读取文件前拒绝倒序范围。列出用量目录，仅按顺序读取与范围相交且实际存在的月度 token 文件，避免工作量随缺失月份增长或产生无界并发读取。按记录保存的 `localDate` 过滤，保留写入进程原有的本地时区分桶，并复用现有聚合和分组排序。

返回摘要保持原有结构，使用 `period: 'range'` 和 `value: 'YYYY-MM-DD..YYYY-MM-DD'`。日/月查询和导出的输入保持不变。CLI 在注明包含起止日期的范围标题下，展示原有总计及模型、认证类型、来源明细。参数缺失、多余参数、不存在的日期和倒序日期返回错误；没有历史数据则返回零。非 ENOENT 读取错误继续向上传递，不能伪装为零用量。

## 影响文件与使用方

- Core token 用量服务及同目录测试：范围查询、共享摘要周期类型、日历与 I/O 回归。
- CLI stats 命令及测试：子命令注册、校验、复用输出和所有执行模式。
- CLI 语言字典和用户命令文档：本地化标签和使用方法。

现有摘要使用方包括日/月命令格式化器、CSV/JSON 格式化器及服务测试。只有命令格式化器需要第三种标题；导出格式化器直接序列化摘要的周期和值，不解释日历。无需修改公共配置、daemon 路由、持久化格式或供应商逻辑。

## 验证与验收

验证跨月跨年的边界包含、单日范围、闰日、本地日期分桶保留、相邻日期排除、缺失月份、空历史、不可读文件、非法或倒序日期及参数数量。使用隔离的运行时存储执行真实命令，不发送模型请求，并保留日/月回归测试。运行定向包测试、构建、类型检查、打包、格式与 lint 检查。在 `.qwen/e2e-tests/stats-date-range.md` 记录基线与修改后的结果。

## 风险与待定问题

只能统计已记录的本地 token 历史，不会重建持久化功能引入前的用量。与现有日/月查询相同，大量历史数据仍需扫描所选月度文件。没有未解决的行为问题。
