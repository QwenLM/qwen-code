# 输入框上下文快捷操作

[English](2026-09-13-web-shell-hover-compression.md) | [简体中文](2026-09-13-web-shell-hover-compression.zh-CN.md)

## 问题与范围

上下文圆环已在悬浮时展示本地用量，但手动压缩仅位于右侧上下文面板。
在悬浮卡片中增加压缩和详情面板入口。保留点击圆环生成历史上下文快照、
现有可见性设置、草稿和附件。不改变压缩算法、daemon API 或共享操作生命周期。

## 交互

使用已有且限定样式范围的非模态 Popover 构建交互卡片。悬浮 300 ms 后打开，
获得焦点时立即打开。圆环和卡片之间移动保留短暂关闭宽限期。悬浮不抢走编辑器
焦点，也不请求上下文。只有鼠标移动才启动悬浮延迟，鼠标按键保持按下时，聚焦或移动均不触发展开，避免快照操作导致卡片闪现。焦点在卡片内时保持展开。鼠标离开两个区域、焦点移出、
点击外部或按 Escape 时关闭。

圆环保留点击生成快照的动作。按向下箭头，或卡片展开时按 Tab，将键盘焦点
移入可用操作区；没有可用操作时保留浏览器原生 Tab 导航。卡片内按 Escape 后焦点返回圆环且不重新打开。提供可访问的
对话框名称、展开及关联属性，并在圆环上提供简洁的本地化已用/窗口说明。卡片按键不触发全局 BTW 关闭快捷键。使用 shadow portal 内真正聚焦的元素处理可用操作区首尾及压缩期间卡片容器的 Tab 导航；进入后若所有操作均变为不可用，Tab 关闭卡片。查看明细关闭卡片后也恢复圆环焦点，除非用户或面板已选择其他焦点。保留 portal root 隔离、现有主题和圆环属性，
复用稳定 CSS 与共享按钮。

卡片保留精确的已用、总量、剩余计数、比例条和严重程度颜色。增加明确的
手动压缩与查看详情按钮。保留现有次级文字与错误颜色，将卡片语义颜色映射到这些局部主题变量。未知计数不妨碍有效实时会话的操作。查看详情为同一
会话打开右侧上下文面板并关闭卡片，不生成对话历史快照。

## 状态与归属

由 App 或 ChatPane 向 ChatEditor 传入已有归属 controls。不再次实例化压缩
hook，也不通过普通输入框提交路径执行。两个入口共享等待标记、可用条件和
完成结果。活动任务、计划准备、审批、恢复、Goal 状态及缺少内置命令元数据
继续使用现有约束。

进行中和结束反馈与右侧面板使用相同文案和语义。关闭已展开的卡片会收起其已结束反馈；掠过或点击关闭状态的圆环不会丢弃未展示的结果；关闭后才完成的操作仍可在下次打开时查看。卡片所属组件重新挂载时不重放先前已结束的反馈。右侧面板继续通过现有刷新操作收起反馈。完成路径已同步实时计数；
失败、取消或连接变化不得宣称读数已刷新。查看详情提供现有 Refresh 恢复入口。
打开卡片不发起读取，也不重试压缩。

App 通过现有面板动作打开主会话详情。SplitView 独立于自定义顶栏渲染转发
分屏详情回调；每个分屏传入自身会话与 actions，并标记标签随分屏关闭。
悬浮卡片在归属会话变化时重置。输入框快捷入口独立遵循输入框工具栏可见性，`header.items` 仅控制顶栏操作，不改变默认顶栏。没有详情面板入口的内嵌旁路任务保留只读概览和快照操作，不引入缺少刷新恢复路径的压缩操作。旧回调仍由已有压缩 hook 的会话/工作区及
等待保护约束。

## 实现区域

- ChatEditor 和内部上下文 Popover 组件：本地计数概览、悬浮/焦点行为、键盘
  操作和共享压缩 controls。
- App、SplitView 和 ChatPane：所属会话的快捷操作及面板生命周期。
- ContextUsagePanel 和共享反馈组件：一致的结果文案。
- 中英文文案、定向组件/接线测试，以及已有浏览器上下文场景。

## 验证与验收

先在隔离的全局 CLI 基线 dry-run，记录缺少悬浮操作的行为。以真实鼠标和
键盘交互验证构建产物：悬浮不发请求、跨间隙移动、焦点进入/Escape、单次
压缩、共享等待/反馈/计数、草稿与快照保留、分屏隔离、计划/恢复约束，以及
自定义顶栏和未知用量时的详情入口。检查浅色/深色、窄布局和中文，保留
React 18 ref 兼容及 portal 隔离。

运行根目录 build/typecheck/bundle 与受影响包测试。对完整差异进行无方向及
反向审计，直到连续两轮无新发现，再进行独立代码审查。PR 使用 fork assets
分支托管的真实浏览器截图，并单独发布 E2E 报告。没有未决产品问题。
