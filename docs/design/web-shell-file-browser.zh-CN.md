# Web Shell 文件浏览器

[English](web-shell-file-browser.md) | [简体中文](web-shell-file-browser.zh-CN.md)

## 问题与现状

右侧拓展区提供文件更改，但无法浏览工作区文件。此次在现有操作旁新增
「文件」入口，选中文件的内容在左侧，持续可见的目录树在右侧。

## 实现方案

新增可选的 `files` 右侧面板配置项及具有工作区归属的 `files` 页签，独立页面
默认启用。空态入口和加号菜单打开或激活每个工作区唯一的文件页签。复用面板
尺寸、关闭、全屏和持久化行为。尚未选择文件时仅显示占满宽度的目录树，点击
文件后显示两列，初始约 70% 用于内容、30% 用于目录树，且不重建目录树；后续切换文件时目录树持续可见。

采用 `@pierre/trees` 展示只读目录树，采用 `@pierre/diffs` 的 File 展示只读
源码。保留现有 Markdown、HTML 和图片预览。Markdown 和 HTML 默认渲染预览，
可切换源码。其他文件沿用现有文件支持及错误行为。不启用 Git 状态或编辑。

通过现有 daemon API 仅加载根目录和已展开目录。Pierre 模型保存已加载路径，
展开目录时加载直接子节点。搜索仅覆盖已加载路径，不读取因搜索而展开的目录。筛选输入保留原文，零匹配时明确
展示「已加载路径内无匹配」。选择文件或按 Escape 结束筛选。筛选非空时优先消费 Escape，
不会退出全屏或关闭抽屉；输入法组合期间保留原生 Escape 行为。刷新清空目录缓存，重新加载
根目录和当前文件，并收起分支。不展示筛选范围说明和逐目录加载日志，仅在需要时
展示可重试错误、空目录和列表截断提示。不递归展开符号链接。两列独立滚动。目录树支持整体横向滚动，保留深层缩进和完整名称；
通过 Pierre 的 Shadow DOM CSS 扩展按内容确定虚拟列表宽度，避免名称被压缩。
中间使用共享 shadcn 可调整尺寸组件提供
支持键盘的拖动分隔线，切换页签保留宽度。文件树底部留出 12px。窄面板可隐藏目录树以阅读
内容，无需关闭文件页签。文件右键菜单提供相对与绝对路径复制、下载、在独立
页签预览 Markdown/HTML/图片，以及引用到当前输入框。引用复用内置 `@` 文件
选择器的标签构造与行内插入，仅面向当前工作区。引用时关闭浮动抽屉，再将焦点交回输入框；
桌面停靠面板保持展开。下载复用现有大小受限、具有
归属检查和取消支持的字节读取流程。

## 归属与生命周期

文件页签保存工作区 cwd 和 ID。扩展现有产物工作区权限守卫，目录请求前后均
校验归属。daemon 公布工作区 ID 时通过具有工作区限定的 SDK REST 接口读取目录（包括 ACP 客户端）；
仅旧 daemon 保留主工作区接口。不可用、歧义、不可信或已变更的归属均拒绝访问。
切换工作区后丢弃迟到结果。文件页签未激活时仍保持挂载，切换页签保留选中、
展开、源码/预览模式、筛选、列宽和滚动位置。隐藏页签仍独立校验工作区归属；关闭页签
或归属失效时丢弃状态。页面刷新仅恢复页签工作区身份。旧归属页签继续拒绝访问，但不遮蔽重新打开当前可信
归属的入口。
文件内容加载保留现有大小限制和取消行为。

## 范围与决策

不实现文件系统修改、代码编辑、Git 操作、监听器或全工作区搜索索引。打开文件
不会自动加入模型上下文；显式「引用」仅插入文件标签，不发送请求。保留现有审查、附件和文件页签行为。Pierre 使用
Shadow DOM，通过公开变量适配 Web Shell 语义颜色。使用原生入口以保留包现有
React 18/19 peer 范围。Pierre 固定版本并作为构建期依赖，原生实现完整打包，
发布包的使用方无需安装其要求 18.3.1 起的 React peer。源码
采用虚拟滚动；切换主题原地更新渲染器。库构建将 Pierre 兼容的 Shiki 3/4
依赖打包进延迟预览模块，其他渲染器保留现有 Shiki 1 依赖；超过 10,000 行或 1,048,576 字符时使用纯文本，以限制语法高亮开销。

## 文件更改承载评估

Pierre FileDiff 可展示现有修改前后文本、合并或双栏视图、行号和行内变更，后续
可替换显示层。输入可能是完整快照、统一补丁或局部编辑片段。局部片段不能展示为
完整文件的真实行号，同一文件的多次编辑也必须保留记录的分段。目前文件更改还
负责工具调用分组、汇总行数统计、历史轮次与最新
工作区语义、打开文件、下载及缺失或二进制文件处理，这些职责应继续保留。
迁移渲染器需要单独验证 CodeMirror merge 行为、大型及截断变更、取消、主题和
折行。本次仅记录评估，不迁移审查渲染，也不接入 Git。

## 影响范围

- 产物面板、配置类型、独立入口、翻译和 README。
- App 页签打开、持久化及工作区归属连接。
- 工作区文件浏览器、Pierre 源码渲染器及针对性测试。
- 具有权限守卫的产物工作区目录读取与归属测试。
- 使用现有模拟 daemon 的浏览器 E2E 测试，明确标注模拟环境。

## 验证与验收标准

1. 「文件」与「文件更改」并列，初始仅显示目录树；选择文件后显示左侧内容、右侧目录树。
2. 展开目录读取直接子节点并复用缓存；深层路径和长名称可通过目录树横向滚动完整阅读。
3. 选择不同文件切换内容，目录树持续可见。
4. Markdown 显示文档，可切换高亮只读源码。
5. 筛选保留输入、明确展示零匹配且不加载目录；刷新、空态、错误和不完整列表提示可见。
6. 右键路径复制、字节下载、独立预览和 `@` 引用均可用。
7. 不可信或已变更的工作区归属及迟到响应不能泄露内容。
8. 切换页签保留文件浏览状态；面板关闭重开、页面刷新恢复页签和窄布局保持可用。
9. 现有审查与附件行为有回归覆盖。
10. 文件浏览与筛选进入 PR 浏览器 smoke 门禁；归属、持久化与传输针对性测试、构建、
    类型检查及目视检查浏览器截图提供验证证据。
