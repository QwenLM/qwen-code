# Web Shell PWA 安装能力

[English](web-shell-pwa-installability.md) | [简体中文](web-shell-pwa-installability.zh-CN.md)

## 问题与范围

Issue #11704 提议开发 Android 配套客户端。双方同意先让现有的 daemon Web Shell
支持安装。目前它没有 Web 应用清单或 service worker。本次变更新增安装元数据和
连接中断页面，不实现 Android 壳、Web Push、后台执行、离线会话或新传输协议。

## 设计

- 在独立 HTML 中引用清单。应用标识、作用域和启动地址均固定在源站根路径，不包含
  token、会话 ID、查询参数或片段。复用现有 Qwen 应用的 192 和 512 像素图标。
  安装元数据使用内置 Qwen Code 标识，运行时自定义品牌另行处理。
- 仅在生产环境的独立入口、安全上下文且非框架内注册根作用域 service worker。
  库使用方和 Vite 开发服务器不注册 worker。注册失败不得阻止现有界面启动。
- worker 仅处理根路径或精确会话深链接的 GET 文档导航。请求优先走网络，保留
  HTTP 错误响应，仅在网络请求失败时返回自包含的连接中断页面。其他路由、静态
  资源、API 调用、SSE 和权限请求保持原状。不新增 Cache Storage、token 存储或
  响应持久化。
- worker 更新遵循浏览器生命周期，不强制激活、不刷新活动会话，也不立即接管
  已打开的页面。
- 两个根路径 PWA 文件不包含敏感信息，公开提供并要求重新验证缓存，明确设置内容
  类型。同时扩展热服务器、冷运行时门禁及远程同源中间件使用的精确 GET/HEAD
  白名单。现有 Host、CORS、认证和 CSP 规则继续生效。图标使用现有公开 assets 路由。
- 除 Vite 构建外，还将根路径文件包含在可分发 CLI bundle 中，确保用户实际运行的
  产物支持安装。

## 受影响的组件

独立 Web Shell 入口、公开资源及测试；daemon 静态文件服务及轻量 pre-auth 判定；
bundle 资源复制；用户文档。新增路由是进程级的公开界面资源，不是工作区或会话
API。无需更改 SDK 或协议能力。

## 约束与风险

安装和 service worker 需要 HTTPS 或本机回环开发源。LAN IP 上的普通 HTTP 仍提供
正常 Web Shell。安装不会将浏览器标签页凭据复制到其他浏览器存储上下文；现有认证
流程可能再次要求输入 token。执行任务仍需要运行中的 daemon 和网络连接。本次不
承诺后台通知。逐设备凭据撤销和更全面的浏览器支持矩阵仍是后续 Android 壳的前置项。

## 验证与验收

验证清单标识和图标尺寸；构建后的独立页面注册 worker；根路径及会话页面离线导航
与恢复；worker 不创建缓存；API 错误响应和流保持原状；认证前 GET/HEAD 静态路由的
MIME 与缓存头；相邻路径及变更请求方法不会进入白名单；打包资源完整；浏览器正常
启动。运行针对性测试、构建、类型检查及项目要求的检查，并报告平台限制。

## 待解决问题

本阶段无待解决问题。原生通知、可随品牌变化的安装元数据及 Android 实现留待后续提案。
