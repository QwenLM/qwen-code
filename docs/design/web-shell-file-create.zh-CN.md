# Web Shell 新建文件与文件夹

[English](web-shell-file-create.md) | [简体中文](web-shell-file-create.zh-CN.md)

## 问题与范围

Files 能浏览已有条目，但无法创建文件或空文件夹。在顶部添加新建文件、新建文件夹
按钮，默认作用于工作区根目录；在文件夹行右侧菜单中添加相同操作，作用于该文件夹。
刷新图标替换为 `rotate-cw`。创建能力支持可信本地工作区。

## 设计

- 复用工作区限定文件写入接口，以 create 模式和空内容创建文件。新增限定工作区的
  目录创建接口、能力及 SDK 方法。只解析选定的 active 可信运行时，执行变更鉴权
  和文件系统边界检查，禁止回退主工作区。
- 在已有父目录下创建单个条目。已有文件或文件夹返回冲突，禁止覆盖或静默复用。
  保留末级符号链接（包括悬空链接），禁止沿链接创建其目标。
  保留已有 mkdir 调用方的幂等/递归行为、运行代际保护、锁与审计。本次不包含 SSH
  创建。可移植路径操作沿用外部进程替换父目录竞态的既有局限。
- 两项可选 artifact 创建动作分别按能力、限定 REST 支持、唯一可信所有者及本地
  工作区门控；请求前和应用结果前重新检查当前所有权及资格。
- 使用 Pierre 原生行尾菜单触发器，同时保留右键菜单。文件夹菜单提供新建文件和
  新建文件夹，文件菜单保留已有操作。复用带作用域的 Dialog、Input、Button 和
  DropdownMenu。输入单个末级名称，显示目标目录，拒绝分隔符、空名称、点名称及
  控制字符，默认聚焦输入框。
- 取消不请求。请求中禁止重复提交和关闭；错误保留在弹窗中供修改或重试。确认状态
  与完成结果绑定到当前文件树及工作区生命周期。
- 成功后将条目插入现有树并更新父目录列表状态，保留其他展开、筛选及预览。合并
  本地新建条目与迟到的目录列表结果，防止旧结果隐藏新条目或误报父目录为空。
  新文件夹创建时为空，首次展开时加载。

## 影响范围与决策

CLI 文件系统、限定工作区写入路由及能力；限定 SDK 客户端；Web Shell artifact
动作、文件浏览器、双语文案及测试。不引入依赖、递归创建 UI、内容编辑器或自动覆盖。
即使选中了其他文件，顶部按钮仍作用于根目录；文件夹菜单始终作用于打开菜单的目录。

## 验证与验收

记录全局 CLI 基线，已安装 CLI 没有 Files 时使用最新 main 的模拟 daemon 浏览器
基线。验证顶部和文件夹行尾菜单、目标准确、取消及名称校验、忙碌/失败/重试、所有权
撤销、能力门控、迟到列表及树状态保留。通过隔离真实 daemon 测试空文件/目录、
冲突、次工作区隔离，以及边界/鉴权/信任拒绝。完成构建、类型检查、打包、定向测试、
浏览器 E2E、lint/格式及两轮干净审查，再独立 review。捕获并目视检查 UI 截图，
明确区分模拟 UI 证据和真实磁盘断言。

## 待定问题

无。本分支基于 main。普通文件删除保留在 PR #14158，本次只增加文件夹删除。

## 文件夹删除与首次加载

文件夹菜单增加“删除”，单独由 `workspace_directory_delete` 能力门控。
限定工作区的目录删除接口只接受非根本地目录，并删除全部子树；拒绝末级符号链接、
文件、根目录和越界路径。子树内的符号链接仅移除链接，不跟随其目标。
所有操作归选定的可信运行时所有；不支持的 SSH/自定义文件系统不回退主工作区。

交互参考文件删除 PR #14158：使用危险操作 AlertDialog，显示相对路径，明确提示
文件夹及全部内容永久删除且不可恢复，默认聚焦取消。取消/Escape 不发请求；
请求中不可关闭或重复提交。失败保留提示供重试（递归文件系统失败可能已经移除部分
子树）。成功移除整棵子树、已加载状态及其中当前预览，保留其他展开和筛选。
使后代加载失效，并过滤迟到的父列表，防止条目重新出现。
可移植递归删除沿用外部替换父目录竞态的局限。首次 Files 懒加载提示水平居中，新建文件图标使用 `sticky-note-plus`。

验证非空/空目录删除、子树链接的外部目标保留、根目录/边界/鉴权/所有权拒绝、
取消/焦点/忙碌/重试、迟到的后代列表、预览清理、其他展开及首次加载对齐。

## Review 后续边界

只读 transcript 入口在构建时排除工作区变更动作，交互入口仍保留这些能力。
保持既有 transcript 体积上限，并验证变更动作不进入产物、只读目录访问仍保留。
仅当目录操作可用时，文件夹行显示 Options 行尾触发器。删除后先将焦点恢复到
仍存在的 roving 文件行，再回退到树根。新建文件夹首次展开时加载目录，因而能
显示首次展开前外部写入的内容，不必手动刷新。已加载目录被外部删除后，同路径
独占创建成功时先清理旧子树、缓存列表及后代预览，再加入新建的空目录。
测试迟到的祖先列表、创建失败无幻影条目、能力菜单的正向对照及无关预览保留。

## 文件树上传集成

保留 main 的拖放上传，与新建及文件夹删除确认共存。上传成功的文件加入已确认
条目合并集合，不自动展开父目录，迟到的空列表不能隐藏它们。上传能力检查独立
于仅限本地的新建/删除，保留 SSH 上传支持；transcript 构建排除全部变更动作。

文件夹删除确认等待上传结束，删除处理中拒绝新文件拖放，防止同面板上传在删除
后重建该文件夹。其他客户端及外部进程仍受既有文件系统并发局限约束。
