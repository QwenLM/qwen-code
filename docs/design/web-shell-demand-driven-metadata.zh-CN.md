# Web Shell 元数据按需请求

[English](web-shell-demand-driven-metadata.md) | [简体中文](web-shell-demand-driven-metadata.zh-CN.md)

## 问题与范围

侧栏展开的工作区目前在挂载、窗口聚焦以及每隔 30 秒时获取概览数据，但这些数量仅在悬浮详情或工作区菜单中展示。聊天区域读取和轮询 Git 状态时也没有检查宿主的 `composerToolbarActions` 配置。会话 Provider 还会在初始化和加载会话时独立获取分支。带来源过滤的会话列表每次读取前也会额外请求发现接口。

本次改动根据消费这些数据的界面控制请求。不改变接口、工作区归属、会话列表的刷新时机，以及工作区管理表格。当前工作区仍可打开 Git 对话框。

## 行为

- 保留现有鼠标悬浮或键盘聚焦的 300 ms 延迟，详情浮层实际打开后才加载概览；打开工作区菜单也会加载。工作区展开和收起时行为一致。仅显示标题操作按钮不会加载元数据。
- 现有 30 秒轮询和窗口聚焦刷新仅在详情或菜单打开期间运行。两者都关闭后停止刷新。保留上次快照，再次打开时刷新。不增加缓存有效期或请求调度器。
- 保留工作区信任和真实路径检查。自定义标题仅在消费概览数据的标题菜单打开时发起请求。
- 移除侧栏标题后的 Git 按钮，在 hover 弹层的分支行右侧显示纯文本摘要，例如“6 已修改 · 11 个 stash”，复用已有 Git 状态翻译；打开终端图标改为 `square-terminal`。对非当前工作区执行分支切换、查看变更或提交，需要先选中该工作区；hover 摘要不是可交互的 Git 选择器。仅在详情或依赖 Git 的工作区菜单打开时读取 Git，关闭后停止 60 秒轮询和聚焦刷新。
- 可见的输入框工具栏包含 `gitBranch`，或环境面板可见且包含环境信息卡片时，聊天区域才读取 Git。仅配置但未打开的环境面板不会触发读取。不传 `composerToolbarActions` 保留默认工具栏选择；显式传入不含 `gitBranch` 的数组则关闭该消费入口。
- `WebShellWithProviders` 关闭重复的 Provider Git 预取，由界面负责读取。已连接会话在首次分支事件到达前，也能展示已获取的分支。继续支持 SSE 分支更新。
- 底层 `DaemonSessionProvider` 保持默认行为。自行管理 Provider 的宿主可在界面负责 Git 加载时设置 `prefetchGitBranch={false}`。这同时适用于延迟初始化和会话加载。

## 会话来源能力预检

带来源过滤的会话列表在旧路由和限定工作区的路由之间，共享父级 `DaemonClient` 的能力预检。发现请求成功后，独立复制其功能集合，缓存 60 秒。预检复用最新的在途发现请求，或读取未过期快照。过期后按需刷新；不增加后台计时器，不跨客户端共享缓存。

公开的 `capabilities()` 始终请求最新数据，并立即使旧快照失效。通过请求代次防止较早响应覆盖新的功能集合。会话恢复超时采用最新成功响应的值，较新的发现请求失败时，不丢弃较早成功响应提供的超时。等待过期请求的预检会继续检查当前状态，过期请求失败时也如此。发现请求失败不缓存。销毁客户端会使待处理的缓存更新失效；传输层继续执行已有的关闭检查。

仅 `session_source_metadata` 的检查使用缓存，包括会话创建和恢复中的检查。缺失能力时的错误及恢复兼容降级行为保持不变。其他能力检查仍实时读取，尤其是记忆作用域检查，它可防止旧 daemon 在写操作中静默忽略作用域。不增加公开配置项。缓存的发现数据不会替代工作区元数据的实时读取。

无缓存时，4 次带来源的列表查询现在只需 1 次发现请求和 4 次列表请求，串行和并发行为一致。如果已有有效的初始化快照，则只需 4 次列表请求。回归验证覆盖两种路由、过期、初始化复用、显式刷新、成功或失败响应乱序、重试、缺失能力、功能集合复制、客户端隔离、销毁，以及有作用域操作的实时检查。运行 SDK 客户端和会话客户端单元测试，以及 Web Shell 工作区 Provider 测试，验证消费方边界。

## 设置页的 Providers

App 的 providers Hook 仅用于设置页的模型管理。仅在工作区功能可用且设置页打开时，启用自动读取和事件刷新。SessionProvider 保留聊天模型初始化所需的 providers 读取。本次从聊天启动过程中移除一次隐藏设置页的请求；之后打开设置页会增加 1 次请求。[维护者的真实 daemon 验证](https://github.com/QwenLM/qwen-code/pull/11644#issuecomment-5649574918)测得启动请求从 3 次降为 2 次，因为 SessionProvider 的延迟连接批次在启动时仍执行了两次。该 Provider 内部重复不在本次改动范围内，因此 #11604 保持打开。直接以设置页启动时仍可能需要两个消费者读取。

每次打开设置页只读取一次最新数据。providers Hook 告知共享事件刷新辅助函数，自动加载已经覆盖启用或加载器变化，避免重新打开时又触发一次事件读取。隐藏期间的事件不请求；可见时的设置事件，以及删除模型、认证后的显式刷新继续生效。手动 `autoLoad: false` 的消费者保留显式读取和重新启用后的补充刷新。其他事件辅助函数调用方保持现有行为。不引入共享 providers 缓存或 TTL。

回归测试覆盖 App 的打开/关闭开关、每次打开仅一次请求、启用与设置变化同时发生、隐藏期间的事件、可见数据更新、显式刷新以及手动模式兼容性。

## 聊天目录按需加载

Web Shell 设置 `prefetchSkills={false}` 关闭无会话状态的 Skill 预取；底层会话 Provider 保留默认行为。打开斜杠候选、输入框 Skill 子菜单或帮助页时，读取当前工作区目录。自定义 `renderFooter` 也视作消费方，因为其公开的 `skills` 字段没有独立加载回调。Skills 管理页保留打开时读取。已有会话优先复用其支持的命令；普通输入和新建聊天不再预加载工作区目录。

对当前工作区、目录版本及草稿/已有会话加载模式复用一次已加载数据和在途请求。设置、扩展和 Skill 事件使缓存失效；入口关闭时延迟到下次打开才读取。已经开始的变更刷新可以在菜单关闭后完成记账，但必须仍属于当前会话。保留已有会话的 Skill 变更部分失败恢复逻辑。切换工作区使待处理结果失效。配置和就绪运行时的 Skill 读取仍是两个不同阶段。

展示加载和失败状态，不因尚未加载而隐藏 Skill 子菜单。本地斜杠命令立即可用；无匹配的斜杠查询在加载期间保持打开。MCP/扩展引用分类保留已有的按需读取和搜索期间请求复用；菜单生命周期缓存与管理页读取、文件系统缓存保持独立。

验收：未提供自定义 footer 时，闲置、普通输入和新建聊天不预取 Skill；工作区目录版本未变时，反复打开斜杠和 Skill 子菜单只加载一次；加载态、失败重试、工作区隔离、Skill 变更刷新，以及 MCP/扩展分类按需读取均正常。不新增接口。

能力响应的内容相同时，即使 features 数组引用变化，也保留已加载目录；实际 Skills 协议能力变化时仍使加载失效。命令刷新失败会在空候选中显示错误，重试时清除，且仅属于发生失败的会话。运行时修改任一预取选项都会重新连接会话；宿主通常应在挂载 Provider 时确定这些选项。

运行时准备失败时保留配置列表作为临时展示，同时提示失败并允许重开后重试。支持 ACP 预热的旧协议主工作区在首次需求时准备运行时，然后重新读取 Skills。清空会话只保留同工作区已有命令；关闭预取不能删除 Skills 接口无法恢复的自定义命令。斜杠状态文案仅在候选为空时显示。跳过 Provider 预取时保留未知命令状态。提交带附件的未解析斜杠命令前，先读取会话命令快照，再判断是否丢弃附件；已知命令和普通消息不增加读取。若读取在提示接纳前失败，显示错误，并在会话未切换且输入框为空时恢复未发送的文字和附件；保留用户新输入的内容。空候选可以触发首次加载，但加载成功后无匹配的菜单应收起。

已连接会话存在待处理的扩展或 Skill 变更时，空候选菜单保留到延迟刷新完成，直接粘贴新命令也可以触发刷新。

## Live 设置读取

打开设置页时读取 Live 配置状态。仅在设置页打开且安装或启动进行中时每秒轮询；首次状态尚未加载、读取失败，以及已启用且安装完成但宿主尚未就绪时，也继续轮询。稳定状态通过窗口聚焦或页面重新可见刷新。关闭设置页停止自动读取。`sidebar.showLive` 仍只控制侧栏分组。Live 未启用时也保留设置入口，以便用户启用功能。

## 约束与风险

打开悬浮详情时会有网络延迟；再次打开时保留的快照可减少空白。关闭后已发出的请求仍可能完成，但现有概览 Hook 会丢弃过期结果。可见区域保留现有轮询周期。输入框隐藏分支入口时，独立 Git 界面仍会请求 Git。关闭 Provider 预取不能清除同工作区会话元数据加载期间收到的分支事件。切换工作区时清除旧分支；侧栏中过期的 Git 响应不能覆盖较新的快照。来源能力预检可能在 60 秒缓存有效期内沿用旧判断；显式调用 `capabilities()` 会立即刷新。

## 验证与验收

使用现有 React/Vitest 测试验证：详情关闭时，挂载、聚焦和计时器不会触发概览请求；延迟悬浮和聚焦加载；收起的工作区也可加载；菜单加载；关闭后停止刷新。验证工具栏显式排除 `gitBranch` 且无环境面板消费者时，聊天区域不会读取 Git，包括聚焦和计时器触发；动态切换消费者能够启动和停止读取。验证无会话状态及已连接会话的 Provider 预取开关、底层 SDK 默认兼容性、分支事件保留，以及事件到达前的分支展示。运行包内定向测试、仓库构建和类型检查。浏览器检查和基线证据记录在 `.qwen/e2e-tests/` 下。

工作区概览的 Playwright smoke 测试覆盖闲置零读取、hover 触发加载和 30 秒刷新周期，以及详情或工作区菜单关闭后停止概览与 Git 读取。仅展开工作区不会重新加载概览。
