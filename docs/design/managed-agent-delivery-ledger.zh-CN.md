## 维护方式

- 每个已合入 PR 一行：``| [#PR](https://github.com/QwenLM/qwen-code/pull/PR) | merged（`合并提交`） | 覆盖 proposal 范围 | 尚未覆盖的边界 |``，合并提交缩写为十位。
- 所有 PR 与 issue 引用都写成显式链接，PR 用 `[#N](https://github.com/QwenLM/qwen-code/pull/N)`，issue 用 `[#N](https://github.com/QwenLM/qwen-code/issues/N)`：仓库内的 Markdown 不会像 issue 正文那样自动为裸 `#N` 生成链接。
- [#12380](https://github.com/QwenLM/qwen-code/issues/12380) 开放表中的 PR 合入后，从 issue 删除其行并在此追加，按合入后的最终状态改写：落地时的范围、迁移编号与契约版本、剩余边界，以及归属到精确 head 的验证证据。
- 本文件与英文版保持相同的行与顺序；配对规则见本目录的 `README.zh-CN.md`。
- 到 [#12998](https://github.com/QwenLM/qwen-code/pull/12998) 为止的行保持 issue 表在 2026-10-07 时按阶段分组的顺序；自 [#13277](https://github.com/QwenLM/qwen-code/pull/13277) 起的行按合入顺序排列，新增行也按合入顺序追加。
- 范围属于 Managed Agent 交付（sdk-java 服务、Hosted 与 managed 运行时代码及其测试、文档与 CI 车道）的 PR 才在此记录；只是顺带碰到 managed 测试的无关 PR 不记行。
- 关闭未合入的 PR 保留在“关闭未合入”表中，便于查找其范围与替代 PR。
