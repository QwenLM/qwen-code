# 终端流式增量渲染

[English](tui-incremental-streaming.md) | [简体中文](tui-incremental-streaming.zh-CN.md)

## 问题和证据

首轮流式节奏改动后，文字仍显得不均匀。主聊天事件已有 17 ms 有序缓冲，
虚拟模式下 Ink 也已设为 60 FPS。增长中的 Markdown 片段仍会随更新重新
解析，代码行和稳定块可能被重复高亮或构建。

本地 Grok Build 源码复用稳定 Markdown 前缀，并将绘制截止时间锚定到
上次绘制。对较早的 Qwen 72 次提交时间线做纯时钟重放时，Ink 现有
leading/trailing 节流的间隔 P95 约为 33 ms，固定截止时间约为 19–20 ms。
这确认了一种调度机制，不代表当前 CLI 的端到端改善。

当前本地基线约每 11–12 ms 接收分片，但 ASCII 文字推进的 P50/P95 为
33/51 ms。受控组件回放中，18 条完整代码行在 72 次更新里被额外高亮
1296 次，自动识别代码的 React 渲染 P95 为 14.81 ms。受控输出端回调
P95 不超过 0.16 ms，这不代表原生终端实际显示耗时。

实现前用确定性分片记录当前 bundle，分开观察分片到达、应用更新、React
工作、Ink 绘制及终端输出。渲染回调在 stdout 写入前执行，不能当成写入
完成反馈。

## 拟议改动

### 按截止时间绘制

只在现有 Ink 补丁内替换普通绘制节流，使调度锚定到上次实际调用。满足
间隔就立即绘制，否则安排最早的剩余截止时间。后续请求合并，不延长
截止时间。回调读取最新组件树，避免排队保存过时帧快照。

保留既有帧率配置、debug/读屏无节流路径、Static 立即绘制、同步输出和
差异更新。在显式边界及卸载时保留 flush/cancel 语义。不增加第三个应用
定时器、Ink 公开 API 或人工逐字播放。保留 17 ms 有序流缓冲，以及完成、
工具、图片、取消、重试和回退时的刷新、丢弃语义。首批仍合并 17 ms；
此后将刷新锚定到上次非空刷新，而不是下一片到达后再等一个完整窗口，
避免 11–12 ms 分片节奏变成 22–24 ms 状态更新步长。空刷新不移动时钟，
重试和回退丢弃数据时重置时钟。空闲后的迟到分片可立即更新，调度前仍
先将全部文字、图片 parts 按顺序入队。

### 稳定 Markdown 前缀

待完成文字只追加时，在现有解析器理解的保守完整块边界，保留已解析的
React 节点，只继续解析变化尾部。保留原始行 key、块计数、复制索引和
空行行为。不切开或冻结仍开放的代码、数学或表格块。显示规则仍以现有
解析器为准。

前缀改写、内容缩短、渲染模式、尺寸、颜色、高亮器可用性或复制来源上下文改变，或结束
pending 状态时，使缓存失效。最终渲染走原来的完整路径。数据只属于当前
挂载消息，不建立全局源码文字缓存。原生预览裁剪和虚拟列表来源选择
保留现有语义。
高亮器不可用时，只冻结不含代码的前缀，使代码渲染仍能沿用加载器的
冷却和重试行为。

### 复用已完成代码行

在各个挂载代码块内缓存代码行高亮。代码行、语言、当前主题及已加载高亮器
不变时复用高亮内容，行号栏仍可独立变化。只保留当前渲染行的结果，
保留 MaxSizedBox 布局要求的直接行结构。变化中的末行重新计算。
高亮器加载、主题或语言变化以及行替换使相关结果失效。保留现有逐行
语法处理、图形回退、裁剪、编号和可选择边界。

## 范围和实现

改动现有 Ink 补丁、流缓冲调度、MarkdownDisplay、CodeColorizer 及定点回归测试。
诊断脚本和原始时间线放在忽略的 .qwen 或任务自有临时目录。不新增永久
产品遥测、模型或协议变更、配置项、输出工作线程，也不迁移渲染器。
Arena 仍显示已完成轮次。

Grok 的写线程可供参考，但新增工作线程或跨层写入反馈协议，需要证据
证明终端输出端是瓶颈。本轮先沿用现有渲染器，减少调度抖动和重复工作。
测量结果也可能进一步缩小实现范围。

## 验证和验收

先检查全局 CLI 作为基线背景，再让未修改的本地 bundle 和重建 bundle
接收相同合成分片。覆盖稳定与突发 ASCII、中文、长段落、开放和闭合代码、
Markdown 表格和列表、思考及工具转换。比较文字推进间隔和接收到输出的
延迟，不只比较绘制次数。分开记录 React、绘制和高亮工作；若观察到输出端
延迟，补慢输出诊断。

验收要求：可测地减少不均匀输出间隔或重复渲染工作，最终文字准确，不增加
内容延迟。保留取消、重试或回退替换、图片顺序、窄窗口缩放、视口脱离底部、
输入框位置及来源复制语义。验证缓存失效和完成后的完整渲染。纯时钟测试
覆盖截止时间、合并、flush/cancel 与清理；真实渲染器测试检查实际输出。

在干净的 Ink 7.0.3 安装上验证补丁可独立应用。运行完整构建、类型检查、
bundle、定点单测、范围内 lint 和格式检查、两次自查及独立复审。如实记录
原生 Warp 和平台覆盖，不承诺固定每秒 60/120 可见帧。

## 待确认问题

基线将判断延迟中调度和 Markdown、布局工作各自所占的部分。输出端背压
推迟处理，除非相同可控回放显示它仍是显著瓶颈。
