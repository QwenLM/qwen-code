# 消息时间戳显示日期

[English](web-shell-message-dates.md) | [简体中文](web-shell-message-dates.zh-CN.md)

## 问题与范围

当前消息时间戳已区分当天和历史日期，但监控详情只显示时间，定时任务消息使用另一种本地化格式。message 区域所有墙钟时间统一使用本地日期判断：当天显示 `HH:mm:ss`，非当天显示 `YYYY-MM-DD HH:mm:ss`，以便跨天、跨年定位。耗时和侧栏会话标签保持不变。

## 实现

复用 MessageTimestamp 中的 `formatTimestamp`，保留按本地日历日期判断当天的逻辑。现有助手、工具、子代理、待办和工作流调用处自动使用统一格式；共享此函数的工作流运行列表也同步生效。TasksStatusMessage 的监控最近事件时间和 UserMessage 的定时触发时间改用该函数。保留定时触发时间的无效日期回退，以及现有显示时机、复制操作和时区行为。无需新依赖或 CSS 修改。

## 验证与验收

使用固定本地日期验证当天、历史、跨年和午夜时间。验证普通悬浮提示及聊天时间戳当天只显示时间，非当天包含日期和秒，定时触发和监控详情格式一致，缺失时间戳继续隐藏。运行针对性组件测试、构建、类型检查，并使用固定数据进行浏览器检查；固定数据检查不验证 daemon 持久化。无待定设计问题。
