# 最近会话刷新与预览

[English](2026-11-08-recent-sessions-refresh.md) | [简体中文](2026-11-08-recent-sessions-refresh.zh-CN.md)

## 状态与范围

刷新与分页修复已通过 16 项定向组件测试与隔离 HTTP 验证。新工作区依赖缺失或版本不匹配，完整构建、打包与工作区类型检查仍未通过。下述预览交互仅为方案。没有守护进程 API 或设置变更。

## 问题

展开的最近列表在页面隐藏时仍轮询。稀疏目录每读一页就对累计前缀重新过滤和排序。现有 API 下，读取足够页面以获得 20 条有效记录是必要行为；静默限制页数会改变结果完整性。

## 实现

监听页面可见性。隐藏页面不启动刷新。可见性变化使进行中的结果失效并阻止后续分页；已发出的 HTTP 请求可以完成。回到前台重新加载。折叠、暂停、范围变化和卸载同样使旧任务失效。刷新期间保留当前显示的记录。

逐页过滤，以会话身份累计有效记录。达到 20 条唯一有效记录或游标耗尽时停止，保留最后一个有效重复记录覆盖、来源隔离、排序与结果数量限制。每个来源结束时排序一次，合并后再排序一次。这避免保留被排除的数据和反复扫描前缀；不限制前台请求总数，也不声称已经测得延迟改善。

## 预览方案

将“显示全部”定义为临时展开：初始最多显示 5 行，点击后最多显示现有的 20 行。折叠重置临时展开；再次打开显示 5 行。切换守护进程或来源范围也重置。同一范围内的普通轮询、选择会话、可见性变化和数据更新均保留展开状态。不新增持久化或设置。在折叠事件中重置预览状态，不与轮询耦合。

这与同类列表一致，但改变了现有一种合理的偏好。因此它不是正确性修复，本次不实现。验收：5 → 显示全部 → 20 → 折叠 → 展开 → 5；展开时刷新仍为 20；不改变请求、选择、键盘语义或已保存的分区折叠偏好。

## 验证与风险

组件测试覆盖隐藏时初次挂载、前台/后台/前台切换、未完成分页、暂停、卸载、重复记录与稀疏目录。保持跨越被过滤页面读取有效记录的能力。重跑独立 HTTP 复现。检查构建、打包和类型检查，将环境失败与已通过的定向测试分别记录。复现模拟页面可见性，未证明真实浏览器节流、电量或服务端延迟效果。

## 验收

隐藏时不新增自动目录请求；未完成页面不能提交过期状态或发起下一页。回前台刷新。有效结果与确定性排序保持基线一致。不添加无条件页数上限。预览方案仅写文档。
