# Independent npm build-tree security upgrades

[English](npm-independent-build-security-upgrades.md) | [简体中文](npm-independent-build-security-upgrades.zh-CN.md)

## Problem and baseline

P1 #17105 and P2 #17134 are merged. At `e832ae58bd`, two active private
Electron build trees retain versions below the fixes tracked in #17099:

| Independent installation  | Dependency path                                                                                                                | Baseline | Target |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | -------- | ------ |
| Live Host                 | electron-builder → app-builder-lib → ajv → fast-uri                                                                            | 3.1.6    | 3.1.9  |
| CUA Electron test harness | electron-builder → app-builder-lib → @electron/rebuild → node-gyp → make-fetch-happen → socks-proxy-agent → socks → ip-address | 10.3.1   | 10.7.4 |

Both are development dependencies used for building applications, not direct
runtime imports. Live Host is excluded from the root workspace and its release
workflow runs standalone `npm ci`. The nested CUA fixture also installs from its
own lock. Root pnpm/npm overrides therefore do not repair these installations.
Library-level reproduction does not establish product exploitability.

## Proposed change and compatibility

Update only the two resolved lock entries within their existing parent ranges:
AJV accepts `fast-uri ^3.0.1`; socks accepts `ip-address ^10.1.1`.
Preserve parent packages and their majors. Add no direct dependency or override
because both parent ranges already admit the fixed version. Retain registry
integrity and dependency metadata generated by npm.

The [fast-uri advisory](https://github.com/fastify/fast-uri/security/advisories/GHSA-w74x-v6f9-j3xg)
lists 3.x below 3.1.9 as affected; the [ip-address advisory](https://github.com/beaugunderson/ip-address/security/advisories/GHSA-rxp7-6hxx-x8q5)
lists versions through 10.7.3, fixed in 10.7.4.
fast-uri 3.1.9 rejects ambiguous/encoded schemes and hosts and correctly escapes
relative suffix references. Check valid URI normalization and AJV references as
well as those security cases. ip-address 10.7.4 bounds malformed zone processing;
check IPv4/IPv6 and SOCKS proxy connectivity as well as the bounded hostile input.

## Validation and acceptance

Before changing dependencies, reproduce the remaining library behavior through
an independent test-engineer report. Afterward, perform clean standalone npm
installs, verify the actual resolved parent chains, repeat security and valid
input probes, and run Live Host build/typecheck/tests. Build the CUA fixture on
macOS and inspect the packaged application. Run repository build/typecheck as
required by the contribution workflow. Record actual outcomes and limitations in
the PR report; these steps are a plan, not a claim they have already passed.

Acceptance requires both installed trees to resolve the intended fixed versions
and the relevant build and compatibility checks to pass. No production options,
daemon routes, or application source behavior are added.
