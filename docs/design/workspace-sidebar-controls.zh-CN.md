# 工作区侧栏控制

[English](workspace-sidebar-controls.md) | [简体中文](workspace-sidebar-controls.zh-CN.md)

## 问题和范围

现有工作区标题可以隐藏整个列表，工作区菜单可以上移或下移工作区。用户还需要批量展开控制和直接拖动排序。本次覆盖当前连接 daemon 的项目工作区；其他主机、托管工作区内容、Live、置顶和最近会话保持现有行为。工作区排序由连接同一 daemon 的浏览器共享，并在 daemon 重启后保留。展开状态继续作为浏览器本地偏好。

## 设计

在工作区标题旁添加具有无障碍标签的展开/收起图标。如果有工作区展开，则全部收起；否则全部展开并显示外层列表。展开使用现有的五条会话预览，重置“显示更多”。单个工作区的操作和持久化展开偏好继续可用。

允许拖动工作区标题至另一标题，根据落点在标题中线之前或之后插入。保留菜单中的上移/下移作为键盘操作方式。不接受外部拖入，也不从工作区操作按钮启动拖动。

在现有工作区注册快照中增加可选的 `workspaceOrder` 元数据保存 cwd 顺序。复用文件锁、原子写入、大小限制以及 Qwen home 中按主工作区隔离的文件。不调整注册数组或运行时 registry 的顺序，因为它们影响启动语义。展示时忽略已不存在的工作区，新增工作区追加在末尾。

提供经过身份验证的 `GET /workspace-order` 和具有严格写入保护的 `POST /workspace-order`，请求/响应使用 `{ cwds: string[] }`。POST 沿用 daemon 现有的跨域方法策略，不扩大共享身份验证模块的改动范围。路由拥有进程级展示元数据，按主工作区持久化，不选择或执行工作区 runtime。验证 cwd 数组长度、绝对路径和唯一性；写入只接受当前可见项目工作区。排序不会授予信任、注册路径或访问请求中的目录。写入参与停机等待，存储不可用或失败时明确报错。

持久化工作区注册存储可用时声明 `workspace_order` 能力，SDK 提供两个 REST 方法。侧栏先加载服务端顺序，再允许排序；浏览器旧值不能覆盖服务端。拖动和菜单操作共用保存入口。先更新展示，禁止重叠保存，失败时恢复原顺序并显示错误。切换 daemon 或主工作区后丢弃旧响应。同一 origin 的主工作区变化时，先重新加载其服务端顺序，再允许排序；旧版 daemon 的本地存储仍仅按 origin 隔离。初次加载失败时禁止排序，直到后续加载成功。未声明能力的旧 daemon 保留本地存储行为。不自动迁移浏览器偏好，避免打开旧浏览器时覆盖其他浏览器的共享顺序。跨浏览器共享在加载时验证；已打开标签页的实时同步不在范围内。

拖动时临时隐藏保持挂载的会话列表，并显示关闭的文件夹图标，不修改展开偏好或预览状态。完成或取消拖动后恢复每个工作区的原有展示，包括“显示更多”、分组展开和搜索结果。只有有效落点才保存顺序。锁定单个工作区的视图不提供排序。

临时收起延后到原生拖动启动之后：在 `dragstart` 中同步移动位于下方的源标题，会导致 Chromium 取消拖动。拖动结束或侧栏切换主机、主工作区时取消尚未执行的延迟更新。任一作用域变化时，清空缓存的展开状态观测值。
源工作区消失或排序变为不可用时，取消尚未启动或正在进行的拖动，恢复剩余工作区的原有展示。

## 涉及文件和风险

修改 `WebShellSidebar.tsx` 及其 CSS 模块、`WorkspaceSection.tsx`、`workspaceOrder.ts`、工作区注册存储和管理路由、daemon 能力/协议文档、SDK、翻译及对应测试。保证由侧栏渲染的主工作区会话与由各分区渲染的其他工作区会话展示一致。稳定的工作区 key 在排序时保留组件状态。原生 HTML 拖动面向鼠标/触控板浏览器；触屏用户继续使用现有移动菜单。不新增依赖。

## 验证和验收

- 批量收起保留工作区标题；展开显示五条会话。
- 单独展开和批量操作通过现有存储 key 持久化。
- 拖动收起当前连接的全部工作区，包括搜索结果。
- 在标题上半部/下半部放下会改变并保存顺序，刷新后恢复。
- 清空浏览器存储或使用全新浏览器上下文后，仍显示服务端顺序。
- 使用相同主工作区重启 daemon 后，仍显示服务端顺序。
- 同一 origin 更换主工作区后，已打开页面加载该主工作区保存的顺序，丢弃旧主工作区尚未完成的响应。
- 无效写入、存储失败和持久化不可用明确报错；旧响应不能跨 daemon 生效，保存请求串行执行。
- 注册集合、启动顺序和展开偏好保持完整。
- 取消、列表外放下或拖回自身保留顺序和展示状态。
- 在临时收起前或之后移除拖动源，均恢复剩余工作区，且不保存新的顺序或展开偏好。
- 排序保留“显示更多”和混合展开状态。
- 通过单元测试、模拟 daemon 的 Chromium E2E、截图目视检查、仓库构建和类型检查。模拟证据不验证真实 Git 后端操作。实现前先检查全局 CLI 基线；其旧版本可能不提供该浏览器界面。
