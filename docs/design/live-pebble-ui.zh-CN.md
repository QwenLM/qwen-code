# Qwen Live Host 的 Pebble 界面

[English](live-pebble-ui.md) | [简体中文](live-pebble-ui.zh-CN.md)

## 目标与现状

用户已选择 Pebble，要求高保真实现；默认主题色为雾紫，并可通过配置文件切换。视觉依据是已确认的本地
Pebble 原型及其红色配色探索；已被否决的 Atelier 不作为本轮实现起点。

此前 Host 使用 112 px 小球、悬停工具栏、384 × 480 透明浮层内的模态设置，
以及悬停后出现、可展开为现有原生任务窗口的独立摘要。这些尺寸和交互与
Pebble 不同，单纯换色无法对齐。

## 呈现与几何

| 组件     | 目标                                            |
| -------- | ----------------------------------------------- |
| 语音主卡 | 234 × 194 px；圆角 26 px；内边距 15 px          |
| 标题栏   | 主卡偏移 15, 15；204 × 12 px；字号 9 px         |
| 语音圆盘 | 偏移 18, 47；51 × 51 px                         |
| 状态     | 12 px / 16 px，字重 550；来源和模式提示 9 px    |
| 工具栏   | 偏移 15, 116；204 × 41 px；五个 31 × 30 px 按钮 |
| 任务摘要 | 主卡下方居中，间隔 13 px，高 30 px              |
| 相机预览 | 161 × 107 px；圆角 14 px；图像内边距 5 px       |
| 设置     | 306 × 532 px；圆角 17 px；标题栏高 48 px        |
| 任务     | 内容宽 280 px；列表和详情在有限高度内滚动       |

尺寸均为 CSS 像素，不随屏幕倍率改变。扩大原生透明画布以同时容纳主卡和
设置，避免缩小设计稿。初始化、主卡、预览和设置分别定义可见边界；原生定位、
屏幕夹取与偏移补偿和 renderer 共用几何。字幕出现时上移预览并保留主卡锚点，
字幕不得遮挡预览或主卡。画布透明区域继续允许鼠标穿透。

标题栏作为拖动柄。右侧展示 daemon 实际下发的快捷键，替代原型中的虚构计时；
现有协议不提供通话起始时间。来源、状态、字幕及任务计数来自现有 Host 状态。
控件持续挂载并保持可见，不向产品加入虚构的任务、相机画面、状态或时长。

## 设置与任务

设置继续使用现有 overlay 和等待原生定位后显示的生命周期，保留过期打开请求
取消和编辑草稿。布局改为声音、视觉及个性化分组，记忆默认折叠，配置入口位于
页脚。设置呈现在主卡旁，采用非模态语义并保留 Escape／外部点击关闭，通话控件
仍可操作。外观模式与语言继续沿用原有持久化 API。

任务摘要改为主卡下方常驻按钮，使用现有 snapshot 计数和明确的待处理标记。
增加一个经过 trusted sender 校验的 Host IPC，直接打开现有 SubagentsWindows
列表，不增加窗口种类、daemon 路由或任务控制协议。保留过期 instance 拒绝、分页、
授权、取消、固定窗口生命周期及位置记忆。悬停不再显示重复摘要。

## 配色与动效

默认使用 Iris 雾紫。表面、正文、次要文字、强调色及浅强调色、圆盘渐变、波形、
边框和阴影使用共享语义 CSS 变量。在独立 Live 现有 `config.json` 顶层增加由 Host
读取的 `themeColor`，`init` 为新配置写入 `"iris"`。支持 `iris`、`clay`、`sage`、
`tide`、`graphite`、`rose`、`berry`。Host 仅在首次连接或重连时读取经过认证的
当前 daemon 所公布的配置路径，不猜测默认路径；缺省或非法的外观偏好回落到 Iris。
手动修改后重启 Host 或重连生效，不增加文件监听器和 daemon 协议。只有选中的
配色名称进入 renderer 状态，原有浅色／深色／跟随系统仍在 Host 独立持久化。

对齐 Pebble 的轻微按压反馈和波形状态：空闲／静音静止，聆听响应真实输入音量，
思考使用三个错峰圆点，播报使用独立波形。仅动画 transform／opacity，键盘操作
立即响应。减少动态、减少透明度和提高对比度模式可用；输入响应不改变发给
daemon 的音频音量。

## 范围与文件

修改 Host renderer 组件和样式、共享浮层几何、最小 preload/main 任务打开桥接、
任务窗口尺寸、聚焦测试、Host 文档和共享双语 UI 文案。不改变依赖、进程、权限、
安装、网络路由、媒体或 provider。摄像头抓图和配额错误修复单独记录于
[摄像头与配额设计](live-camera-quota-fixes.zh-CN.md)。

## 验证与验收

[修改前](assets/live-pebble-ui/before.png)和[修改后](assets/live-pebble-ui/after.png)
截图使用生产组件与模拟状态。修改后的展示合并主卡、设置和任务窗口，便于查看；
其中相机预览为占位内容，不是真实摄像头图像。

1. 适用时使用全局 CLI 记录基线，并说明原生视觉行为为何需要 renderer／原生
   窗口 fixture。
2. 构建和类型检查 Host，执行仓库要求的 build／typecheck／bundle 及相关 Host
   回归测试，单独记录环境失败。
3. 使用实际生产组件而非复制原型，在 Chrome 和本地 Electron 窗口注入确定状态，
   对照设计稿检查组件尺寸、截图和跨时间动效。
4. 验证静音、通话启停与退出、仅隐藏预览、设置草稿、记忆锁定、语言／外观、
   任务及授权，检查 DOM 稳定、键盘可用性、小屏定位和控制台错误。
5. 完成两轮连续无问题的完整 diff 自检及独立审查。Renderer fixture 结果不等价于
   真实麦克风、provider 或后台任务 E2E。

验收要求达到上表尺寸、浅深色下等价的间距和材质、没有功能回归，并明确视觉
证据来源。默认雾紫和所有可配置配色应在主卡与任务窗口的浅深色模式下同步应用。
