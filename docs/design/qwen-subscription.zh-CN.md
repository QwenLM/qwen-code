# Qwen Subscription 接入

[English](qwen-subscription.md) | [简体中文](qwen-subscription.zh-CN.md)

关联 Issue：[#15180](https://github.com/QwenLM/qwen-code/issues/15180)。

## 范围与可用性

CLI（Ink/OpenTUI）、桌面端和 VS Code 共用 Core 的会员凭证、会员查询及 OpenAI Chat 推理。`DEV=true` 是已有预发能力开关，不涉及生产开放或旧 OAuth 改动。移除产品模拟开关、模拟 transport、预览页面和原生调试启动器；保留回归测试替身。

桌面端在现有供应商弹窗增加 Qwen，不增加独立引导页或常驻订阅按钮。VS Code 保留原生供应商选择器，选择 Qwen 后进入共用侧栏会员流程；原生 QuickPick 账号操作只负责退出和升级。

## 授权、购买与恢复

1. 申请设备码，显示并打开授权链接，轮询 Token。Core 按返回的 `expires_in` 控制期限；GUI 不另设固定 600 秒。链接复制截止于原始授权期限。旧 OAuth 保留独立标题、倒计时和取消行为。
2. 保存完整 Token 对，再查询身份和 `member_type`。首次会员查询失败保留凭证，Check again 只重新查询，不重新授权；无需浏览器回调。
3. 套餐展示只调整大小写，保留 Free、Lite 及其他返回名称。只有忽略大小写的 Plus/Pro 可以激活。新授权网页已展示套餐，不自动打开第二个标签页，查询恢复后也不重复打开；复用本地凭证且未打开授权网页时自动打开一次套餐页。
4. 从首次确认未付费状态起，每五秒查询一次，最多自动查询两分钟。超时或查询失败允许手动 Check again，同时保留 Open plans again 和退出登录。查询期间禁止重复查询。
5. 关闭取消待完成任务。临时网络错误保留凭证；授权、兑换、存储、会员、刷新、清理和撤销错误区分阶段，不暴露任意响应正文。只有刷新阶段的 `invalid_grant` 表示刷新凭证过期。共享持久化冷却期限让申请授权、刷新和 userinfo 遵守 Retry-After。
6. 退出先删除本地凭证，再撤销远端会话。远端失败仍需同步本地退出并说明远端未撤销；本地删除失败不能宣称退出成功。宿主视图取消后不能更新新的归属。

## 桌面端与侧栏展示

桌面文案跟随语言设置，包括入口描述、新标记、弹窗标题、错误和操作。产品名、套餐名、模型 ID、命令和 URL 保留原值。中英文入口均为 Qwen；能力可用时默认选中首项，高亮、直接点击和下一步对应同一可见选择。其他类型索引包含首项偏移；能力不可用时默认选择首个普通类型。

桌面授权是连接供应商的第二步。上一步取消授权并返回选择；授权、会员确认和错误期间下一步禁用，确认成功自动继续。授权失败不提供重新登录按钮。浏览器兜底说明和等待文字使用供应商描述的弱化颜色，链接保持蓝色；查询失败保留重新检查。

购买引导使用独立可访问弹窗，保留授权流程生命周期。内容顺序对齐 CLI，并按桌面语言翻译：标题、未付费套餐说明、等待状态、重新打开套餐页、改用阿里云百炼、退出及弱化描述。省略重复账号行，保留等宽字体，取消位于独立底栏。复用供应商选项样式：整行次级背景、6px 圆角、选中标题蓝色。上下键只移动选择，不触发操作；移除终端箭头和浏览器焦点描边。关闭返回选择，不撤销凭证。

侧栏使用 VS Code 字体和语义颜色、13px 字号、1.6 行高、14px 区块间距及可换行宿主按钮。按已确认要求，购买引导在两种宿主语言中均保留英文；授权和就绪状态继续本地化。购买标题前显示登录邮箱和实际套餐，随后为说明与等待状态。打开套餐和重试使用主按钮，其他操作使用描边按钮，说明弱化。使用标准 Tab/Shift+Tab 和 Enter/Space。授权错误返回 Get Started 下方；购买和查询错误保留流程内恢复操作。

## 激活、模型与归属

恢复凭证、新授权、查询恢复或购买轮询确认 Plus/Pro 后，均在每个授权/transport 生命周期内自动激活一次。回调重渲染不能重复激活；等待时显示进度，普通失败提供显式重试。取消、卸载和归属替换抑制迟到成功。首个会话尚未创建时，关闭认证前先更新欢迎页输入框待用模型，避免首条请求恢复旧供应商模型。

通过 `GET /compatible-mode/v1/models` 获取全部 ID，不设白名单。已记录的预发列表包含 `qwen3.8-max`、`qwen3.7-flash` 和 `qwen3.7-plus`。首次优先使用返回的 `qwen3.8-max`，否则选择首项；已保存模型下线不能静默替换。网络或服务端故障保留凭证，可使用上次成功列表；无缓存时明确报错，不虚构模型。HTTP 错误按状态处理，只提取既有 `error_description` 字段，不解释响应业务码或猜测其他错误结构。HTTP 403 原样显示该文案，不返回缓存列表。退出或新账号授权清除账号所属缓存。

CLI 模型恢复提示 `/model`，启动时也允许 Esc 返回输入框。桌面和 VS Code 遇到 `subscription_models_unavailable` 或 `subscription_model_unavailable` 时关闭会员认证，保留凭证及现有会话模型，不增加专用重试或模型选择页，也不宣称激活成功。HTTP 403 为例外：在当前错误区保留后端业务文案；普通模型加载、选择和刷新仍由现有输入框处理。激活读取工作区已保存的模型，不提供临时覆盖模型的参数。

激活在两个宿主间传递错误阶段、HTTP 状态、文案及 Retry-After。OAuth 保留既有 `error`/`error_description` 解析，以及轮询、刷新凭证所需的业务码判断；模型和搜索 HTTP 错误使用按状态确定的客户端分类，不使用响应业务码。刷新凭证过期时退出就绪态，不隐式重新授权；激活重试遵守返回的冷却期限。推理取凭证失败和 MCP 搜索失败保留刷新、权限、限流分类，不再统一替换为重新登录提示。不展示未知本地异常和非 JSON 响应正文；GUI 兜底文案跟随宿主语言。

账号 daemon 路由属于进程级；激活和模型刷新明确访问选定工作区 runtime，遵守信任、generation 和生命周期，不回退主 runtime。CLI 写入受信任的工作区配置，不回退用户设置。取消终止提交前检查；安装事务一旦获准开始，需完整完成，取消视图忽略结果。

VS Code 捕获 daemon、规范工作区和选定会话。侧栏激活通过带 flow/request 关联的桥接访问捕获工作区，验证运行时同步后只更新捕获会话。初始引导不能发送未注册的 Web Shell client ID。重新 bootstrap、会话/工作区变化、daemon 替换和视图销毁均终止归属。短生命周期账号 client 保留原 daemon 地址和 Token，晚到的登录请求仍向正确 daemon 取消。

退出/升级命令使用原生状态行及完成/重试操作。开发开关启用命令菜单后仍需查询实际 daemon 能力。冷启动等待 bootstrap，并限制超时、清理销毁/错误路径。不能替换进行中的账号操作，不可取消的退出必须完成并同步结果。日志只记录安全错误码、HTTP 状态和操作名。浏览器拒绝打开时提供重试。

## 协议与凭证安全

| 用途            | 接口                          |
| --------------- | ----------------------------- |
| 设备授权        | `POST /api/oauth/device/code` |
| Token 兑换/刷新 | `POST /api/oauth/token`       |
| 身份/会员       | `GET /api/oauth/userinfo`     |
| 撤销            | `POST /api/oauth/revoke`      |

预发认证域名为 `https://pre-auth.qwen.ai`，OAuth `client_id=qwen-code-cli`。浏览器授权链接为 `https://pre4-chat.qwen.ai/authorize?user_code=<code>&client=qwen-code`；网页 client 与 OAuth client_id 不同。购买统一使用 `https://pre4-chat.qwen.ai/?memberPlan=qwen_code`，不带设备码参数。此网页入口已于 2026-10-29 对照 qwen-chat-fe 的 feat/qcode_authorize 提交 127d20ad8 确认，需要网页登录。

Core 负责私有权限的原子存储、恢复、跨进程刷新锁和撤销。宿主只在有效 `QWEN_HOME` 相同时共享会话。会员与旧 OAuth 分开存储；刷新替换完整 Token 对；Token 和设备码不进入 GUI 响应。

推理固定使用 `https://pre-api.qwen.ai/compatible-mode/v1` 和 OpenAI Chat Completions。配置仅保存鉴权选择、模型 ID、固定网关及凭证占位符。传输边界注入 Bearer Token，保留代理/取消，在发凭证前拒绝重定向或其他目标。HTTP 请求在凭证锁外运行；401 时刷新被拒 Token 并重试一次，在锁内比较当前/被拒 Token，避免重复轮换。403/404/429 不刷新，已开始交付的流不重放。缺失凭证直接失败，不隐式授权；退出清除后续请求缓存凭证。

## 思考与搜索

复用 ModelReasoningControls 和现有 session/ACP reasoning 设置。会员 `qwen3.8-max`、`qwen3.8-flash` 关闭时发送顶层 `enable_thinking: false` 且不带预算；低/中/高发送 true 和 4096/16384/32768，已有 xhigh/max 映射高档。移除冲突 reasoning/reasoning_effort 和嵌套 chat-template 思考开关，保留无关选项。显式原生预算继续有效，单次请求关闭移除预算，仍遵守强制思考元数据。未操作默认值、未知模型和其他供应商保持原样。

Max 已声明共用 UI 能力，Flash 只有请求映射，不增加能力声明。默认强度仍需产品确定。真实 Max 网关已接受关闭和三档预算，关闭无 reasoning_content、开启有；这证明参数接受和开关行为，不证明长推理预算严格执行或 Flash 支持。会员搜索复用现有 MCP 后端，动态注入 Bearer Token，HTTP 401 时刷新被拒 Token 并仅重试一次，取消归属工具请求。详见[会员 MCP 联网搜索](subscription-mcp-web-search.zh-CN.md)。

## CLI 成功提示与账号命令

两种渲染器激活成功后返回对话，追加账号、确认套餐和所选模型的用量提示，并从当前 Config 同步模型显示。只展示确认的 Plus/Pro，确认前不猜套餐。遵守隐藏提示和读屏设置，省略默认会员标题空行，保留自定义副标题。OpenTUI 保留完整提交元数据/接收结果和规范历史元数据。

会员输入提示 `/usage`、`/status`、`/upgrade`、`/logout`，各命令独立下划线。Usage 是已有 CLI 本地统计，不是服务端剩余额度。仅开发模式的交互升级命令打开统一套餐页，禁止或打开失败时保留可复制 URL。仅开发模式的交互退出命令限主响应空闲时执行；本地退出成功后取消后台 agent/侧问，清理会员运行时、模型/鉴权缓存及所选会员设置，再返回登录选择。保留其他供应商 API Key 和配置；本地清理失败不能清空当前运行时。现有 `/auth` 保持原有行为。

## 开发与验证

CLI 执行 `npm run dev`；GUI daemon 继承 `DEV=true` 和 Core oauth-config.ts 的固定预发配置。构建/打包后用 `node packages/vscode-ide-companion/scripts/copy-bundled-cli.js` 同步 VS Code；桌面包执行 `npm run build:runtime` 再 `npm run dev`。已有 daemon 需重启加载代码/环境；发布前替换为确认的生产配置。

定向覆盖授权期限、无重新授权的恢复、Retry-After、轮换/撤销/清理、完整列表与下线模型、激活生命周期/归属、两种渲染器、默认供应商、本地化桌面导航、侧栏桥接、序列化思考参数、流式请求和其他供应商。使用可丢弃凭证与本地 HTTP fixture，不退出开发者真实账号；测试计划/结果放在忽略的 `.qwen/e2e-tests/`。交付前构建、类型检查、打包并审查完整 diff。

2026-10-29 已记录真实 Pro Token 的 SDK 流式/非流式冒烟，返回 HTTP 200、OK 和 usage，仅证明 SDK 对话链路。原生宿主完整 OAuth、浏览器/购买生效、agent/工具流程、额度/错误契约、逐模型思考支持及长预算执行仍需验收；本地模拟和构建不证明部署或生产可用。
