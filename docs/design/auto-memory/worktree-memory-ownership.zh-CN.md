# 任务 worktree 的项目自动记忆归属

[English](worktree-memory-ownership.md) | [简体中文](worktree-memory-ownership.zh-CN.md)

## 存储与会话归属

在 worktree 中启动任务时，应保留发起任务的工作区已有的项目知识。
私有项目自动记忆按既有规则编码归属路径，存放于
`<memoryBaseDir>/projects/<编码后的绝对归属路径>/memory/`。
会话以启动目录或 daemon 注册工作区为归属。直接从 linked worktree
启动的新会话以该目录为归属。运行输出目录和记忆基目录覆写继续生效。
已有库保留原有位置。

分别维护记忆归属、当前检出与会话存储。`--worktree` 切换 cwd 前捕获启动路径。
工作区会话、恢复的 worktree 会话与子代理切换检出时保留归属。
代码与 Git 跟踪的团队记忆使用当前 worktree，本地记忆模式使用当前目录。
在任务 worktree 内执行 `/cd` 时保留归属，离开 worktree 或在普通会话中切换目录时
绑定目标目录并刷新记忆上下文。会话记录、sidecar 和恢复沿用既有查找顺序。

daemon 启动工作区前检查已注册工作区在同一实际记忆基目录下是否有相同编码。
若另一工作区路径的编码冲突，则拒绝启动并提示配置独立运行目录或调整路径。
原工作区及其现有库保留。

## 写入、恢复与召回

按实际库串行提交项目主题变更，进程内 FIFO 排队，进程间用共享短锁互斥。
在锁内比较操作读取的主题版本和当前版本。更改任意主题前在磁盘上记录待重建标记，
生成的索引成功发布后才清除。使用有待重建标记的索引前先修复。
运行时根据主题生成项目 `MEMORY.md`，并拒绝直接编辑生成文件。
Dream 可在提交锁外持有独立整合锁。模型调用与等待确认在提交锁外进行。

提取任务按记忆库依到达顺序排队，仅合并同一会话的待处理任务。
用有界会话表保存偏移量，升级时保留原单会话偏移量。
在提交锁内合并游标和元数据更新，保留待重建标记以及时间单调性。
常规写入、forget、Dream 删除、元数据升级和迁移均校验版本。

磁盘索引和标准提示预算为 200 行、25,000 个 UTF-16 代码单元。
当前模型的上下文窗口小于 128K 时，加载的项目索引最多 100 行、12,500 个代码单元。
保留所有主题供按需读取、结构化搜索与 Dream 整理。

## 显式迁移

`/memory migrate-worktree <旧路径>` 接受显式指定的一个旧检出路径或记忆目录。
运行时使用同一编码规则映射检出路径，拒绝超出所选记忆基目录的库及不安全的链接，
并将调用会话的项目记忆库固定为目标。不带源路径时，命令会提示输入具体路径。

隔离的模型请求读取源和目标的快照，由模型选择新增与更新并处理重复与冲突。
快照需要在 512 KiB 和当前模型的上下文窗口内装入单次请求。
模型只返回结构化提案，无法执行工具。请求与输出均不进入主对话和后台提取。
运行时展示源库、目标库、变更和冲突，并要求明确确认。取消时丢弃提案。
确认后在提交锁内复检目标库和相关版本，仅应用展示获批的方案。每条主题单独原子写入，源库全程只读。
启动时不扫描历史库，也不调用模型执行迁移。已有 Codex 导入命令继续管理其导入库。

## 验证

检查从仓库根、子目录和独立 linked worktree 启动，任务启动与按 ID 或标题恢复，
进入和退出 worktree、任务子代理，以及在 worktree 内外切换目录。
验证 daemon 中分支和重启后的工作区隔离，并拒绝编码冲突的注册。
覆盖同一主题和不同主题的并发写入、三个会话排队提取、旧偏移量升级、索引重建中断、
加载预算及超过 200 个主题后的召回。使用隔离运行目录和可控模型验证取消时两库无变更、
确认过期编辑失败，以及仅获批主题进入目标库。
