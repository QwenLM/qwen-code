# Git Worktree 共享项目自动记忆

[English](shared-worktree-project-memory.md) | [简体中文](shared-worktree-project-memory.zh-CN.md)

## 问题与范围

[#18030](https://github.com/QwenLM/qwen-code/issues/18030) 描述了临时 Git worktree 中学到的经验无法在所属工作区的新会话中召回的问题。Standalone Git 会话应共享长期项目自动记忆。`qwen serve` 中独立注册的工作区继续隔离原生项目自动记忆，包括同一仓库下的工作区。聊天记录、用户和团队记忆及检出文件沿用各自位置。分支级有效性校验不在本次范围内。

## 归属与升级

Standalone 默认使用 `git-root`。非符号链接的主检出 `.git` 目录、注册和反链经验证的 linked worktree、`core.worktree` 匹配的子模块，以及 bare Git 目录，都能以真实 common Git 目录确立仓库身份。校验只使用 Git 元数据。移动后未修复反链的 worktree、损坏的元数据、符号链接 `.git` 和非 Git 目录使用路径独立库。非 bare 主检出使用独立 Git 目录而缺少反链时，保留自己的路径独立库，其合法 linked worktree 之间共享仓库库。直接从名为 `.git` 的独立元数据目录的父目录启动是首版不支持的用法，因为 Git 会把该父目录视作普通主检出。

仓库在记忆根目录中原子绑定唯一活动库。若规范库已经存在，初始化时优先选择它。否则，能直接验证归属的主检出可以沿用它的旧库。其他首次会话绑定规范库。并发启动以先发布的绑定为准，之后的会话沿用同一绑定。linked checkout 可提示未证实归属的候选旧库，待用户显式查看。之后从主检出启动可以验证主库归属并提示导入。符号链接别名可通过解析到同一检出证明旧库归属。历史库保留在原处。

Daemon 默认使用 `workspace`，归属在会话加入所选工作区时确定。创建、进入、分支或恢复任务 worktree 会继续使用该工作区的项目记忆。改变 daemon 会话的 cwd 无法选用其他注册工作区的记忆。Standalone 从启动期 worktree 的子目录运行时也沿用启动时的归属。Standalone 切换目录离开该 worktree 时按目标位置解析归属。团队记忆继续从当前检出解析。

## 并发写入与召回

每个活动库的短跨进程提交锁串行执行最终快照校验、版本比较、原子写入、删除与索引发布。Dream 和导入的生命周期锁先获取，项目提交锁在内层。模型调用在提交锁外执行。项目写入流程只修改主题文件，项目 `MEMORY.md` 由同一个运行时入口生成。同主题并发修改时比较读取时的版本。过期的编辑、遗忘、Dream 删除、迁移和导入提案会保留更新的内容。

后台提取按库和会话排队。同一进程内，不同会话按到达顺序提取，同一会话的待处理请求可合并。提取租约保证跨进程串行。升级单会话游标时保留原会话偏移量。游标提交与磁盘最新状态合并，成功重建索引后在同一次提交中清除待修复标记。项目元数据在提交锁内合并字段更新，时间戳保持单调。

生成的索引与标准启动加载上限为 200 行和 25,000 个 UTF-16 code units。上下文小于 128K 的模型最多加载 100 行和 12,500 个 UTF-16 code units。超限主题保存在磁盘上，可通过按需读取和结构化搜索召回，Dream 可整理重复或相关主题。

## 历史记忆导入

离线预览展示目标归属者、作用域和实际记忆目录，以及来源条目、稳定 ID 与成本估算。仓库作用域发现已校验的注册 worktree 及已确认归属的旧主库或符号链接路径。工作区作用域使用当前工作区自己的会话 sidecar 和 worktree 归属标记。已删除或无法验证归属的检出可用 CLI `--source` 指定。Daemon 在用户选择的可信工作区运行时内发现来源。

`qwen memory import worktree` 默认执行预览。`--scope` 优先于环境变量。用户针对该预览确认所选条目后才开始模型整理。worktree 条目只能导入项目记忆。任务身份包含目标三元组，重试和重启恢复都会重新校验。模型提出新增、重复、冲突或跳过的建议。首次发布和恢复发布都在提交锁内校验最终目标快照，再发布内容并重建索引。导入保留源文件和目标库原有主题。

## 验收

使用真实 Git 检出覆盖主检出和 worktree 首次升级顺序、并发绑定、符号链接启动、bare 和子模块 worktree、独立 Git 目录、损坏元数据及原子替换跟踪文件。验证新会话双向召回、同仓两个 daemon 工作区在 worktree 创建、分支和重启后的隔离，以及启动期 worktree 内外的目录切换。跨进程并发提交和索引修复，存入超 200 条主题后验证两种召回。使用独立运行目录验证预览、确认、重启与目标漂移，并对照操作前后的源文件和目标文件。
