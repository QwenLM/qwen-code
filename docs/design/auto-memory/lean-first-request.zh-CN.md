# 降低首问提示词开销

[English](lean-first-request.md) | [简体中文](lean-first-request.zh-CN.md)

## 问题

文件式自动记忆会在每次主模型请求中携带完整写入规则，包括只读回合。新会话也会发送空索引目录。通用模型的系统提示词会给普通问答附带操作示例。在此前的固定首问样本上，本地估算草案可节省约 1,720 token。该样本的 provider 用量未知。

## 设计

- 在文件式记忆的常驻提示词中保留已启用的记忆目录、召回和时效校验规则，以及显式记住或忘记的触发方式。在显式写入、更新或忘记前加载内置的 `memory-policy` Skill。Skill 保留现有的元数据、作用域、查重、索引和团队规则。
- 仅在选中官方内置 Skill、Skill 已启用且会话具有可用调用路径时使用短提示词。Skill 缺失、禁用或被同名版本遮蔽时，采用现有的内联写入规则。结构化会话使用现有工具。
- 所有已启用索引为空时省去初始目录。历史中已有非空目录时，删除最后一条记忆后记录一个空快照，以取代旧目录。非空目录保留来源标签、截断限制和提醒转义。
- 通用工具调用格式默认省去示例，保留显式 `QWEN_CODE_TOOL_CALL_STYLE=general`、专属模型格式和 Code Mode 示例。精简风险操作段落，保留授权、无交互时停止、保护现有工作和遵守安全检查的要求。

## 验证

使用受控的 OpenAI 兼容 provider 驱动 CLI 和 ACP，检查出站请求、工具结果及记忆文件。覆盖全新空会话、新增条目、删除最后一条、恢复会话、重新加入条目。覆盖 Skill 缺失、隐藏、禁用、同名遮蔽，以及元数据、查重更新、遗忘和作用域。验证通用默认、显式通用、专属模型和 Code Mode 提示词。

真实模型基准每个场景运行五对全新会话，交换顺序，固定题目、模型、配置、权限及初始记忆。分别报告 provider 首个主模型请求的实际用量和各组件估算。显式记住、更新和忘记回合计入所有工具往返和重试。在同一估算器和冻结首问样本下，目标为改动组件净省至少 1,200 token。合入条件是五对首问的 provider 输入都下降，普通问答的 `memory-policy` 调用为零，记忆与授权行为检查通过。报告显式写入整轮成本及抵消该开销所需的普通首问数。
