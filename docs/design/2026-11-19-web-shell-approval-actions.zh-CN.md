# Web Shell 审批操作

[English](2026-11-19-web-shell-approval-actions.md) | [简体中文](2026-11-19-web-shell-approval-actions.zh-CN.md)

## 问题

共享审批卡片在底部为每种权限范围都展示一个按钮。用户审批工具调用时，需要一眼分清单次决定和范围更广的授权，在窄屏上也能区分。

## 设计

- 将拒绝和同意主操作放在右侧。主按钮提交单次允许选项。有多种允许方式时，主按钮右侧的箭头展开菜单，列出请求提供的所有允许范围。
- 优先使用普通的单次允许选项，退出规划模式时优先使用手动审批选项。模式变更和更广的授权范围在菜单中显示。只有持续授权选项时，主控件打开菜单。选项类型缺失或有多种拒绝范围时，沿用原有列表。
- 保留现有初始焦点、原生按键激活、关闭行为和提交防重。菜单打开时，Esc 先关闭菜单。数字快捷键只作用于可直接提交的可见操作。复用共享 portal，提交原始选项 ID。

## 验证

覆盖单次允许、持续授权、规划模式、禁用和切换请求。用浏览器验证桌面和窄屏的菜单与焦点行为，并覆盖嵌入式和浮层审批卡片。
