# macOS 覆盖式标题栏

## 问题

桌面壳通过 Tauri 的默认可见标题栏以编程方式创建窗口。在 macOS 上，标题栏会占用 Web Shell 上方单独的一行，形成一条贯穿窗口的空白区域，与 Codex 等应用采用的一体化布局不一致。

## 设计

保留原生带装饰的窗口和红黄绿窗口控制按钮，但将 macOS 窗口配置为 `TitleBarStyle::Overlay`，并隐藏标题文字。这样 WebView 可以绘制到原生标题栏下方，而无需依赖透明窗口的私有 API。

原生壳会在启动页或由 daemon 提供的 Web Shell 运行前注入一个布尔标记。Web Shell 根据该标记添加仅适用于 macOS 的拖拽区域和 38 px 内容留白。侧边栏和主区域的背景仍绘制到顶部边缘，同时交互内容不会与窗口控制按钮重叠。启动页添加相同的拖拽区域，但其状态卡片居中显示，因此不需要额外的内容留白。

本地启动页和远程 loopback Web Shell 的 capability 都获得窗口拖拽权限。浏览器托管的 Web Shell、移动端布局以及 Windows/Linux 桌面窗口不会收到该标记，因此保持现有布局不变。

## 验证

- 在启动页和 Web Shell 加载完成后，分别对两种主题截取固定尺寸的 macOS 截图并进行比较。
- 确认侧边栏和主区域绘制到窗口控制按钮下方、原生标题文字已隐藏，且没有控件与窗口控制按钮重叠。
- 从顶部空白区域拖动窗口，并验证关闭、最小化、缩放、全屏和窗口位置恢复行为。
- 运行 Web Shell 定向测试以及桌面壳测试和构建验证。
