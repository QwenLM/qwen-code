# 订阅生图与 ASR 接入

[English](subscription-image-asr.md) | [简体中文](subscription-image-asr.zh-CN.md)

## 范围与现状

Qwen Account 对话已使用设备凭证，生图仍要求 API Key 环境变量，语音选模只支持
API Key 和裸模型 ID。本次按网关协议接入账户生图和普通录音转写，不自动选模，
不回退到其他 Provider。参考图编辑和实时 ASR 不在本次范围内。

## 设计

每次主模型选模请求 `/models`，每次场景选模请求 `/models/scenes`，包括直接指定
模型的命令。仅已登录账户请求订阅目录。场景目录保存在现有账户凭证文件，按账号
revision、OAuth 环境和客户端隔离。启动只恢复缓存，缓存缺失也不补拉场景目录，
仅进入选模时刷新目录；临时请求失败保留成功缓存并
提示回退。成功的空目录替换旧条目。退出登录删除凭证和目录，保留显式模型设置。

区分对话与场景资格，生图和语音专用模型不能成为主模型候选。API Key 候选继续
来自本地配置。imageModel、voiceModel 保存带路由的选择，必要时携带端点，并兼容
无歧义的旧裸 ID。未选择即不启用，切换主模型不修改辅助模型设置。

调用时从账户会话获取 token，复用刷新机制。token 不写入模型设置，也不发送到
用户配置的第三方地址。生图使用固定网关 `/api/v1/services/aigc/
multimodal-generation/generation` 同步接口；普通 ASR 使用
`/compatible-mode/v1/chat/completions`、`stream: false`、音频格式和 base64
Data URI。完整编码请求不得超过网关 8 MiB 限制。两种下发的 ASR 模型统一使用
该协议，由网关转换上游格式。保留现有 API Key JSON 和实时实现。

会员、计费和额度由网关判断。辅助调用不要求先激活订阅主模型。复用现有鉴权和
请求错误处理，不静默切换计费路由。名称使用服务端值，缺失名称回退 ID，
不显示订阅模型的 description。

两个目录都读取可选的 `thinking_strength` 并写入账户缓存。有效档位和顺序用于
思考强度选项；包含 medium 时默认 medium，否则默认首个档位。字段缺失或为空时
兼容原客户端默认值。按协议 2.3，`budget_tokens` 仅用于展示，保留现有路由的
请求参数和预算映射。目录刷新时同步更新运行中的 reasoning snapshot，选项与
后续请求无需重启即可使用新档位。保留显式关闭思考和 API Key 原有行为。

主目录与场景目录中的同 ID 模型使用最近一次成功请求的思考元数据，重启后也应
保留该结果。旧主目录缓存不能遮蔽新场景元数据，主目录刷新也应替换旧场景思考
元数据。模型是否属于主目录、哪些场景仍分别保留。

Web Shell 在打开语音选模或通过 `/model --voice <id>` 直接选模时显式刷新场景
目录；常规语音状态轮询只读取缓存。
异步刷新前后保持 legacy-primary 与 workspace-qualified 路由的归属和 generation
检查。

## 涉及组件

账户目录 schema、会话存储、模型注册表与配置、选模命令和弹窗、生图配置/工具/
服务、语音选模与转写、Serve 语音调用方。各调用方共享路由解析。

## 验证与验收

覆盖重复刷新、缓存回退、空目录替换、账户切换、主模型和场景隔离、带路由和旧
选择器、调用时 token 刷新、端点与请求体、显式选择、取消、超大音频及 API Key
回归。运行针对性测试、构建、类型检查和打包；使用隔离配置验证全局 CLI 基线和
本地制品。区分 Mock 协议验证与真实网关联调。
