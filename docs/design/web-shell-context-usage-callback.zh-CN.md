# Web Shell 上下文详情打开回调

[English](web-shell-context-usage-callback.md) | [简体中文](web-shell-context-usage-callback.zh-CN.md)

## 问题与范围

Composer 上下文用量的 hover 操作会打开 Web Shell 右侧面板。嵌入宿主需要
改为打开自己的详情界面。主会话和分屏已共用一个详情打开入口，内置页头和
自定义页头也使用它。

## 设计

为 `WebShellProps` 添加 `onContextUsageOpen?: (sessionId: string) => void`。
提供回调时，共用入口将来源会话 ID 传给宿主，并在创建或选中内置面板标签前
返回。不提供时保留现有行为。`WebShell` 和 `WebShellWithProviders` 通过
现有公开类型暴露此参数。

回调适用于 composer 详情和页头详情入口，包括分屏。它不拦截圆环的
`/context` 快照操作、压缩操作或已持久化面板标签的恢复。它是打开行为的
替代，而非通知；无需返回值协议或额外 UI。

## 文件与验证

修改 `client/App.tsx`、现有测试和包 README。测试主会话与分屏 composer
的回调及会话归属、不创建面板或自动读取详情、回调替换和移除，以及默认打开
行为不变。已有 popover 测试覆盖 hover 操作连线。执行构建、类型检查、
定向测试，以及使用模拟 daemon 的浏览器冒烟验证。

## 验收与风险

宿主每次详情操作收到一次对应会话 ID，并自行决定展示方式。未提供回调时
仍打开现有右侧面板。共用入口也会重定向页头操作，这是明确记录的预期行为。
不改变 daemon 路由或数据协议。无待决问题。

## 历史快照折叠

消息卡片默认展开。在「历史快照」后添加图标按钮，收起标题行以下的全部内容；
展开后恢复现有卡片。使用共享 Button、已有中英文展开/收起文案及 Lucide 箭头。
正文保持挂载但隐藏，保留内部明细的展开状态。按钮提供 `aria-expanded`，
支持 Enter 和空格操作。状态仅属于当前挂载的卡片，不增加持久化或宿主选项。
右侧面板的 compact 内容没有快照标题和折叠按钮，保持显示。

验证默认展开、收起后只保留标题行、键盘重新展开、切换不请求上下文以及 compact
渲染不变。扩展已有浏览器上下文压缩场景，并检查展开/收起截图。
