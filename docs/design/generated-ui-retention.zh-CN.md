# Web Shell 中的 Generated UI 保活

[English](generated-ui-retention.md) | [简体中文](generated-ui-retention.zh-CN.md)

## 问题与范围

转录卡片重新挂载会重建 iframe 和 Worker，丢失已应用结果、未应用输入、动态控件和
guest 状态。本设计在同一浏览器页面中为符合条件的内置 Generated UI 激活实例保活，
覆盖虚拟列表、历史导航、同工作区导航、新任务和主视图/分屏交接。

普通 MCP Apps 和手动安装的扩展保持原有生命周期。刷新、关闭页面、导出和派生会话
不会保存或转移活实例。不持久化交互快照，不新增 daemon 路由或协议字段。

## 身份与归属

记录的键包含 daemon/凭据/工作区 scope、会话、生产者工具调用 ID、服务端和资源 URI。
独立调用和复制的会话不会共享激活实例。单独的资源键包含 bootstrap HTML、参数/结果、
权限、CSP、daemon epoch 和宿主能力。资源变化会释放实例并要求显式重开。
通过 memoization 避免在无关渲染中重新序列化完整 bootstrap。

Provider 将 session client 绑定到原 scope。在重连和分离期间，daemon 已确认的规范 cwd
仍是身份依据；请求路径的别名不会因传输故障生成新 scope。真正切换宿主、凭据或工作区
会退役原 scope。绑定守卫不得将旧 client 重新指派给不同的 scope。
通过 action 创建的 client 仅在 scope 与 daemon 的规范 cwd 匹配后绑定。创建成功后、
attachment 前的 connected 渲染不得将其绑定到请求别名的临时 scope。

## 停放与授权

页面拥有一个 store，以及位于主文档和 portal 根中的隐藏、inert 停放宿主。活容器只在
同一根中、仍连接的元素间通过原生 `moveBefore` 移动；空容器可以使用 `appendChild`。
浏览器不支持或无法移动已填充容器时，释放实例，不声称保持连续性。跨根交接不能保留实例。

每次只有一个可见的转录 slot 拥有实例。隐藏、折叠、卸载或清空会话会同步撤销 lease。
新任务仅停放，不删除。返回时要求当前 owner、匹配的启用回执及兼容资源。每次宿主调用
在 await 前后检查 lease，并将调用的 abort signal 与 lease signal 组合。

隐藏会取消待确认的消息审阅。已派发的分析继续在原会话中执行；导航和重置不会重发分析，
也不会声称将其取消。停放期间的尺寸通知不能改变返回后的高度。

## 上限与失效

最多保留四个停放实例，淘汰最早停放的实例。每次停放最多 15 分钟，同时通过定时器和
绝对时长校验。所有根共享这些上限。最多追踪 128 个身份；之后的卡片只能显式打开，且不保活。

策略事件和明确禁用的回执会释放匹配 scope 的实例。SDK 同步报告每个已校验且仍有效的
禁用回执，并向较晚订阅者重放最新的撤销版本。工作区 owner 在读取 context 前订阅，
因此后续启用回执或 React 批量提交不能抹去已确认的撤销。缺失/失败的回执撤销权限，但不代表
已确认策略撤销。认证失败释放实例但保留身份记录，避免恢复后静默重启。删除、回退、epoch
变化、淘汰、过期和资源变化也保留释放记录。只有真正退役 scope 才遗忘其记录。

已释放且仍符合准入条件的卡片提供 **重新打开交互视图**。**重新打开并重置** 也可重置
保活、已停止或失败的卡片。两者均从保存的原始内容创建新实例，并显示交互丢失提示。

## 验证与验收

- 在仍符合保活条件时，新任务、受控空会话导航、虚拟列表、历史和临时加载失败后的成功
  重试，保持真实 realm、Worker、已应用结果和未应用输入。
- 规范 cwd 重连保持 scope 和 owner source 稳定。真正的 scope 变化和外部 scope 保持隔离。
  创建可以在 attachment 前提交；连接后的 client 仍须拥有规范 owner，并在首次 prompt
  后保留激活实例。
- 禁用的 load/context 回执及已连接流/heartbeat 的访问失败会释放运行时。已释放卡片恢复
  后需要显式重开。在同一次 React 提交前先收到禁用、再收到启用回执，仍须释放旧实例；
  过时或属于其他会话的回执不得释放另一 owner 的实例。
- 隐藏的主视图/分屏（包括 artifact 全屏和会话缺失状态）拒绝工具/消息 RPC，同时保留
  符合条件的运行时身份。
- 重开只重置目标实例；其他卡片和独立分屏保留 frame 与未应用值。普通 app 移除即关闭。
- 单元/DOM 测试覆盖 lease、资源变化、重置、准入拒绝及上限。原生 Chromium 测试验证
  frame/Worker 连续性及宿主 RPC 拒绝；单独的 DOM 移动 shim 无法证明浏览器连续性。

浏览器必须支持保状态移动。Firefox/WebKit、在线模型质量和长期内存压力仍不在本次变更的
验证范围。保活的 Worker 仍受已有执行预算约束。
