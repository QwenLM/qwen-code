# 活跃 ACP 会话中的 MCP 连接恢复

对应 [英文设计](./2026-09-08-pooled-mcp-recovery.md)；问题：[issue #11272](https://github.com/QwenLM/qwen-code/issues/11272)。

## 复现与责任划分

基线 `bb79319ce5e0e2bbe64307c50dc3621621afc25c` 使用本机 `qwen serve`、ACP WebSocket、确定性模型端点和记录 PID、调用次数的 stdio MCP 服务验证。普通取消会发送 `notifications/cancelled`，子进程存活，两个会话可以继续使用工具。让测试服务收到取消后退出，或输出无效 JSON-RPC 帧，会造成连接状态失真或注册丢失。这些受控故障不能证明原报告中的钉钉环境采用相同的断开机制。

工具调用持有参数、取消信号和一次权限决定；响应丢失时，服务端可能完成了副作用。连接池按传输配置指纹持有 transport 和进程，负责清理进程及其后代。会话持有连接引用，以及按权限和配置过滤的工具、提示词与资源注册。连接池删除条目后，会话仍然存在，因此需要在下一次模型请求前恢复注册。

## 设计

1. 对连接池管理的客户端，把意外 SDK close 转成断线状态；主动 disconnect 受 `isDisconnecting` 保护。非池化客户端保留原有健康监控语义。发现期间发生断线时拒绝部分结果，避免一个成功的列表掩盖另一个列表中的连接关闭。
2. 持有的连接失败，或取得句柄后在登记监听前发现连接失败时，记录服务名和传输指纹作为恢复候选，不保存或重放工具调用。主动断开、移除和停止清除候选；首次获取连接失败不创建候选。
3. ACP 和子 Agent 在模型请求前按需恢复。检查工作区信任、禁用状态、待审批状态、传输指纹和工具权限；等待连接返回后复查配置及权限。取消只结束当前调用者的等待，不取消其他会话共享的连接创建。
4. 同一会话的发现、恢复和运行时添加串行执行。每个发现请求保存自己的失效服务集合；停止、移除和主动断开使旧请求失效。旧请求对目标服务停止读写，避免删除后续添加建立的连接；新的显式刷新在旧请求之后执行。添加成功时清理失败记录，添加失败和未执行移除的请求保留原恢复记录。连接池沿用共享创建协调，替代连接等待旧条目清理；非池化 HTTP/SSE 的等待范围为会话与传输指纹。关闭流程在既有期限内包含已移出池的清理任务。
5. 池投影工具禁用调用级重连与重放。子 Agent 注册表保存来源，在模型请求前恢复来源并刷新继承的 MCP 对象；子 Agent 的配置覆盖继续拥有自己的发现过程。继承工具经过子 Agent 的配置和权限检查。停止时移除来源引用，阻止迟到刷新重新填充注册表。
6. 恢复后刷新模型工具声明及 ACP 提示词命令。提示按服务的相邻状态去重，保留“成功→失败→成功”的变化；继承父连接的子 Agent 与资源读取保留来源 manager 的 ACP 提示。拥有独立发现过程的子 Agent 将提示保留在自己的 manager；转发到 ACP 的事件机制不在本改动内，其失败可从调试日志和 manager 状态观察。取消期间产生的提示保留到后续请求。恢复异常按尽力而为处理，不阻止普通模型请求。

运行时添加与恢复使用相同的有效配置，包括 stdio 的隐式工作目录；配置覆盖保留原始形式，以便跟随工作区迁移。`mcp.serverCommand` 占用的合成名称 `mcp` 不允许运行时添加覆盖。关闭旧 transport 时结束旧 SDK 请求并移除回调，避免迟到的 close 清除新 transport。句柄释放检查自身身份，旧句柄不能删除新的会话注册。

父子注册表可能共享逻辑会话 ID，因此池订阅使用逻辑会话 ID 与 ToolRegistry 身份共同区分。父子注册表各自接收失败通知、释放自己的注册；关闭逻辑会话时清理其全部订阅。声明 MCP 配置的子 Agent 使用独立的提示词与资源注册表，子 Agent 清理不会删除父会话的注册。继承父配置的子 Agent 通过来源注册表的 manager 读取资源，并更新调用方持有的工具副本；等待恢复后复查来源关系及各层子配置的资格。执行过独立发现的 manager 负责其配置服务，包括失败与主动断开的服务；即使 HTTP/SSE 配置与父会话相同，资源也必须来自自己的 MCP 会话。独立配置覆盖比较生效的 stdio 工作目录、传输与会话策略；共享同一原始配置对象的普通子 Agent 保留向来源借用连接的行为。旧式命令生成的 `mcp` 配置优先于同名原始条目；命令相同的普通借用者保留来源工作目录。

资源读取通过池恢复请求中指定的服务，不触发无关服务恢复，不创建私有客户端。池条目失败时可以保留恢复候选；主动重启中的客户端即使暂时断开，也保留其会话引用。主动关闭的条目不成为恢复候选。工具收到连接故障时保留“结果未知、没有重放、核实结果后重试”的说明；没有全局状态记录不等于观测到断线。客户端不重放并不能保证模型未来的决策不会产生重复业务操作。

传输获取失败或会话接纳失败启动共享的五秒冷却；预算拒绝不启动传输冷却，容量释放后可再次尝试，并保持预算提示。显式管理发现与重启不受这项冷却限制；即使另一个会话存在健康池条目，该冷却仍可能延迟其恢复。冷却定时器只清理记录，不发起连接。局部恢复保留其他服务的预算拒绝记录，成功后清除本服务记录；完整发现重新计算拒绝集合。状态快照保留尚未解决的拒绝，拒绝事件只包含当前新拒绝的尝试；成功恢复不发布空拒绝事件。对外 refs 字段继续计数逻辑会话，不计父子 registry 的内部席位。

运行时删除和添加失败通过连接池释放未使用的预算预留。连接池检查同名服务的存活条目和创建任务；其他会话持有同名服务或空闲进程正在等待退出时保留预算，避免健康连接存在但预算被清空。移除操作不承诺在进程退出前释放容量。

## 现有管理接口与范围

调查时 PR #7309 为 open，负责工作区运行时管理、认证、审批和显式重启入口。当前 main 拥有工作区 MCP 池与重启路由，本修复复用它们。#11145 处理工作区预热后的首次发现，本修复只处理曾持有连接的恢复。

本改动不新增管理路由、命令、鉴权方式或通用重试框架。运行时管理、审批、认证和显式重启沿用现有入口；`QWEN_SERVE_NO_MCP_POOL=1` 关闭池后使用原有单会话恢复。

## 验证契约

以工具调用计数、PID、实际资源结果和后续模型请求中的工具声明判断成功。覆盖普通取消、取消后退出、独立进程退出、多会话并发、冷却、禁用与审批、迟到连接、发现超时、运行时添加移除、子 Agent 和关闭清理。被取消的工具调用次数应为一。

## 审查跟进

发现和运行时添加在客户端重启期间保留活跃池条目的订阅。客户端暂时处于 CONNECTING 或 DISCONNECTED 不代表连接池归属终止；closed 和 failed 条目不被接纳。同配置添加更新已有投影，不释放订阅。替换失败时恢复原进程内运行时配置及其恢复路径，但服从本次请求自己的断开、移除和停止失效记录；后续排队请求不能恢复旧请求的回滚权限。

子代理 MCP 配置快照保留装饰后的元数据和继承配置的原始来源。只发现 SDK 服务时，其他服务保持父会话借用关系；SDK 覆盖失败不能在刷新时移除健康的继承扩展工具。子代理自己的覆盖在两种配置视图中具有相同优先级。

扩展元数据装饰会在每次读取时创建配置副本。借用关系通过原有配置合并与准入过滤获取原始配置来源；独立覆盖继续核对有效传输与会话策略，不增加配置缓存。工具异常判断优先读取本次调用的 SDK transport。没有直接客户端的池化 callable 根据错误证据判断，不使用按服务名记录的进程全局状态，避免另一条同名连接关闭时掩盖健康连接的业务错误或执行超时。

池投影使用未过滤的发现快照创建会话工具副本，并在测试中检查共享快照仍保留 standalone 行为。五秒冷却记录会过期，即使配置不再被使用；这些计时器只做清理。

恢复会延迟模型请求：stdio 发现默认三十秒，远端默认五秒，另有旧连接清理等待；五秒冷却不是回合期限。保留现有发现超时配置，不增加超时策略。池投影需要创建工具副本，不能宣称零分配。验证证据区分本机 macOS daemon、真实生产钉钉环境、Windows/Linux 进程行为和真实 OAuth 服务商。
