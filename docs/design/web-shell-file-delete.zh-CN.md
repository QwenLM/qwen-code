# Web Shell 文件删除

[English](web-shell-file-delete.md) | [简体中文](web-shell-file-delete.zh-CN.md)

## 问题与范围

Files 右键菜单已有预览、引用、复制路径和下载，但无法删除文件。为可信本地工作区
添加单个普通文件的永久删除，二次确认明确提示删除后不可恢复。本次不包含目录、
符号链接和 SSH 工作区删除。
普通文件删除与 main 已有的目录删除并存，各自受独立能力门控。

## 设计

- 添加可选的本地文件系统 `deleteFile(input)` 操作。在选定工作区内解析父目录，
  保留末级文件名，拒绝根目录、目录、符号链接和其他类型，仅使用非递归 `unlink`。
  复用写入的信任、运行代际检查、逐路径锁及文件系统审计，记录原始文件大小和
  忽略规则归因，在 unlink 前再次验证规范父目录。Node 的可移植路径 unlink 无法让外部进程替换父目录完全原子化，
  本次沿用既有文件系统变更边界模型。
- 只添加 `POST /workspaces/:workspace/file/delete`，使用严格变更鉴权和可信
  selected-runtime 解析。文件系统必须取自该运行时，不支持的工厂明确拒绝，
  禁止回退主工作区。返回确认删除的工作区相对路径，以 `workspace_file_delete`
  公布新接口能力，同步公开协议文档，并与其他文件变更统一删除请求的遥测分类。
- 添加工作区限定的 SDK 方法及可选 artifact 删除动作。要求删除和限定 REST
  两项能力、准确可信的所有者，以及非 SSH 的本地工作区。请求前后重新检查能力和
  所有权，防止过期处理器修改替换后的工作区所有者。
  从只读 transcript 构建中排除变更动作，保留既有体积预算。
- 仅在普通文件菜单中显示删除。复用带主题作用域的 AlertDialog，显示工作区文件
  绝对路径和不可恢复警告，默认聚焦取消，必须点击危险操作按钮才执行。取消和 Escape 不发起
  请求。删除过程中禁止关闭和重复提交，失败提示保留在弹窗内并支持重试。
  与既有文件夹确认流程共用弹窗，按文件/目录类型区分文案和接口，等待进行中的上传
  完成后才允许确认。
- 成功后从既有树移除文件，若其正在预览则清除预览，保留其他展开、筛选和选中状态。
  防止菜单恢复焦点抢占确认弹窗，关闭弹窗后优先恢复活动行焦点，无活动行时回退树
  容器。确认及请求结果绑定到文件树和工作区生命周期。

## 文件与决策

改动涉及 CLI 文件系统 intent、策略及实现、已有工作区写路由注册和能力列表，
SDK 限定工作区客户端，以及 Web Shell artifact 目标、文件浏览器和双语文案。
文件系统方法设为可选，因为已有 SSH/自定义工厂不支持删除。不引入 shell 命令、
递归删除、回收站或恢复功能、新依赖或旧主工作区删除接口。

## 验证与验收

先记录全局 CLI 基线，已安装 CLI 没有 Files 时回退最新 main 浏览器测试。
验证普通、二进制和空文件删除，目录/根目录/符号链接/越界拒绝，信任及关闭运行代际
保护、父目录替换、规范路径锁及审计字段；路由鉴权、不支持的工厂、目标工作区且
不回退，并验证主次工作区存在同名文件时的隔离；SDK 请求形状；过期 UI 动作；浏览器取消、
确认、忙碌、失败、预览清理，以及能力和符号链接门控。使用隔离真实 daemon
确认磁盘结果。捕获并目视检查实际确认和成功界面，明确标注模拟 daemon，图片
独立于实现存储。完成构建、类型检查、打包、定向测试、lint/格式及两轮干净差异审查。

## 待定问题

无。永久删除及明确的二次警告均为用户要求。
