## Independent discovery and association

Every actual-column predicate is independent OR discovery over all states. This is a proposed query contract, not executable/qualified SQL. A wide candidate is not authorized membership: validate whole original identity or prove a different owner. Wrong tenant/workspace/hash/binding/generation/harness/parent, missing/unparseable association, overflow/page gaps stay BLOCKED.

Never use INNER JOIN, ACTIVE-only/accepted-only/latest filters or only found-parent IDs to erase candidates. Independently enumerate parts, refs, publication children, ACK, recovery work and secondary ledgers. JSON-only association requires independently bounded full-field/table/tenant paging and strict complete parsing; substring matching is discovery only.

Automation command/channel delivery have no Session column: independently page bounded tenant domains and prove elsewhere using full schedule/result/request or claim/native-record/resource ownership; unresolved orphan remains BLOCKED. Shared definitions/defaults/grants/tenant parents and same-Workspace channel configuration are not automatically original work.

Use final primary-key keyset order below. RuntimeSession=(scope_key,runtime_session_id), execution=execution_call_id_hash after original V12 swaps. Recheck complete current membership/bytes on the same Connection. Ordered FOR UPDATE scans alone do not prove phantom exclusion or absent-row insertion fencing; explicit row/page/total-byte bounds, binary identity and overflow behavior require actual implementation/RC/RR qualification.

## Necessary prefix and real producer gates

P=broker tenant placement, R=retention tenant, G=current TRUE private predicate (generated profile OR retained runtime_request_key), not cached profile. Generic G consumers refuse private; native consumers validate original persisted pin/progress, not G as a grant.

Proposed necessary cut prefix to qualify: P→R→all slots by request_key→all bindings by request_key/binding_id→indexed current private pin/context→registration→physical holder→immutable intent→same-intent progress; then complete heads/journal/resources/refs→RuntimeSession membership→executions→all remaining explicit tables in declared fixed table/key order. No standalone activation table exists. This is a proposed obligation, not a claim every current producer follows it.

Pass active original Connection and already validated authority/progress into a narrow consumer; same DataSource alone is insufficient. No nested transaction/REQUIRES_NEW, late P/R after descendant B/head, RPC or physical IO in cut locks. Binding-only claim/renew/release must acquire the new prefix before B if control fields are fenced. After blocking lock groups and before mutation recheck fresh sameConnection DB time, fixed deadline, exact identity/versions/stage/head/resource membership.

FROZEN closes fresh native renew/resource/recovery/commit/read/execution/control writes. Sole pre-cut terminal exception consumes durable exact whole frozen request and original complete predecessor. Postcut exact retry takes persisted read-only observation before live assertion/acquire/renew; historical terminal validation cannot reuse active-only NativeHead unchanged. Empty sets need real accepted producer fences/qualified ranges; never fabricate unsupported rows or infer physical IO join from any-row rejection.
