# Managed SQL 查询与结果映射整理

[English](2026-10-14-managed-sql-query-cleanup.md) | [简体中文](2026-10-14-managed-sql-query-cleanup.zh-CN.md)

## 状态与问题

与[毫秒时间戳设计](2026-10-14-managed-sql-millisecond-timestamps.zh-CN.md)一同实现。以现行 32 表权威 baseline 和公开 API 为准。此前部分生产查询使用星号投影，多表查询中的字段未限定所属表，成功变更遗漏已有修改时间。请求回执还通过通用 Map 跨越 JDBC 边界。这些做法增加了结构演进和驱动差异的核查难度。

## 范围

将生产 Managed 表的星号查询改为静态明确列举的字段。限定多表查询字段。业务变更同步推进已有修改时间。Session 请求回执改为具名 Java record，并在其余恢复文档边界统一 JDBC 标量类型。

主键、外键、ACL、Actor 身份、幂等作用域、分页契约、恢复证据和 JSON 文档结构保持原有定义。物理时间字段命名与类型遵循链接的毫秒设计。本次处理选定的查询与映射规则，不代表已采用阿里 MySQL 章节的全部规则。

## 决策

### 明确字段投影

共享字段投影放在共享 Managed schema 实现旁。投影明确列出字段名，可附加内部表别名。不会从实际数据库发现字段，也不会在运行时展开 SQL 星号。完整恢复文档投影保留原来导出的全部字段；普通类型化读取可以选择更小的投影。通过权威 DDL 校验投影名称，发现漂移。

### 修改时间

成功业务状态变更在同一条 SQL 中更新 `gmt_modified`，使用数据库 epoch 毫秒。保留已有 CAS 条件、领取代次和幂等检查。被拒绝或过期的状态变更不能更新时间。

生命周期、存储 fence 和注册 upsert 仅在持久化值真正改变时推进修改时间。先计算该赋值，再修改其他列，使条件比较原有记录。同值重放保留修改时间和原始创建时间；首次插入记录真实数据库时间。

仅修改读取/唤醒水位或协调字段时，不改写明确用于衡量投影工作或唤醒调度的时间戳。不改变不可变日志/资源身份和创建时间。验证报告应记录保留的纯协调更新例外。

### 结果映射

Session 请求回执使用具名 Java record，显式读取身份、可空布尔和数值字段，替代 Map 强制转换。恢复与 CSI 文档保留原有版本化 JSON 结构。其 JDBC 解码器显式读取整数、布尔、二进制和文本，使文档类型不再由驱动 `getObject` 返回的类决定。业务时间戳为整数毫秒。布尔归一化保留 SQL 数值表达式的数值类型，生成的 CSI guard 始终解码为布尔值。不将原始 Actor 字节和不可变正文解码为文本。

将新合入主干的重放与排序修复适配到本 baseline 时，保留其语义：类型化命令回执携带记录者的原始 Actor key，Session 分页及其 V3 索引使用不可变的 `gmt_create`，relay 排序在创建时间和 Session 身份之后保留 `first_sequence`。V3 及其升级夹具与 V1 使用同一套改名后的时间列；这不增加对旧时间戳 baseline 数据库的迁移支持。

## 风险与验证

投影遗漏字段可能破坏 mapper 或丢失恢复证据。对照合并后的 V1/V2 baseline 校验全部 28 组共享投影，并运行已有回执、Session、输出、恢复和 Broker 仓库测试。映射后应保留可空值、字节精确身份和整数毫秒值。投影应保留新合入的 CSI authority 字段及其变更门禁。

先复现回执完成后修改时间未变化，再实施修复。验证成功完成推进时间，冲突或过期结算不改变记录，幂等重放保留已提交结果。使用不同 JDBC 整数表示和空值检查结果映射。

执行 Java 包检查和相关数据库契约测试，以及仓库 build/typecheck。真实 MySQL 证据与 H2 分开报告。完成连续两轮完整 diff 自审后再声明完成。

## 验收标准

- 生产 Managed 表读取没有星号投影。
- 修改的多表查询明确限定字段所属表。
- 成功业务变更原子推进已有修改时间，被拒绝的写入不推进。
- Session 回执使用类型化结果，保留身份和可空字段。
- 恢复文档标量类型和字节在支持的 JDBC 驱动间保持稳定。
- 不改变权威键与约束、公开响应格式和恢复/领取条件；时间存储遵循链接的设计。

## 本地验证

最终合并验证结果、测试数量和平台限制记录在[毫秒时间戳设计](2026-10-14-managed-sql-millisecond-timestamps.zh-CN.md#验证结果)中。生产 Managed 读取没有星号投影。原生测试覆盖回执、快照、渠道、Action、Task 事件、发布、恢复、CSI authority 和查询计划。纯协调更新的时间戳例外保留此前的调度语义。这是本地 SQL 验证，部署验收不在本次修改范围内。
