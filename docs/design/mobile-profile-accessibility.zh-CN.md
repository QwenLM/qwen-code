# Android 连接配置的无障碍支持

[English](mobile-profile-accessibility.md) | [简体中文](mobile-profile-accessibility.zh-CN.md)

## 问题和范围

原生连接列表重复显示 Connect、Edit 和 Delete，但每个操作的无障碍标签没有标明
所属配置。编辑器的可见标签未与输入框关联。校验信息缺少实时区域语义；当大字体
或较矮的横屏窗口把控件挤出可见范围时，存储恢复页面无法滚动。

此后续变更仅涉及原生配置管理，不改变 WebView 设置、字体缩放、凭据、daemon API
或连接恢复。Activity/进程恢复以及完整 Web Shell 的无障碍支持属于后续工作。
Chromium 已根据系统字体缩放设置初始文本缩放，本次变更不覆盖该行为。

## 设计

保留现有按钮的可见文本，为每个配置操作添加包含操作名称和配置名称的本地化
无障碍描述。这样，直接在按钮之间导航的用户也能获取上下文。配置名称已经可见；
凭据值不得进入这些描述。

为每个编辑器输入框生成视图 ID，并通过 `labelFor` 关联现有的可见标签。保留
输入提示、密码转换、禁用状态保存和禁用自动填充的行为，不把令牌复制到标签中。

将编辑器校验信息和存储失败说明标记为 polite 无障碍实时区域。这样可以向无障碍
服务提供语义信息，而不打断当前朗读。设置这些属性本身并不能证明某个服务会朗读
每次更新；实际 TalkBack 行为需要单独的手动验收。

使用 `ScrollView` 包裹存储恢复页面，与其他原生页面保持一致。Retry 和 Reset
保留原有行为和确认流程。页面必须在系统字体放大和横屏模式下保持可操作。

## 文件和验证

产品代码仅修改 `packages/mobile-shell/app/src/main` 下的 `MainActivity.kt` 和
`strings.xml`。设备测试验证不同配置操作的标签、字段与标签的关联、密码语义、
实时区域元数据，以及恢复页面可滚动且其控件可访问。仍需运行现有 JVM 测试、
debug/release 编译和 Android lint。

在模拟器上使用合成配置运行基线 APK 和修改后的 APK，捕获连接列表、编辑器错误，
以及大字体/横屏存储恢复页面的原生无障碍节点和截图。检查保存、编辑、取消删除及
恢复操作是否出现回归。记录 API/提供程序和实际运行的测试。不得把节点检查称为
真实的 TalkBack 测试，也不得从模拟器结果推断实体设备已通过验收。
