# 有界 CUA 观察

[English](cua-bounded-observations.md) | [简体中文](cua-bounded-observations.zh-CN.md)

## 问题与范围

较长的 macOS AX 树达到遍历上限后，每次观察都会丢弃 revision 基线。即使捕获到的界面
没有变化，重复全量树也会持续扩大模型上下文。

依赖顺序为 #11683 → #11705 → #11735（本次增量）。直接基线是
#11705（`54d75e88401c598c7027ec11c4a5cfbf9892ee3a`），它基于
#11683（`9ad582281de6d79350b255a63b7f7757e14ec11e`）。前两层修复了嵌套捕获完整性
字段并新增原生紧凑 App 观察，但仍丢弃有界基线且没有返回文本上限。本次增量保留
macOS 有界 revision，并限制包含 App 工作流在内的 facade 文本。保持原生文本投影
不变，不再添加重复的 facade 精简逻辑。已捕获的动作绑定仍保留在 App 句柄内部，
精确窗口调用方也可通过 `elements` 访问。

## 捕获与 revision 语义

分别记录 AX 读取是否成功和深度、节点数截断。读取成功且原生身份唯一的有界捕获可以
保留 revision，其 `capture_complete` 仍为 false。完整捕获和有界捕获使用独立
lineage，同时按 session、目标、遍历限制、App/legacy 投影和格式版本隔离。

相同的有界观察可以返回 `no_change`。有界观察出现任何变化时，返回当前捕获范围的
full，不生成删除 diff：消失的节点可能只是落到了预算之外。原生读取失败或身份有
歧义时仍使 lineage 失效。token 只指向当前捕获到的元素，不能用保留的 token 操作
本次遗漏的元素。

macOS 在顶层提供捕获完整性、读取完整性、截断状态和不完整原因，同时保留已有 revision envelope
字段。facade 保留 #11683 已建立的 envelope 优先级，并回退到顶层字段。仅对暂时性
读取失败重试一次，包括同时达到遍历上限的情况；纯预算截断不重试。即使有界原因
列表已经填满，`capture_read_complete` 仍能区分混合失败。保留当前 snapshot 已签发的 token，不把覆盖
范围不完整等同于当前元素不可用。暂时 revision 也为每个 snapshot token 附加文本中
的短 ID，避免 App 动作混淆全部节点的显示编号与可操作节点的索引。旧 daemon 缺少
这一映射时，带 revision 的 App 观察不回退到动作索引；精确窗口调用方仍可使用当前
snapshot token。

## 面向模型的文本

facade 保留原生行内容，包括 revision 比较所用字段。原生投影和富文本格式仍由
#11705 负责。

`maxTextChars` 独立于 `maxElements`、`maxDepth` 限制返回文本，默认 12,000 字符。在
完整行之间截断，并在输出开头明确提示。完整的已捕获元素数组仍可用。App 句柄保留
当前短 ID 动作绑定，原样转发有界文本而不替换捕获警告；其提示指向 `app.getState`，
不会指向未公开的元素数组。调用方可以用
`disableDiff: true` 和更大的 `maxTextChars` 请求较大的全量文本；未输出的文本不能
证明元素不存在。捕获警告也放在树的前面。

## 验证与验收

- 修改前，通过全局 CLI / qwen_node_repl 复现已安装 facade 的嵌套字段错误和重复全量输出。
- 原生测试覆盖相同有界观察、变化后的有界捕获、token 失效、捕获上限及暂时读取失败分类。
- facade 测试覆盖两种捕获字段位置、预算不重复重试、当前 snapshot token、
  按行预算以及元素数组保持不变。App 测试覆盖有界 no-change 后的短 ID、读取失败
  警告和更大的全量文本。
- 执行包构建、类型检查和定向测试，以及仓库构建、类型检查；通过 qwen_node_repl 对真实
  浏览器进行观察与动作检查。
- 静态有界页面读取成功且原生身份唯一时必须复用基线；真正的捕获失败仍明确标记为
  不完整，身份有歧义时仍返回 full。
- 默认文本包含前置诊断且不超过字符预算。该预算是字符限制，不是模型计费 token 承诺。

## 风险

部分捕获不能证明删除或全局不存在。变化时返回 full 的规则为此主动放弃 partial diff。
有界文本可能省略已捕获的行，调用方可以请求更大的全量文本或截图。精确窗口调用方
也可查看当前结构化元素。旧版已
安装 driver 可以受益于 facade 输出修改，但保留有界 revision 需要重建原生 driver。
