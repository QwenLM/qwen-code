# 在精确窗口输入校验中识别附着窗口

[English](cua-attached-sheet-input.md) | [简体中文](cua-attached-sheet-input.zh-CN.md)

## 问题与范围

App 观察可以选中一个附着的 macOS 文件选择窗口，但其 CGWindowID 可能不在应用直接的
AXWindows 数组中。当前输入校验会以 `off_space_or_ax_unresolved` 拒绝这个已观察的
窗口。全新 VM 中的复现确认，VLC 的键盘输入和已观察到的 Search 元素点击都受此影响。
更早的 AXPress 报错实际已经打开该窗口；本修改不重试或重新解释那次结果不确定的派发。

## 预期行为

保留已有直接窗口路径。仅当目标不在 AX 记录中时，对仍被持有的根窗口调用已有的
有界附着窗口发现。只有根窗口和附着窗口发现都完整、附着窗口自身 ID 可映射、根窗口也有映射记录时，
才加入记录。附着窗口随根窗口一起最小化，因此继承其最小化状态；未知状态仍为未知。
不重复已有记录，也不通过几何位置推断窗口。

WindowServer 所有权、元素归属、隐藏和最小化状态、键盘焦点与其他输入目标的检查
继续生效。输入仍在后台执行；不增加前台回退、重试或范围更大的应用级目标。
未映射或发现不完整的附着窗口仍被拒绝。已有直接目标不增加一次发现遍历。

## 验证与接受条件

测试已映射和未映射的附着关系、未知和已最小化的根窗口、重复记录，并保留已有的
同进程其他窗口键盘歧义检查。在不操作宿主桌面的前提下，构建并运行针对性的原生
单元测试。随后在独立的 guest Qwen MCP 会话中，带原生错误采集复现文件选择窗口
操作，确认动作作用于目标窗口。再从干净副本运行未修改的转换任务并验证导出的 MP3。
保留失败尝试，记录时间和 token；只有正确性提高后，才能把更短的运行视为性能收益。
