# 侧栏最近会话

[English](sidebar-recent-sessions.md) | [简体中文](sidebar-recent-sessions.zh-CN.md)

## 目的

在首页侧栏的项目之后、已归档之前新增可折叠的最近会话区域。保留项目和无工作区会话列表。

## 行为

汇总当前 daemon 上受信任、可见工作区的顶层、未归档普通会话，以及后端支持的无工作区会话。排除频道、Live 和子会话。默认显示最新五条，展开后最多二十条。排除置顶会话，点击置顶后立即从最近列表移除。标题右侧提供悬浮或聚焦时显示的新建按钮，调用与顶部新建相同的不指定工作区的创建流程，并展开最近会话；新会话获得 ID 后在此列表高亮。取消或创建失败会清除待选中状态。按活动时间排序（`updatedAt` 不早于 `createdAt`），在标准会话详情悬浮窗中显示来源信息。保存折叠偏好。

## 实现

复用工作区限定和独立会话列表 API，不依赖项目展开状态。支持会话组织时使用工作区 organized/all 分页，以取得置顶元数据；跳过置顶项，每个来源读到二十条有效会话或结束，再合并并按工作区范围和会话 ID 去重。点击沿用工作区和独立会话的打开回调。要求支持工作区限定 REST 能力。只汇总当前聚焦的 daemon，并遵循工作区锁定范围；不汇总其他远程主机。

展开时，每轮读取完成十秒后刷新；切换会话、独立会话变更时刷新；折叠或卸载后停止调度。范围变更后忽略过期结果。部分来源失败时保留成功来源，并提供重试。复用现有侧栏会话行渲染，包括状态标记、标题布局和详情悬浮窗。右侧仅提供置顶和归档按钮，不展示来源文字。最近会话采用独立于普通会话行内联配置的专用布局，但两个操作均遵守宿主的操作项策略。项目置顶沿用已有分组操作和乐观状态；项目归档沿用已有范围限定操作。无工作区归档调用专用 API，并刷新两个列表。由于后端缺少无工作区置顶 API，其置顶按钮禁用并提供原因说明。仅高亮点击所在列表中的会话项：最近会话与原项目或无工作区列表的视觉选中位置独立于实际当前会话。如果选中的最近会话副本不再渲染（例如置顶或折叠后），则回退到原列表中当前会话的高亮。同一目录范围内刷新时保留已有行，避免导航闪烁；数据范围变更时清除旧数据。会话恢复期间暂停目录读取，并忽略未完成请求的返回：无工作区恢复持有排他锁，目录可能暂时缺少该会话；连接就绪后恢复读取。无工作区视觉选中使用独立的会话 ID 范围，不依赖内部运行目录。点击当前无工作区会话仅转移选中位置，不重复恢复。导航时传递侧栏已知标题，立即填充顶部标题；新无工作区会话首轮结束后刷新标题。当前会话和运行中会话不可归档。重命名、删除和分组继续通过现有项目菜单完成。

## 验证和验收

验证项目后的排列位置、相同的行尺寸、详情悬浮窗、置顶和归档路由及禁用条件、排序、跳过子会话的分页、范围身份、混合来源导航、受信任工作区过滤、折叠持久化、预览展开、部分失败和定时刷新。在已有 localhost:5173 服务中验证项目保持折叠时最近会话仍可用，并分别打开项目和独立会话。不修改后端或 SDK。活动更新最多延迟一个轮询周期；归档和重命名在刷新后同步。
