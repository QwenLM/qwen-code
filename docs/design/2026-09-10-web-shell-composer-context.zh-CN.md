# Web Shell 输入框与上下文可读性

[English](2026-09-10-web-shell-composer-context.md) | [简体中文](2026-09-10-web-shell-composer-context.zh-CN.md)

## 问题与范围

输入框即使为空也预留 140px 高度，上下文圆环需要悬停才能读取占用率。
上下文侧栏将每个名称与 token 数分成两行，并展开所有工具、记忆与技能明细，
使用户难以快速浏览概览。

本次改进现有 Web Shell 的显示方式，不改变消息发送、上下文统计、API 路由、
会话归属、轮询或公开的自定义选项。

## 设计

- 输入框默认最小高度降至 116px，编辑区、工具栏弹层或引用选择面板激活时显示轻微边框提示。
  Escape 关闭弹层后恢复触发按钮焦点；选择插入操作时保留其现有焦点处理。
  保留自动增高、现有最大高度、附件滚动和宿主 CSS 变量。
- 输入框宽度超过 520px 时，在现有圆环旁显示上下文占用百分比。窄输入框保留
  圆环、无障碍标签及提示。两者均执行现有上下文操作（`/context`）。警告和错误
  百分比与圆环使用相同级别。主窗口与分屏输入框采用相同连接状态判定，失效时
  隐藏过期读数及不可用的上下文操作。
- 将单行悬停文字改为结构化提示卡片，显示占用率、比例进度条、已用 token 数、
  上下文窗口大小，以及点击后在对话中查看的本地化说明。悬停使用现有本地计数，
  不请求上下文，也不创建对话消息。辅助技术使用简洁的本地化已用/窗口说明。
  普通百分比、提示卡标签与说明、明细分组数量使用现有次级文字颜色，确保两种
  主题下均清晰可读。
- 保持侧栏概览可见。类别与明细的数值右对齐，长名称允许换行，token 数保持可读。
- 紧凑模式的工具、记忆与技能明细使用原生折叠分组，初始收起并显示项目数量。
  键盘展开后显示相同的完整有序明细。对话记录中的明细分组默认展开，也可收起。
  激活原生分组标题时暂停本次交互的对话跟随到底部。折叠选择仅保留在当前挂载
  实例中：虚拟列表移除对话行后重新挂载时，其分组恢复默认展开；侧栏重新挂载
  时恢复默认折叠。跨卸载保存这些选择不属于本次布局改进范围。
- 对话记录中的卡片使用相同比例进度条、自适应列及完整名称换行，在标题旁显示
  占用率，采用界面无衬线字体；对话卡片使用具名分组，不为每张卡片增加区域
  地标，避免重复读数挤占地标导航。紧凑卡片在右侧面板内保持不具名。本地化的
  “查看明细”按钮执行现有 `/context detail` 操作；没有回调的
  只读渲染器保留命令提示。明细名称完整显示，删除已无生产调用方使用的内部
  长度上限配置。

复用现有 CSS Modules 和主题变量。原生 details/summary 提供键盘交互，无需新增
依赖或自定义折叠状态。保留预估、不可用、加载、重试及超限状态。

## 影响文件

`packages/web-shell/client/` 下的 `ChatEditor.tsx`、`ChatEditor.module.css`、
`ContextUsageMessage.tsx`、`ContextUsageMessage.module.css`、主窗口与分屏可用性判断、
对话跟随保护、添加菜单焦点处理、本地化文案，以及对应的定向单元测试与浏览器测试。

## 验证与验收

修改前使用全局安装的 `qwen` 进行基线验证，再验证本地构建。检查空输入、多行
输入、达到上限后的滚动、附件布局、桌面与触屏发送、宽窄工具栏及明暗主题。
检查折叠展开、数量、完整长名称、token 数排序、预估和超限读数、悬停/聚焦不发
请求，以及点击圆环后点击“查看明细”的流程。只读渲染保留命令提示，显式请求的
明细默认展开；两种主题均覆盖窄对话卡片。运行构建、类型检查、打包、定向单元
和浏览器测试，再审核完整差异。固定检查 520/521px 输入框断点、实际主题颜色、
圆环键盘访问、静息/聚焦边框、引用搜索和每个换行明细的对齐。检查两个输入框
断点下左侧工具栏的裁剪和模型按钮命中、两处显示面的次级文字可读性、重复具名
分组，以及超限时已用数值的错误颜色和对齐，并将定向浏览器测试加入 PR smoke
流程。
浏览器测试夹具可提供确定的上下文读数；其结果与真实 daemon 验证分别记录。

## 风险与待定事项

百分比会增加工具栏宽度，需要通过容器断点及现有测量逻辑确保发送和模型操作
始终可达。长上下文名称应换行而不引起横向滚动。本次有限的布局改进没有待定
设计问题。
