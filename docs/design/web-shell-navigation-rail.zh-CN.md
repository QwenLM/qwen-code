# Web Shell 左侧导航栏

[English](web-shell-navigation-rail.md) | [简体中文](web-shell-navigation-rail.zh-CN.md)

## 问题与范围

当前侧栏混合了全局导航和项目会话，收起后通过悬浮弹层访问会话。改为桌面常驻图标栏与可收起的首页第二栏，保留嵌入宿主显式配置和后端行为，未配置宿主默认仅首页。不增加用户头像、全局最近列表、新导航框架或 daemon API 改动。

## 双栏布局与行为

首页展开现有品牌、新建任务、置顶和项目分组；没有独立 Live 入口的宿主继续在此显示 Live（开启时）。已启用的主要导航入口直接展示在图标栏。一级底部只保留「更多」和「展开／收起」；仅首页模式的收起／展开按钮保留在二级栏底部右侧；存在一级栏时，按钮只放在一级栏底部，所有二级栏均不再显示。设置、主题及其他已启用底部操作收入「更多」；版本号也移入「更多」，宿主自定义内容保留在首页宽区域。仅首页时保留的 Live 分组使用与「项目」一致的标题颜色，展开图标紧随文字；频道、Live 左栏标题与首页品牌名共用 18px、500 字重、20px 行高，标题下分隔线同样左右留白 12px，不通栏。项目标题后的展开箭头和操作按钮仅在鼠标悬浮或键盘聚焦时显示，触屏保持可见。首页、主要导航、更多和展开／收起入口使用共享的黑底白字、无箭头、无进出动画的 Popover 响应悬浮和键盘聚焦，替代原生 title，保留无障碍标签与作用域 portal-root。导航图标统一为 17px、1.8px 线框描边，首页使用 House。选中时保持相同图标造型，仅改变前景色和背景色。常态图标为中灰，悬浮与选中时加深前景色并使用柔和圆角底色，不增加明显按钮边框；项目和 Live 会话组保留缩进并移除层级竖线。Live 继续使用已有能力及 showLive 限制，本次不新增语音启动策略。

存在一级栏时，收起后完整隐藏二级，只保留 56px 一级栏；点击一级底部展开按钮或首页恢复二级，悬浮不展开。仅首页模式则保留 main 原有的 56px 折叠侧栏，包含品牌、新建任务、会话悬浮面板和底部展开按钮。点击首页展开第二栏并回到原聊天，不创建会话。除下述频道和 Live 入口外，点击其他导航图标，在图标栏右侧打开现有完整功能页，替代首页第二栏及聊天的展示，不将表单挤进项目栏宽度。通过命令打开的 MCP、Skills、Agents 和 Extensions 就地面板保留首页栏及其选中态。浏览器历史返回聊天时恢复首页，Live 会话 URL 则恢复 Live。定时任务和目标在图标栏可用时隐藏返回按钮，单栏、窄屏抽屉或隐藏侧栏的宿主继续保留；页头与频道设置统一为最小高度 46px、上下内边距 10px、标题字号 14px。键盘收起时若焦点位于将隐藏的二级栏，先将焦点移至一级展开按钮。收起／展开及 Cmd/Ctrl+B 只改变侧栏显隐，保留当前页面、URL、表单草稿和进行中的通话。主动切换功能页仍可能按现有行为卸载表单。主题和本地文件控件仍是操作，不视为功能页。

## 合并频道入口

双栏模式中，当服务支持来源元数据、现有来源切换开启且允许频道入口时，点击「频道」同时展开 300px 会话栏和右侧完整设置页。顶部只保留「频道」标题和底部分隔线，搜索保留在项目工具栏；点击一级「频道」图标可重新打开右侧现有完整管理页，保留频道列表，右侧标题为「设置」。双栏独立频道设置页在图标栏可见时不显示返回按钮，窄屏抽屉、单栏和旧入口继续保留。打开频道会话后回到聊天并保持频道选中。首页展示普通任务。只有替代入口可达时才隐藏原「任务／频道」标签；单栏宿主及旧服务保持原有行为。

复用已有来源筛选会话目录、WorkspaceSection 会话渲染和共享行操作。频道栏保留与首页一致的工作区文件夹和展开收起状态，同时保留按工作区加载、搜索、频道类型分组、重命名、导出、支持时的置顶、删除、归档／恢复、错误处理及能力权限限制。频道归档同样按工作区分组。频道设置移除顶部介绍和重复的工作区摘要。工具栏左侧放工作区选择器，隐藏可见标签但保留无障碍名称，紧接选择器显示「已配置 N 个频道」徽标，刷新仍在右侧。未配置的空状态增加边框，左侧文件夹不增加配置数量。频道设置继续保留工作区切换行为，不合并不同工作区的同名频道。工作区管理统一留在首页：频道隐藏工作区管理／添加、文件夹行操作及带管理操作的工作区悬浮详情，保留搜索和会话操作。不改 daemon、频道路由，不增加通用导航配置。增加本地首页／频道／Live 栏目选择，保证从设置返回或打开会话时仍留在频道；公开 Channels 路由继续表示频道管理。

## 独立 Live 入口

双栏模式下，`showLive` 和现有一级导航白名单控制新增的 `live` 入口。点击 Live 同时打开 300px 会话栏和右侧现有 Qwen Live 设置卡片，页头高度 46px，返回规则与频道一致，两页右侧标题统一为「设置」。现有 Live 表单改为最大宽度 768px 的单列，标签和输入框对齐，表单下方只保留一个保存按钮，Key 必填时在字段名称后显示红色星号并设置 aria-required，替代「必填」文字。启用开关、地址、Key 替换／移除、模型、音色和原生快捷键先暂存；保存时通过现有 POST /live/setup 一次提交已修改且受支持的字段。原生启用确认在保存时出现；取消或请求失败均保留草稿。字段改回已保存值时移除对应草稿。刷新发现未保存字段已被其他客户端修改时，显示明确冲突并阻止保存；用户可放弃草稿，加载最新已观察到的设置后重新编辑。该客户端检查仅覆盖已观察到的变化，不提供原子并发写入保护，也无法识别元数据未变的密钥替换。暂存的 Key 移除在重新启用后仍可见且可撤销。无冲突时，后台状态刷新不禁用已加载的表单或保存按钮；首次加载和实际提交期间仍禁用相关控件。选择 provider route 模型时不提交不适用的地址／Key 替换草稿；切换回自定义模型时，仅显式编辑地址才提交 endpoint，未编辑则保留已有独立配置，界面提示保留地址而非暗示恢复默认值。Host 安装重试和启动仍是即时操作。点击 Live 会话打开现有详情，再次点击一级 Live 回到设置。左栏直接平铺 daemon 管理的 Live 工作区会话及现有操作，不再增加可折叠的「会话」目录，不展示普通项目管理，也不新增归档能力。Live 列表加载完成且为空时，以淡色收纳盒图标和下方原有「暂无会话」文案水平居中展示，保留已有加载和错误处理。频道使用 MessagesSquare，Live 使用 AudioLines，均保持 17px、1.8px 描边。

复用现有设置卡片、设置 hook 和通话弹窗，不增加欢迎页或语音能力。通过 portal 把现有输入框中的语音按钮移到 Live 左栏，控制器持续挂载，保证导航既不开启媒体采集，也不中断通话。二级栏隐藏或窄屏抽屉关闭后，通话入口回到输入框。只有用户明确点击语音入口才走现有启动／连接流程；继续遵守能力支持和输入框动作限制。独立入口可用时，全局设置不再重复展示卡片；单栏、隐藏侧栏、`showLive: false` 和白名单不含 Live 的宿主保留原「设置 → 实验性」卡片与会话位置。旧服务不支持设置时仍保留会话列表，并显示设置不可用提示。在现有路由解析、历史处理及 daemon 公开页面路径列表中增加 `/live`，不另建导航系统。只有精确页面路径的 GET/HEAD 文档请求返回公开 HTML；冷启动及已启动 daemon 的 Live API 请求继续要求认证。

验证路由／刷新／历史、设置迁移与回退、会话切换、收起展开、窄宿主返回、纯导航不产生 Live 修改请求或媒体采集，以及按钮迁移时通话控制持续可用。现有语音和设置单测覆盖未变更能力；模拟浏览器截图仅证明布局。

## 兼容与实现

**Breaking change（不兼容变更）**：省略 `sidebar` 从隐藏改为展示首页；省略菜单列表从全部改为仅新建任务／收起。旧宿主如需保持隐藏，显式传 `sidebar: false`；如需原菜单，显式填写 `primaryNav.items` 和 `footer.items`。窄屏品牌默认显示，需要隐藏时传 `branding.hideWhenCompact: true`。

使用一套自动布局，不再提供 `sidebar.layout` 选项。首页始终存在；实际可用的已配置一级入口或底部功能存在其他项时展示一级栏，否则只展示 300px 二级栏。计算时遵守项目能力、Live 开关、托管 provider 和工作流支持等条件。分屏入口和分屏自动折叠统一使用容器宽度（1024px），分屏为侧栏保留空间的阈值为容器 1200px。未配置宿主、`sidebar: true` 和空配置默认仅首页／新建任务，底部默认只有收起。`sidebar: false` 或 `enabled: false` 仍隐藏侧栏。独立 Web Shell 显式配置现有完整一级及底部入口；宿主通过现有 `primaryNav.items`、`footer.items` 开启其他功能，省略列表不再默认开放全部入口。仅首页时收起为现有 56px 窄条和悬浮会话面板，多入口时收起仅保留一级栏，点击首页或一级底部展开按钮恢复；这种布局的所有二级栏都不放收起按钮。

保留 sidebar.enabled/defaultCollapsed、primaryNav.items/render、footer.items/render、branding、showLive、lockWorkspaceCwd 及宿主抽屉 API。sidebar:false 同时隐藏两栏。宿主 render 回调在首页保留宽插槽。功能页选中状态来自 App 现有 activePanel/mainView；本地首页／频道／Live 选择用于筛选会话来源，不增加路由系统。浏览器历史与已有页面回调仍为权威状态。启用 URL 导航时，只有宿主显式菜单列表限制已有页面路由；默认仅首页不拒绝设置、插件或目标 URL。新增 Live 路由仍要求存在可用 Live 入口。

保存的侧栏宽度代表图标栏与首页第二栏总宽，首页第二栏默认 300px，另加 56px 图标栏（总宽 356px）；单栏默认 300px，已有保存总宽度优先，但展开后的下限为单栏 220px、双栏 276px（含 56px 一级栏）；不对历史值无条件增加 56px。拖拽及响应式适配需考虑嵌入容器，而不只依赖窗口宽度。桌面聊天区域宽度至少 760px 且时间轴隐藏时，右上角保留独立的会话搜索入口；紧凑移动视图保持原有行为。窄容器首页默认保留商标与品牌名，即使已保存桌面收起状态也显示；宿主显式 branding:false 或 branding.hideWhenCompact:true 仍隐藏。窄容器复用抽屉交互，两栏均位于抽屉内；保留 Escape、焦点、弹层及宿主边界。主要入口高度不足时滚动。「更多」复用现有底部操作和宿主可见性配置；关闭菜单时，更新轮询、本地文件连接与桌面中继保持挂载。上游新增的桌面中继继续在「更多」中可用，保留原有授权与连接生命周期。保留作用域 CSS、语义颜色、公共变量、React 18/19 及 portal-root 接入。

影响区域：WebShellSidebar 及其样式、App 布局接线、翻译、README、针对性单元及浏览器测试。原悬浮会话浮层仅用于只有首页的折叠态；一级栏布局完整隐藏二级并通过点击展开。

## 风险与验证

主要风险为宿主自定义内容、受限宽度、路由选中状态、收起状态持久化、分屏、键盘焦点与 Live 能力限制。验证默认、隐藏、自定义及锁定侧栏，悬浮与点击差异，草稿保留，浏览器历史，移动端及窄嵌入容器，短高度滚动，明暗主题和会话操作。模拟 daemon 浏览器截图只证明 UI 行为，不证明真实 Git 或后端操作。运行构建、类型检查、针对性测试、打包、浏览器测试及两轮无问题自审。

## 验收与待决项

仅首页模式收起保留原有 56px 窄条和底部展开入口。存在一级栏时收起／展开按钮只放一级底部，收起后仅剩 56px 一级栏，点击首页或展开按钮恢复会话树；点击功能打开对应页面。所有已启用入口可直接访问或通过「更多」访问、首页不新建会话。宿主现有配置继续有效，嵌入模式 Live 仍需显式开启。无待确认产品问题；本次实现不包含 PR 或发布。
