# Linux CUA 输入恢复

[English](linux-cua-input-recovery.md)

Linux 的语义输入回退此前会将分发后的失败视为语义通道不可用。原生动作可能已经
修改应用状态，随后丢失 D-Bus 回应，而点击工具继续发送像素点击。滚动也存在相同
回退；部分点击路径还会忽略 AT-SPI 的 false 确认并报告成功。

使用已发布的 0.20.8 源码复现：动作产生效果后返回错误或触发原有 25 秒超时，
夹具会记录两次效果，分别来自语义动作和像素动作。未产生效果且返回 false 的确认
仍被报告为 “Clicked element”。这是使用受控传输端点、提取实际源码的复现，
不能据此认定所有历史零分任务的原因。

将 macOS 的恢复原则迁移到现有 Linux 实现：输入分发之前可以回退，一旦可能已经
分发，就必须停止自动重放。每次 AT-SPI 尝试局部记录分发状态，覆盖超时和只完成
部分步骤的滚动批次。确认返回 false、失败或超时时，返回输入结果未确认错误；
调用方必须先观察，再决定是否重试。保留安全的分发前回退、精确目标身份和现有
前台保护。

Node REPL → Computer Use facade → Linux 原生驱动的现有调用结构、进程、安装和
权限保持不变。不引入新的公共 API、服务、全局重试策略或特定 provider 的绕过。
模型指引仍来自固定的 Computer Use 主 skill 文件。

文本插入和整体值替换采用同一分发边界。结果不确定的插入不能继续回退为整字段
替换，被拒绝的替换也不能回退为追加。成功写入但没有回读时仍属于未验证结果；
不能自动报告前台升级要求，否则共享 core 会把它解释为投递失败。

可编辑文本独立于 accessible label 保存，清空字段时也保留空值。紧凑观察行省略
重复标签和值、默认状态及主激活动作，结构化元素仍保留全部动作。非默认状态和
次要动作继续可见，确保 revision 比较保留有意义的操作差异。

像素回退保留精确窗口与元素身份。元素边界与窗口取交集，并在前台准备后重新计算
点击点，避免过大的控件误点同进程的其他窗口。GTK3 已提供含客户端装饰的正确屏幕
坐标，不再套用 GTK4 的阴影重建。GTK4 路径单独保留并验证：其 X11 顶层 Screen
范围实际上是窗口局部坐标，因此同进程多窗口只能通过在原生窗口列表和可访问性
窗口列表中均唯一的标题关联。缺失或重复标题继续拒绝。语义主激活仅适用于无修饰
键的单次左击，保留用户请求的右击与双击语义。

独占 Linux 桌面还复现了活动窗口与 core 焦点就绪需要 644–734 毫秒。将现有焦点
确认循环的预算设为一秒；就绪后立即返回，只重试准备过程。动作回调仍只执行一次，
不会重放结果不确定的输入，也不能据此认定历史 benchmark 的焦点失败原因。

Linux 继续使用精确窗口公共 API。仅将适用的 macOS 批处理指引加入固定 skill：
合并已知动作，在一个 cell 中完成最终验证和清理，遇到新对话框或菜单时先观察。

观察重试共享一个原生 25 秒预算。此前四次原生尝试各自获得完整预算，SDK 的
读取失败重试还可能再执行一轮。为处理工具包延迟注册，只对完整但为空或仅有根
节点的树重试；失败或不完整读取立即返回。保留原生部分树和诊断，无树时保留
X11 回退。直接原生调用方收到第一次失败，不再隐式重试。SDK 对短暂读取失败
仍保留一次重试，但耗尽截止时间的部分捕获直接返回，不再启动完整遍历。

紧凑化和 LibreOffice 有界采集。

## 验证

修改前先复现已发布代码。覆盖 true/false 确认、分发前失败、独立观察到效果后的
失败、超时和滚动部分进度。除模型可见错误外，还断言真实效果次数和第二执行器
未触发。覆盖元素与坐标路径，确认回退保留精确原生身份。随后在独占 Linux VM
重跑 MCP → Node REPL → SDK 输入、焦点恢复和截图测试，并独立回读应用状态。

将右击和双击与坐标控制组比较。通过观察结果及独立应用状态文件验证有标签文本框
的设置、插入、清空。分别覆盖超大控件、同进程双窗口、GTK3 装饰和 GTK4 几何。
这些 GUI 验证不能证明传输故障语义：GTK 可访问性桥会在回调排队后确认，不依赖
回调本身的返回值。

覆盖完整与不完整树、不可用与失败读取、延迟注册恢复及预算耗尽。用计数端点验证
原生包装和实际 SDK facade。确认重试耗尽后保留最后一份有效最小树，每次尝试
只能使用剩余预算。模型实际等待、分配的原生时间预算和 provider 延迟分别度量。

历史任务终态、评测得分、唯一模型响应数、未缓存/缓存输入和输出 token 是独立
指标。原生调用数或文本字符数减少不能证明模型成本下降；宣称效率或得分提升前
必须取得成对真实任务证据。
