# 已保存工作流斜杠命令的完成通知

[English](2026-09-21-workflow-slash-completion.md) | [简体中文](2026-09-21-workflow-slash-completion.zh-CN.md)

状态：针对 [#12176](https://github.com/QwenLM/qwen-code/issues/12176) 的修复方案。

## 问题

已保存工作流的斜杠命令发起客户端工具调用。前台结果不触发模型续轮，注册表的完成通知服务于后台任务，因而结果可以存在磁盘中，却没有进入对话。

## 决策

保留斜杠工作流的前台执行。将结果投递与运行模式分开：`executionOrigin.kind` 为 `client` 时，调度器为支持通知的调用传入内部通知标记。来源缺失或来源为模型时不启用通知，其中包括结果应返回父调用的嵌套 code-mode 调用。具有多种含义的 `isClientInitiated` 标记不决定投递。Workflow 将投递标记传给运行器和注册表条目。该标记不属于模型可传入的工具参数，也不属于持久化运行模式设置。初次调度及 `PermissionRequest` hook 编辑参数后重新创建调用时均保留标记。

客户端发起的任务完成或失败后，复用现有完成回调和通知队列。模型发起的前台任务沿用工具结果返回；后台任务沿用后台通知。取消不产生完成通知。终态检查防止一个任务报告两次。

运行器在执行结束前将终态刷新到工具卡片。按 Esc 取消后，卡片保留运行 ID 和阶段记录，显示 `status: "cancelled"`，替换取消前的运行中进度。任务结束后移除查看实时进度的提示。这次显示刷新不向队列加入完成通知。

前台进度保留在工具卡片，包含运行 ID，并提示在卡片查看进度。`/workflows <runId>` 在任务结束后用于查看运行；前台执行期间输入该命令会进入队列。完成通知显示运行 ID、状态、每行上限为 4,096 字符的返回值预览或错误、运行器记录的子任务失败，以及结构化对象返回值顶层非空的 `failed`、`errors`、`error` 字段。从原始对象读取这些字段，其他字段无法序列化时也保留失败信息。普通字符串不作为 JSON 失败报告解析。这些字段作为脚本报告的数据展示，不把完成状态改判为运行失败；不解释任意业务结果结构。没有返回值的任务显示 `(workflow returned no value)`，不向模型发送结果元素。

前台和后台完成通知将模型结果预览限制为 25,000 个 XML 转义后字符，该上限不受工具输出配置影响。显示和模型通知复用结果的序列化文本；XML 转义限于预览部分，截断不保留残缺的 XML 实体。截断提示标明用于读取完整聚合结果的运行快照（`<runId>.json`），现有诊断信息保留逐 agent 的 journal 路径。注册表结果和持久化快照不截短。后台摘要保留原有包围引号和经过转义的标签。

TUI 在收到前台完成回调时显示通知，无需等待模型准入或回复。同一通知随后经现有队列进入模型及聊天记录，后续追问可以获得结果。斜杠命令派发记录中的 `outputHistoryItems` 可以保持为空，完成结果有独立的通知记录。

## 替代方案与取舍

删除所有前台运行的过滤条件，会为已有工具结果返回的模型任务增加通知。将斜杠任务切到后台，会改变内联进度和前台取消行为。内部投递标记保留这些行为，并复用通知通道。

让客户端工具进入正常工具结果续轮，还需要处理缺少模型工具调用记录、轮次归属及取消的问题。把命令展开成模型提示，会在执行前增加一次模型调用，并把参数选择交给模型。这次修复无需采用这两种方案。

现有通知通道会触发模型回复并消耗 token，本方案保留原 issue 要求的结果回报行为。静默写入上下文或自动总结开关属于额外功能；保留前台执行不意味着增加这些选项。用户看到的结果不依赖模型总结成功。

## 范围

交互式命令保留脚本路径／仅名称调用、参数、审批、前台进度及取消行为。Headless 和 ACP 保留提示展开。嵌套 code-mode 调用向父调用返回结果，普通模型调用不增加通知。不增加公共工具参数、配置选项或持久化结构迁移。

OpenTUI 的独立斜杠工具处理器接线，以及工作流历史的结果查看器，不属于本次修改。

## 验证

使用隔离交互会话和记录请求的模拟模型端点，检查受控 agent 完成前的前台进度、完成结果和真实子任务失败的显示、一次结果通知、聊天记录及追问上下文。覆盖包含大量 XML 特殊字符、失败字段位于预览范围之外的大结果：显示通知保留显式失败行，有上限的模型预览及截断提示进入后续追问上下文。覆盖脚本抛错、取消和审批拒绝。模型发起的前台任务作为对照：一次工具结果返回，无额外完成通知。保留参数、仅名称模式、headless 和 ACP 的命令加载测试。与命令输出可见性测试共享现有的 90 秒只读 `/about` 就绪探测。

单元回归覆盖初次调度及 hook 参数重建时的来源判定、JSON 外观字符串、无法序列化但包含有效失败字段的对象、三种常见错误字段、无返回值以及后台摘要转义。

运行相关单测、终端回归、构建／类型检查及修改文件的检查。本次修订不运行本地全仓测试。执行证据写入 PR 验证报告，区分模拟传输检查、真实模型总结质量和原报告的九 agent 工作负载。
