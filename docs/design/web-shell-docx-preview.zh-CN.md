# Web Shell DOCX 预览

[English](web-shell-docx-preview.md) | [简体中文](web-shell-docx-preview.zh-CN.md)

## 问题与现状

Word 文件目前仅支持下载。附件、@ 引用、Files 内嵌和独立预览，以及工作区 artifact 均无法展示 DOCX 内容。PDF 和 XLSX 已使用支持工作区归属检查的二进制读取流程。

## 方案

增加一个按需加载的 DOCX 预览组件，使用固定版本的 `docx-preview`。已有附件 Blob 在本地处理；工作区文件通过 `readWorkspaceFileAsBlob` 和解析后的所属工作区 actions 读取。按原始文件名识别扩展名，保留 `#`、`?`；仅在没有扩展名时使用规范化后的 DOCX MIME。不把通用的 `kind: document` 当作 DOCX。放行现有 Files Preview 操作，并保留不可用 artifact 的状态拦截。Sources 复用相同分流，不增加单独的加载器。Sources 附件保留 `source.title` 作为下载名，附件标识继续作为读取定位；工作区文件使用真实文件名。

## 渲染与隔离

使用固定 `srcDoc` 和 `sandbox="allow-same-origin"` 的独立 iframe，不启用 `allow-scripts`。同源访问允许可信父页面代码写入文档，sandbox 同时阻止文档脚本。CSP 禁止网络资源、嵌套 frame、表单和 base URL，仅允许内联样式与 data 图片/字体。设置 `renderAltChunks: false`、`useBase64URL: true`，显示前移除外部超链接导航。内部书签由可信父页面注册的事件处理器阻止默认导航，并在 iframe 内滚动到对应元素。不能使用原生片段导航，因为 `srcDoc` 会继承父页面的 base URL。文档使用独立的浅色画布，样式不能注入 Web Shell。

每次渲染独占新的容器和样式。加载时通过 visibility 隐藏 frame，保留布局测量；已取消的任务只能在被丢弃的容器中结束。通过可横向滚动的容器保留纸张宽度，避免窄面板裁掉左侧内容。文件、版本、工作区、Blob 或重试变化时重新加载。替换或卸载时释放原文件下载的 Blob URL。这是 DOM/脚本隔离，不是 CPU 或 ZIP 解压沙箱。

原文件 Blob 加载完成后，使用 30 秒计时器覆盖字节转换、渲染库导入和渲染。超时时丢弃本次容器，忽略迟到的成功或失败，并显示重试、保留原文件下载。完成或清理时取消计时器。这只能限制事件循环仍可运行时的异步等待，不能中断阻塞主线程的同步计算。

## 限制与回退

DOCX 预览输入上限为 10 MiB，在工作区字节读取前和附件 Blob 渲染前检查。保留二进制分块、stat 一致性和工作区归属检查。读取或解析错误时提供重试，损坏或超限时也保留原文件下载。压缩后的输入上限不能限制展开后的大小，庞大或恶意文档仍可能消耗浏览器资源。不保证 Word 原生分页和复杂布局的还原程度。

## 范围与涉及文件

仅修改 Web Shell 预览分类、面板分流、Files 菜单、独立 DOCX 组件、本地化文案、包依赖/锁文件/notices 和定向测试。保持 `.doc`、`.docm`、其他 Office 格式、PDF 和 XLSX 行为。不增加 daemon 路由、进程、外部转换服务、编辑器、OCR、自定义分页或通用阅读器框架。

## 验证与验收标准

先验证基线，再通过草稿/已发送附件、@ 引用、Files 内嵌/独立页签和 artifact 检查真实 DOCX 文字、表格与内嵌图片。覆盖通用 MIME、大写和特殊字符路径、保留原路径的纯二进制工作区读取、附件隔离、正确下载字节与文件名、错误/重试、大小/状态拦截、新渲染仍挂起时的取消、超时与迟到结果、版本/工作区变化和 URL 释放。验证脚本/altChunks、外部资源、外部超链接和文档样式不能影响 Web Shell；内部书签滚动时父子文档地址均不变。包含 Sources 和既有 PDF/XLSX 回归。捕获并目视检查实际浏览器状态，明确标注模拟 daemon 证据。执行定向单测、构建、根类型检查、bundle、lint/格式检查、连续两轮干净自审和代码 review。

## 待定问题

当前范围内无。精确 Word 分页和全面防范压缩文档资源耗尽需要其他渲染架构。
