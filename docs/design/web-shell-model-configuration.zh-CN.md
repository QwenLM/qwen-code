# Web Shell 模型配置

[English](web-shell-model-configuration.md) | [简体中文](web-shell-model-configuration.zh-CN.md)

## 问题

“设置 → 模型”通过供应商设置流程添加模型。现有高级配置使用没有选中语义的菜单式按钮，上下文输入框也缺少标签。虽然安装 API 已接受 `advancedConfig.maxTokens`，界面仍没有最大输出 token 数控件。无效的上下文大小可能被静默修改或丢弃，模型列表也没有展示已配置的能力和上下文限制。

## 设计

保留现有供应商目录、设置步骤、持久化和运行时刷新行为。仅将高级配置步骤替换为共享的 Field、Switch、Checkbox 和 Input 组件，提供思考、独立的图片/视频/音频/PDF 输入能力、上下文窗口大小及最大输出 token 数配置。可选数值必须是 1 到 10,000,000 之间的整数，与 daemon 解析器一致。留空时由模型注册表根据模型 ID 推断限制。在向导中后退时保留输入，开始配置新供应商时重置输入。保存期间禁用所有可编辑控件。

安装请求与可读的确认摘要使用同一份高级配置值，摘要包含供应商、协议、端点、模型 ID、能力标志和限制。API key 仅显示是否已设置。不在前端重建 settings.json：由后端确定自定义凭据环境变量名称及预设元数据。供应商预设保持目录定义的现有行为，不展示后端会忽略的覆盖选项。

在现有模型列表中展示模型 ID、描述、实际上下文限制、支持的输入模态和凭据环境变量名称，不暴露凭据值。继续使用现有分组、选择和删除控件，通过不透明配置键匹配持久化条目。

## 模型角色与现有配置

Advisor Model 使用共享模型选择器，并提供跟随主模型的默认选项。已配置选项保留精确的原始端点身份；运行时在发送请求前移除这个限定信息，并仅使用对应路由的凭据。失效端点会报错，不会绑定到其他配置。角色选项正在加载、加载失败或无法解析时，不得隐式重置已保存的选择。Image Model 展示可见的选择器，按端点区分已配置的生图路由。Voice Model 列出 daemon 支持的转录模型，包括仅语音条目及其显示名称、安全端点和上下文限制。语音选择器保持所选工作区的归属语义。

自定义供应商设置增加用途选择：对话、生图或语音转录。生图路由设置 supportsImageGeneration 和 imageOnly；语音路由设置 voiceOnly，并要求 OpenAI 协议及受支持的 ASR 模型 ID。安装仅服务模型时保留当前对话模型和认证选择，包含仅服务预设。新增服务路由排列在现有对话路由之后，自定义服务凭据使用独立的环境变量键。未明确提交用途的重连保留原有角色、生成配置及服务凭据键。ACP 按端点和凭据键分组列出模型 ID；省略凭据时，新增对话模型 ID 不得复用服务密钥。使用独立密钥的生图和语音组必须分别重连。安装过程中，针对已有 voiceOnly 或已选语音模型 ID 产生的新歧义会在写入前被拒绝。其他预设设置行为保持不变。

预设重连保留已编辑的上下文窗口。接受模板更新时，刷新目录拥有的名称和生成默认值，同时保留自定义模型 ID 及其配置。仅更新凭据的重连如果省略高级配置，会保留已保存的生成配置；明确提交自定义高级表单时，包括空表单，会替换思考、模态、窗口和输出限制控件的值，同时保留无关配置。Web 通过 `advancedConfig.replaceExisting: true` 表示完整表单替换。其他客户端的部分提交保留未提供的控件；明确关闭思考或模态时只修改对应控件。

自定义服务重连如果使用同一凭据桶中拼写不同的 URL，会在写入前被拒绝；用户必须使用已保存的原始端点，以维持精确角色选择的有效性。仅保存服务模型不会完成首次对话认证。仅服务安装如果会通过身份替换或预设归属覆盖现有对话模型，必须在任何设置或环境写入前拒绝。包含对话模型的安装也会拒绝隐式移除选项中遗漏的归属服务模型。预设可以将归属服务模型迁移到新端点，前提是保留模型 ID 和用途；归属替换不能通过变更端点改变用途。追加和仅服务预设重选保留既有行为。拒绝将已有身份改为其他用途。生图设置说明现有 DashScope/MiniMax 兼容传输方式。

GET /workspace/models 返回不包含秘密的持久化模型配置列表，包括仅服务模型和明确配置的上下文窗口覆盖值。该路由的 PATCH 接受不透明模型键及上下文大小（1–10,000,000），或通过 null 恢复按模型 ID 推断。DELETE 接受相同的不透明键，即使显示 URL 已脱敏，也能精确定位持久化条目。键包含作用域、存储供应商、模型 ID 和端点；存储目标缺失或存在歧义时失败，不执行回退。加锁后的重新读取、修改和写入保留凭据及无关生成配置。PATCH 写入未解析的设置副本，使环境变量占位符在磁盘上仍为占位符。DELETE 在写锁内检查原始作用域快照，如果读取后已有其他编辑提交则返回冲突。删除模型后，当该角色不再有可用路由时清理角色引用。剩余配置遵循注册表按协议、ID 和原始端点确定的首条优先规则；被遮蔽的别名不能保留选择。Fast 接受仅快速模型，Vision 接受仅视觉模型，Image 要求可用的生图配置。主模型、Advisor 和 Compaction 均排除四种仅供特定角色使用的标记。Voice 和回退模型引用保留原有的裸 ID 行为。

模型列表为持久化条目提供小型窗口大小编辑器；内置及仅运行时模型不会被标为支持持久化编辑。窗口写入会刷新模型注册表供新会话使用，现有会话必须重启才能采用新的实际生成限制，编辑器会明确说明这一点。

## 范围与归属

新增模型配置路由、现有供应商设置和模型管理仍归属 legacy-primary。设置中的角色选择使用既有作用域语义。配置键遵循各供应商桶实际可写的作用域，包括与无关工作区供应商同时生效的用户桶。路由唯一性判断还包含只读 System 和 SystemDefaults 桶，因此别名不能为只读模型附加可写键或角色选项。

独立存储的可写别名保留精确删除操作，并标注为已保存配置。存在歧义的运行时路由暴露 `canEditContextWindow: false` 并拒绝窗口更新，防止别名静默修改运行时不采用的值。无键删除在所有有效作用域中查找，包括只读条目，并要求唯一的可写目标；对于已脱敏的端点，仅当模型 ID 唯一时保留只按 ID 匹配的回退。

PATCH 和 DELETE 同步实际提交的作用域，包括角色清理和部分持久化：只要有用户写入，就刷新已注册的其他工作区运行时；仅工作区写入则作用于主运行时。语音继续使用已解析的所选运行时，不回退到主运行时。生图配置必须通过现有设置/模型供应商刷新路径到达正在运行的配置。关闭生图时隐藏其缓存工具，并刷新当前对话的工具声明；重新开启时恢复可用性。忙碌会话在下一次空闲重载时应用遗漏的生图和供应商变更。供应商比较使用各会话实际的注册表；每次空闲重载均重新应用生图设置，包括此前失败的情况。代码模式绑定保留与直接工具声明相同的可用性和声明条件。GET 仅投影安全字段；设置变更广播使客户端缓存失效，不发送模型凭据。

供应商安装如果仍被更高优先级的供应商桶遮蔽，则在选择新模型前失败并回滚。CLI 适配器单独快照原始文件内容，与每次写入的临时 `.orig` 备份分开；安装失败时恢复精确原文或最初不存在的状态。仅服务保存的反馈同时检查主运行时的有效认证环境和已持久化设置。

生产代码改动覆盖 Web Shell 组件及翻译、daemon SDK、CLI 路由/持久化接线和供应商安装计划。现有供应商及主模型状态 API 保持各自的模型过滤规则。凭据编辑和任意 JSON 编辑不在范围内。

## 验证

定向测试覆盖模型身份、秘密保留、作用域/信任、数值校验、仅服务安装不选择主模型、角色选择器取值、窗口编辑/重置/报错和现有向导行为。浏览器测试基于已构建的静态 UI，在桌面和窄屏尺寸下验证“设置 → 模型”。真实 daemon API 测试使用隔离设置及仅供测试的凭据。完成前构建、类型检查、打包，并审计完整差异。

## 待定问题

无。语音配置覆盖 daemon 已支持的转录传输方式；本次改动不增加语音合成或新传输方式。
