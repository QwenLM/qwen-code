# 定时任务工作区可见性

[English](scheduled-task-workspace-visibility.md) | [简体中文](scheduled-task-workspace-visibility.zh-CN.md)

## 问题与范围

Issue [#16383](https://github.com/QwenLM/qwen-code/issues/16383) 指出，隐藏工作区字段会让
定时任务看起来像是无工作区任务。目前单工作区或宿主锁定时，表单选择器和任务卡片上的
工作区标签都会隐藏，但任务仍然在其所属工作区执行。

本提案仅限定时任务页面。Issue 仍为 `need-discussion`；本地实现是供审查的提案，并不
代表维护者已批准更改整个 Web Shell 的展示约定。无工作区调度（#8212）、其他页面、任务
路由、存储和 daemon API 均不在范围内。

## 展示行为

- 保留现有多工作区选择器及其编辑、权限规则。
- 选择器隐藏时，在新建／编辑表单中以只读标签展示已确定的工作区，沿用 **工作区** 文案。
- 复用现有的工作区命名规则：显示名称、SSH 标签或路径末段。复用现有工作区标签样式，并通过原生
  `title` 展示完整路径。
- 宿主锁定的表单额外显示 **由宿主固定**。
- 单工作区和宿主锁定时也显示任务卡片的工作区标签。旧版 capabilities 可以使用已有的
  `primaryWorkspaceCwd` 作为后备信息。
- 工作区路径未知时，不虚构工作区，也不显示具有误导性的“无工作区”。保留现有路由和
  加载行为。

## 实现与验证

改动位于 `ScheduledTasksDialog.tsx`、其同目录测试和已有样式、`i18n.tsx` 中的中英文
文案，以及定时任务用户文档。不需要新增组件、公开参数或请求。

两处展示共用文件内的标签渲染函数和工作区名称候选列表。宿主锁定工作区排在首位，
确保宿主提供的名称优先。

验证单工作区新建／编辑、宿主锁定的次工作区、旧版主工作区路径能力，以及多工作区
选择行为保持正确。断言覆盖可见名称、完整路径标题和原有写操作目标。在浏览器中检查
长路径和窄视口。通过构建、类型检查、定向测试、格式检查及独立审查完成本地验证。
