Independent actual Java/MySQL baseline reproduced six successful producer calls after explicitly reassociating saved ordinary history with a naturally created private UUID; natural private CREATE itself does not establish that legacy history. The common producer verifier validates original runtime, binding and writer evidence, but has no independent current private exclusion. Refuse unsupported legacy private production before the common verifier's head/publication mutation, and refuse the legacy writer before its head mutation. Preserve original non-private deferred_v3, ordinary missing-public-Session and native file result/receipt routes. No read/PUT callback, schema, lifetime fence, inventory cut, DRAINED, finalize, physical release or public selector is introduced. Native evidence already closing a route stays necessary; this design does not label every method outside the common verifier a gap.
