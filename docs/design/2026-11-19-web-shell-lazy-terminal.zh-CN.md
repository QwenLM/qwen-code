# 按需加载 Web Shell 终端

[English](2026-11-19-web-shell-lazy-terminal.md) | [简体中文](2026-11-19-web-shell-lazy-terminal.zh-CN.md)

## 问题

工作区终端和托管会话终端都导入了 xterm、FitAddon 和终端样式。静态导入让这些依赖进入启动路径，只打开聊天的用户也会加载它们。

## 设计

在启用工作区终端或挂载托管终端主体时，加载共享的终端运行时。恢复的未激活工作区标签可以在加载运行时之前注册 PTY 释放回调。托管终端对话框立即打开。两个入口都会在运行时下载期间显示加载状态，并在运行时就绪后启动现有连接逻辑。

终端样式随同一个异步 chunk 加载。库构建沿用已有的组件 CSS 作用域处理，并将样式渲染在终端旁，使其在 Shadow DOM 中也能生效。

## 验证

- 用冷缓存打开聊天，确认浏览器没有下载 xterm 运行时和样式。检查独立版和嵌入版产物中的静态导入。
- 打开工作区终端和托管终端，验证运行时加载且终端能够连接。验证加载过程中关闭标签不会随后建立连接，且已有的工作区 PTY 会释放。
- 恢复一个未激活的工作区终端标签，验证运行时只在激活该标签后加载。
