# 原生扩展上下文文件

[English](native-extension-context-files.md) | [简体中文](native-extension-context-files.zh-CN.md)

启用的 Qwen 原生扩展目前默认提供根目录的 `QWEN.md`。已经用 `AGENTS.md` 提供指令的扩展还需要在清单里重复声明这个文件名。

原生扩展将按固定顺序发现根目录的两个文件，先 `QWEN.md`，再 `AGENTS.md`。自动发现的 `AGENTS.md` 必须是扩展内的普通文件，也可以是指向扩展内普通文件的链接。非空的 `contextFileName` 字符串或列表仍按配置顺序决定完整的文件选择。省略或留空时采用默认值。

文件发现和监听共用同一份候选列表。新增、修改或删除任一默认文件均沿用现有的扩展刷新行为。转换后的插件沿用原有的回退规则，托管扩展包继续独立选择资源。

验证原生扩展只有一个文件或同时包含两个文件时提供相应指令，清单指定其他文件时排除两个默认文件，以及启动后新增 `AGENTS.md` 会提示扩展需要刷新。已启用扩展中原先未使用的 `AGENTS.md` 可在下次加载时开始提供上下文。
