# 归档会话行内操作

[English](archived-session-inline-actions.md) | [简体中文](archived-session-inline-actions.zh-CN.md)

## 问题与范围

在设置 → 归档会话中，导出对话记录和恢复隐藏在每行的更多菜单里。Issue #15866 希望这些高频操作能在悬停时被发现。本次只调整已有操作的位置；归档存储、路由、生命周期语义和托管归档界面保持原样。

## 设计

`WebShellSidebar.tsx` 的归档分支将导出对话记录和恢复渲染为更多按钮前的行内按钮。复用 `sessionActionButton` 和 `sessionActions`，包括已有的悬停、键盘焦点和粗指针样式。每个按钮提供翻译后的无障碍名称和提示。更多菜单保留重命名和删除，两者均不可用时不显示更多按钮。

保留现有操作的显示和禁用条件，包括工作区解析、无工作区回调、会话操作策略、忙碌操作和导出进度。操作区域的宽度按实际渲染的行内按钮数加上可选的更多按钮计算，沿用每个按钮 26 像素。

`sessionActions.items` 继续控制操作可用性。`inlineItems` 保持其文档中仅适用于普通会话行的范围；归档行固定将导出和恢复置于行内。将该选项扩展至归档会改变普通行归档操作的安全策略，本需求不需要这种扩展。仅澄清现有 API 注释，不引入配置。

## 影响文件与验证

更新侧边栏组件、就近的归档断言和归档设置浏览器测试。无需新增组件、公开选项、CSS、daemon 路由或依赖。本文及英文版本说明用户可见的操作位置变化。

组件测试验证工作区和无工作区会话的导出/恢复、策略受限行、菜单内容、禁用状态及精确区域宽度。浏览器测试验证悬停显示、键盘焦点、触屏可见性和操作区域无重叠。为 PR 截取设置界面。执行仓库构建、类型检查、打包、定向测试、格式化、lint 和最终 preflight；如有无关失败，明确记录。

## 验收标准与开放问题

- 悬停或键盘聚焦时，在更多旁显示导出对话记录和恢复；触屏无需悬停即可使用。
- 两个行内按钮沿用已有处理函数和限制。
- 更多中保留重命名、删除，不再显示导出和恢复。
- 宽度与实际可用按钮相符，包括缺少导出或恢复能力的情况。
- 普通会话行的配置与行为保持原样。

本范围内没有待决设计问题。
