# Web Shell 语音反馈

[English](web-shell-voice-feedback.md) | [简体中文](web-shell-voice-feedback.zh-CN.md)

## 问题与范围

输入框的语音输入按钮已翻译操作标签，但浏览器和 daemon 的错误仍直接显示英文。
反馈浮层无法关闭，麦克风会一直保持红色，直到再次开始录音。
未检测到语音的提示保存的是已翻译文本，显示期间无法跟随语言切换。

本次覆盖输入框语音输入反馈的英文和简体中文。Live Voice、daemon 协议、
工作区路由、录音限制和提供商行为均不在本次范围内。

## 预期行为

在 Web Shell 展示边界翻译错误。使用小型语音错误格式化函数，将现有浏览器与
daemon 文案映射为翻译键。识别采样率和连接关闭模板，翻译已知的关闭原因，
保留数字诊断信息。未知异常和关闭原因显示本地化通用提示，不直接显示未翻译的
技术文本。传输层保留原始错误与现有回调。

浮层、麦克风悬停提示和无障碍重试标签使用同一份翻译。未检测到语音的提示保存为
状态而非已翻译文本，让所有反馈在渲染时跟随当前语言。

在错误和未检测到语音浮层右上角添加共享 Button，带有本地化无障碍名称和 X 图标。
允许浮层交互，为按钮预留空间，避免遮盖或截断文案。点击或键盘激活关闭按钮时，
清除提示；错误状态通过现有 abort 操作重置，麦克风恢复正常。关闭不会开始录音或
插入文字，后续错误仍应重新显示。实时识别文字属于录音内容，不添加反馈关闭按钮。

## 实现与决策

- `client/voice/voice-error.ts` 映射现有传输层文案；同目录测试覆盖全部明确错误、
  动态模板与未知异常。
- `client/voice/messages.ts` 提供成对的中英文文案，由 `client/i18n.tsx`
  合入共享翻译器。
- `client/voice/VoiceButton.tsx` 渲染翻译并处理关闭；
  `VoiceButton.module.css` 保留现有局部样式，仅添加反馈布局和关闭按钮样式。
- 组件测试和浏览器 E2E 使用现有模拟 daemon，覆盖两种语言、关闭、重试与
  未检测到语音的行为。

展示层映射兼容旧版 daemon，避免为 UI 优化修改跨包协议。
daemon 新增文案在明确映射前使用本地化通用兜底。关闭不会解决底层配置或权限问题，
再次尝试仍可能失败。

语音输入属于交互式输入框功能。其词典沿用现有的 transcript 构建空模块替换机制，
避免只读转录导出携带未使用的语音输入文案。构建产物测试同时检查 transcript 入口
不含这些文案、交互入口保留这些文案，并维持原有 transcript 体积上限。

## 验证与验收

1. 每条明确的语音输入错误都有中英文反馈；浏览器动态异常不会将未翻译字符串
   带入中文界面。
2. 浮层、悬停提示和无障碍重试标签一致，反馈显示期间切换语言也正确更新。
3. 关闭按钮可见、支持键盘，在窄屏可用。关闭错误后浮层与红色状态消失；关闭
   未检测到语音提示后清除通知；仍可重试并显示新的错误。
4. 录音、实时识别文字、最终文本插入与工作区隔离保持现有行为。
5. 定向测试、构建、类型检查和浏览器 E2E 通过。自动化浏览器测试使用模拟麦克风与
   daemon 响应；补充的未配置模型验证可使用实际本地 daemon。两者均不作为真实
   ASR 操作的验证证据。
6. transcript 构建不含语音输入翻译键，并满足原有体积上限；交互构建保留两种语言。
