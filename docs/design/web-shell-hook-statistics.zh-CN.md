# Web Shell 钩子统计

[English](web-shell-hook-statistics.md) | [简体中文](web-shell-hook-statistics.zh-CN.md)

## 问题与范围

PR #17015 已提供本地主 Agent Hook 生命周期记录、规范历史身份和轮次分页查询。
本次第二个 PR 在回复中提供查看这些记录的入口。托管采集、异步最终结果、会话级
统计及子 Agent 聚合仍不在范围内。

## 数据与归属

复用会话持有的 trajectory 生命周期 store 保存实时及回放 Hook 元数据，沿用其
重连、失效及清理边界。通过轮次的持久化记录及导航索引的 `historyPromptId`，或
实时 Hook 元数据的规范身份定位轮次。请求 ID 与历史身份不能混用，尤其在重试时。
不得按到达时间将事件归入最新回复。

Provider 将只读 SDK 查询绑定到已连接的会话及客户端。会话切换使未完成读取失效。
持久化全轮汇总来自服务端；完整实时记录可立即展示执行中状态，未知回放状态不会
覆盖已持久化的最终结果。明细使用冻结快照，每页 50 次执行。实时 Hook 变化刷新可见
摘要，只刷新受影响轮次，文本增量不触发查询。渲染窗口之外的历史仍可通过导航查询。

## 界面

每轮最新助手回复在分支与来源／时间之间显示低调的锚形图标。没有助手回复的轮次
在回复前使用提问行，有终止状态后使用终止状态行。悬浮或键盘聚焦显示执行、阻止、
失败及总耗时的紧凑摘要，点击打开统计弹窗，最近记录只在弹窗中展示。窄屏使用更多菜单。
复用共享 tooltip、dropdown、dialog 组件、portal root 和主题色。Escape 关闭浮层，
焦点返回入口。

弹窗以紧凑网格展示全轮执行次数、阻止数、未成功数（error + timeout）和累计执行耗时。
按时间顺序展示可展开记录，宽屏下摘要保持单行、展开详情使用双列。记录区域最大高度为
70vh，展开详情时可展示更多内容，超出后再滚动。打开时读取新快照，无需手动刷新按钮，
也不重复显示状态汇总和耗时说明。
状态、事件、来源、耗时及安全名称只作为文本展示。
异步派发不等于完成，派发耗时单独标注。未知结果和历史不完整仍明确标记；
缺失的执行耗时不计入总耗时，也不再显示额外警告。未记录或不支持且无记录的轮次
不显示虚构零值或入口。
读取失败时保留可重试入口；关闭弹窗后刷新悬浮摘要。

## 改动与验证

改动限定于 Web Shell 生命周期状态、Provider／查询接线、消息入口位置、界面
组件、翻译及测试。数据契约和 Hook 执行行为仍由 PR #17015 负责。

验证实时／回放去重、重试规范身份、会话切换、过期响应、重连、分页快照一致性、
错误重试、无助手回复轮次、partial／unknown／dispatched 状态及超过 1,000 次
执行。运行定向测试、build、typecheck，并使用真实本地 Hook 记录完成浏览器验收。
检查亮暗主题、320 px、键盘、触屏、Escape、焦点返回及原有回复操作。
基线与最终证据记录于 `.qwen/e2e-tests/web-shell-hook-statistics.md`。
