# Token 消耗信息层级

[English](token-usage-hierarchy.md) | [简体中文](token-usage-hierarchy.zh-CN.md)

## 问题与范围

会话 Token 消耗面板在高卡片中重复指标，难以比较。本次调整呈现及提示交互，保留数值、Token 归一化、daemon 路由、轮询和 SDK 协议。按用户要求，将“缓存输入”“思考（包含在总输出中）”缩短为“缓存”“思考”。

## 设计

会话总量放在圆角两列摘要卡片上方，“总 Token”文案跟随数值同行显示并使用正文颜色达到至少 4.5:1 的文字对比度，右侧保留刷新及更新时间，换行后仍右对齐。摘要使用输入、总输出两列；会话总量固定 28px，摘要主数值固定 24px。输入保留归一化后的完整输入量，不减去缓存，下方显示缓存数量及缓存量/输入量比例；总输出下方显示思考数量。保留零值，小字使用 12px 普通无衬线字体及正文颜色，不显示包含关系提示。

模型按归一化总消耗降序排列。名称固定 15px 加粗，占比固定 14px，比例条沿用用户参考图配色。不显示序号色块、每个模型的总量行、点击展开或整行 hover 背景。面板统一使用一个 Tooltip provider，首次提示延迟 300ms，随后跨行查看即时打开。模型名下方用始终可见的三列网格展示该模型的 API 耗时指标，直接展示数值，因为跨模型对比这些数值是打开面板的主要目的之一。单元格依次排列：平均首 token 延迟、流式计时生成时长为正时的输出速度和平均生成耗时，随后是请求次数和平均延迟。没有流式计时的模型只在第一行显示请求次数和平均延迟。保持原计算方式和可用条件。网格标签使用正文色与卡片底色按 70% 混合，达到至少 4.5:1 的对比度；数值固定 13px 等宽字体并保持单行。标签和数值的 HTML title 属性保留完整本地化文本，使窄面板下被省略的内容仍可查看。自定义焦点环（包括刷新按钮）使用局部正文颜色，在浅色与深色主题下均与相邻卡片达到至少 3:1 的对比度，不修改全局主题 token。

比例条上方显示“输入 xxx（缓存率：xxx） · 总输出 xxx”，行内不显示单独的缓存数量和思考。指标保持单行，溢出时显示省略号。无论是否截断，悬停、聚焦或触屏点击始终显示完整的输入、缓存数量及缓存率、总输出、思考，每项各占一行。指标行使用普通箭头光标。消耗占比位于线条最右侧，悬停、聚焦或触屏点击进度条显示“Token 占比：百分比”。触屏提示在主动关闭前保持显示，提示内容不拦截对相邻指标行的点击。保留真实占比，即使异常来源超过 100% 也不静默截断显示数值。比例条行的顶部 margin、模型列表 gap 和模型标题底部 margin 均为零。拖动侧栏宽度时字号固定；“按模型”“按agent”“工具”标题使用一致的字号、字重及颜色。

“按agent”默认收起，首行固定显示“主Agent”，后面按归一化总消耗降序逐条显示子 agent，不分类或汇总。主 Agent 用量按会话模型总量减去已归属的子 agent 用量计算：先逐个归一化来源输入和总量再扣除，并单独扣除缓存和思考。剩余总量取非负值，输入不超过剩余总量，缓存不超过输入，输出为剩余总量减输入，思考不超过输出。主 Agent 是已归属子 agent 之外的剩余用量，不再次计入顶部总量。sources 为空时显示主 Agent；字段缺失时仍隐藏此区域，因为旧服务不支持区分来源。

所有 agent 使用相同卡片：原名称位于标题左侧，与名称不同的本地化类型位于最右侧，过长时省略，并在 HTML title 属性中保留完整内容。名称与类型相同（忽略大小写）时，在整张卡片中只显示一次；保留实际不同的本地化类型。文字固定 12px，类型文字使用正文颜色达到至少 4.5:1 的对比度，保留浅色圆角边框及与分区标题对齐的左右内边距。占比以顶部会话模型总量为分母。实际子 agent 的唯一执行 ID 保留在卡片 HTML title 属性及 React key 中；主 Agent 使用独立前端标记，不伪造服务端来源 ID。不显示序号、内层折叠或包含关系说明。

## 影响文件与约束

## 验证与验收

运行构建、类型检查、打包、定向测试、lint/格式检查和 Chromium 浏览器测试：1200px 英文浅色、中文浅色、英文深色，以及 390px 英文触屏浅色、中文触屏浅色和深色。不把此矩阵视为 WebKit 覆盖。用原始总量与归一化总量排序相反的模型验证排序，覆盖仅有缓存的输入、旧版总量、零值、主 Agent 剩余量边界（通过完整提示断言缓存和思考的上限，包括零余量）及整卡名称不重复，并验证来源 ID 的 HTML title。覆盖本地化类型大小写去重、仅缓存来源的主 Agent 扣除、输入/缓存/思考的非负下限、完整总览小字，以及两种语言的提示标签与数值配对。验证两种语言下流式耗时数值显示在始终可见的耗时网格中、不可用时不展示，且模型卡片不再有 Info 按钮。验证可见内容约束、390px 下耗时数值不被截断、拖到最小面板宽度后被截断的耗时标签和数值具有完整 HTML title（包括 449.0 tok/s 的测试数据）、小字与焦点对比度、标题样式一致、彩色文字对比度、长名称截断、宽卡片下类型最右对齐、跨行提示延迟分组、占比提示触屏保持及相邻行可点击，提示的悬停/聚焦/触屏操作及实际拖动侧栏变窄、变宽时字号不变，固定时间下 320px 侧栏换行后刷新行仍右对齐，以保证布局检查可重复。手动刷新测试在页面加载前暂停自动轮询，先验证初始响应已显示且只有一次读取，再要求点击产生恰好一个新请求和可见数值更新；确认拦截手动处理逻辑后断言会失败。

通过本地打包版 daemon 读取真实历史会话，不发送新模型请求或模拟统计，对照响应与总览及 agent 数值，目视检查桌面和触屏截图，并保留用户正在验证的服务。截图不验证供应商计费，触屏模拟不替代实体设备或跨浏览器测试。
