# Web Shell Excel 预览

[English](web-shell-excel-preview.md) | [简体中文](web-shell-excel-preview.zh-CN.md)

## 问题与范围

工作区 artifact、@文件引用和传入/上传的 XLSX 文件目前进入仅下载或不支持预览状态。
为三类入口增加统一的只读右侧预览。支持 `.xlsx` 及其标准 MIME 类型；旧版 `.xls`、
宏工作簿和其他 Office 格式保持现有行为。不提供编辑、公式计算、外链、图表或后端转换。

## 设计

复用绑定工作区归属的二进制读取和附件 Blob 路径，保留归属检查、取消、内容更新标识
和下载行为。在二进制/源码回退之前识别表格，包括来源卡片和附件预览。
缺失 artifact 不应触发文件读取。

按需导入的表格组件负责加载、错误、工作表选择、虚拟滚动和下载。通过 Vite 内联 Worker
在打开组件时加载 ExcelJS；其代码不得进入应用或组件库的初始入口块。
内联 Worker 避免为嵌入式宿主引入独立 Worker 资源路径约定。
关闭、输入变化或解析超过 30 秒时终止 Worker。宿主需允许 blob Worker；失败时提供下载回退。
第一方 VS Code webview 明确允许 `worker-src blob:`，不放宽 `script-src`。

Worker 首次只返回工作表名称。选中工作表后再请求该表的预览数据；
页面只保留当前表并忽略过时响应。解析后的工作簿保留在 Worker 内，直到关闭预览
或输入变化；每次请求均有 30 秒超时。ExcelJS 首次仍会解析整个 XLSX：
按需生成工作表预览可避免把所有表传至主线程，但不提供流式解析，也不限制
Worker 内工作簿的内存占用。

工作表切换使用顶部横向标签，外观参考 Excel 工作表标签，并复用共享 Tabs 组件。
标签顶部圆角，未选中时使用浅色背景；选中标签使用蓝色文字和面板背景色，隐藏底边以衔接表格上方的窄留白。
标签溢出时可横向滚动，支持键盘方向键切换；切换后滚动位置归零。
每次最多挂载 50 个标签，通过上一组/下一组按钮切换，保留全部工作表及其原始索引。
方向键可跨组切换，Home/End 到达首个/末个工作表。下载失败独立显示状态，
不会丢弃已成功加载的预览。序号栏默认最小宽度为 56 px，随当前字体的行号数字位数
自动撑开，并使用等宽数字。

ExcelJS 读取工作簿，使用小型 SSF 格式化库处理 Excel 数字格式，避免自写格式解析器。
保留公式缓存结果（包括零和 false）、错误值、转为纯文本的富文本；没有结果的公式
明确标记为未计算。不执行公式或超链接。单元格使用白色底色，保证深色主题下文档颜色可读。
展示基本显式 RGB 颜色、粗体/斜体、对齐和合并；
复杂样式/主题及嵌入对象不在预览保真保证范围内。

预览文件上限 10 MiB，每个选中工作表最多预览 100,000 个网格单元格，包含内容/合并范围内的空位置。
计算范围时忽略外围仅有格式的空白单元格，保留原始坐标和合并占位。
直接遍历 ExcelJS 4.4.0 的稀疏行/单元格存储，并读取已规范化的合并边界，
避免扫描数组空洞或序列化整表模型；升级 ExcelJS 时重新验证这些私有结构。
以这一总量预算替换独立的工作表数量、行数和列数上限：保留全部列，最多保留
floor(100,000 / 列数) 个完整行。空工作表不生成预览行。
仅当前工作表超过预算时显示截断提示。100,000 格兼顾内容量与响应：合成混合数据的
生产构建测试中，切表约 88 ms，页面 CPU 降速 4 倍约 260 ms，而 200,000 格约需
419 ms。这些测量结果不是通用的响应或内存保证。复用已有 TanStack 虚拟滚动库，连续纵向滚动时仅渲染可见行及
少量缓冲行，并测量换行后的实际行高。原生表格占位行维持滚动范围和固定表头；
稳定列宽避免滚动挂载新行时横向布局变化。在渲染窗口边界裁剪合并范围，保留原始
主单元格内容及行列坐标。切换工作表时重新挂载表格，重置滚动位置与行高测量。
移除分页控件。
单元格预算限制预览数据量，行虚拟滚动减少挂载行数；二者都不是 ZIP 解压内存硬限制；Worker 可终止但不是内存沙箱。
在 ExcelJS 展开合并区域前，拒绝所有工作表合计超过 100,000 个合并单元格或
10,000 个合并区域的工作簿。这两个独立的加载预算包含未打开的工作表，防止紧凑的
合并声明分配无界数量的单元格或执行无界的两两相交检查。Worker 内的钩子包装
ExcelJS 4.4.0 私有方法 `_parseMergeCells`，仅检查已登记的预览工作簿，
并发加载时各自保留独立预算。保持 ExcelJS 精确版本锁定，升级时重新验证此钩子。
非法合并地址直接拒绝。拒绝后仍可下载原文件。这些保护不限制一般 ZIP 解压或
非合并数据的工作簿内存。下载保留已有的独立文件大小策略。

## 影响范围

- ArtifactPanel 路由、artifact 类型识别及共享预览组件。
- 客户端翻译、依赖/锁文件、按需 Worker 构建和发布检查。
- 同目录解析/组件测试及浏览器 E2E 覆盖。

## 验证与验收

实现前验证全局 CLI 基线，然后执行针对性单测、根目录构建/类型检查/打包及浏览器 E2E。
使用真实 XLSX 字节和模拟 daemon 做确定性 UI 检查，并在截图说明中标注。
验证 artifact、@文件、待发送上传、持久化附件和传入 Blob 路径；工作表切换、格式/公式/错误、
合并、损坏/超大文件、下载及归属切换。验证挂载行数有界、滚至最后保留行并返回、
文本换行及跨虚拟窗口的合并。验证第 20 个之后的工作表、超过 2,000 行及 50 列的内容，
以及恰好达到预算和超过预算的截断行为（包含空单元格）。与分页和全量渲染基线对比大表性能。目视检查实际截图。
检查应用和组件库构建块，确保 ExcelJS 不进入初始入口且按需 Worker 可正确发布。
检查超大合并区域、面积/数量恰好达到和超过阈值、跨工作表累计、并发加载预算隔离，
以及外围空白格式。验证第一方 webview CSP 允许 blob Worker，而限制更严的第三方
宿主仍提供下载回退。验证上千工作表时标签挂载有界、跨组导航、较宽字体下六位行号、
独立的下载失败，以及远端稀疏格式不会触发空洞扫描。
