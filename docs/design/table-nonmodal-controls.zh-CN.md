# 表格的非模态控件

[English](table-nonmodal-controls.md) | [简体中文](table-nonmodal-controls.zh-CN.md)

## 问题

展开复制或表格密度菜单会禁止整个文档的指针交互并锁定滚动。这些继承属性变化会让大表格发生昂贵的样式重算。对照实验确认了模态菜单与生成的 CSS 作用域匹配相互叠加；减少渲染行数只能掩盖部分开销。

## 范围与决策

表格命令和筛选运算符使用现有 Radix 非模态下拉原语。保留共享原语的默认行为和 CSS 隔离。

| 界面                 | 行为                                |
| -------------------- | ----------------------------------- |
| 复制与表格密度       | 显式使用非模态下拉菜单              |
| 自定义列与列筛选     | 保留现有非模态浮层                  |
| 文本与数值筛选运算符 | 使用非模态下拉单选组替代模态 Select |
| 列右键菜单与行详情   | 保留现有局部菜单与行内展开          |
| 提示                 | 保留现有非模态提示                  |
| 单元格值与全屏       | 保留模态对话框、遮罩和焦点约束      |

运算符菜单保留当前值、翻译标签、筛选草稿、浮层归属和层级。键盘导航与焦点恢复必须兼容普通及 Shadow DOM portal。选择运算符时外层筛选保持打开；Escape 先关闭运算符菜单。外部交互可以在关闭工具菜单的同一次点击中操作下一个表格控件。关闭动画期间再次点击同一个触发按钮时，不能让旧菜单的外部交互处理再次关闭新展开的菜单；保留 Escape 的正常焦点恢复。

真正的对话框需要让背景内容不可交互，移除模态会改变其交互约定。本次不优化这些对话框的 CSS，也不调整生成的样式表。

## 验证与验收

- 展开表格工具菜单或运算符菜单，不禁止 body 的指针交互，不从无障碍树中隐藏表格，也不新增滚动锁。
- 全屏内展开这些控件，保留对话框已有的滚动锁，不叠加新的锁。
- 复制文本/Markdown、密度选项、文本/数值运算符、应用筛选、外部点击关闭、方向键、Enter、Escape 与焦点恢复均正常。
- 行内/全屏、普通/Shadow DOM 路径保留 portal 样式，并兼容支持的 React ref 包装器。
- 定向单测与浏览器 E2E 检验行为，不设置依赖机器性能的耗时阈值。单独重复模拟 daemon 性能场景，并与真实服务验证区分。
- 目视检查截图，执行构建、类型检查并审阅完整差异。
