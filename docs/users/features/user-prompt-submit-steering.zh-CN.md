# UserPromptSubmit 追问与取消

[English](hooks.md#userpromptsubmit) | [简体中文](user-prompt-submit-steering.zh-CN.md)

`UserPromptSubmit` 在接收每条新用户消息时运行一次，也覆盖运行中发出的追问。钩子可以检查、拦截或补充消息。工具结果、Stop 钩子触发的续跑、模型请求重试和自动任务会跳过这一事件。追问被明确拦截时，同一续跑中的工具结果仍可继续处理。

在使用 ACP 的 Web Shell 和桌面端会话中，追问在钩子放行并由 daemon 提交后才进入对话。在此之前按 Esc 或停止，追问连同有效附件退回发送端的草稿。钩子执行异常时，草稿会附带错误提示。钩子明确拒绝时，会显示拒绝原因。再次按发送会把恢复的草稿作为新输入提交，并重新运行钩子。已正式提交的追问即使紧接着遇到取消，也会保留在对话中。当前轮次自然结束时，排队中的追问可以按相同的过检和提交规则开启下一轮。
