# Session overview

Open **More → Session Overview** in Web Shell to review sessions and select
them with their row checkboxes.

To archive a selected session while editing its title, click **Archive** in
the footer. The unfinished rename is canceled and the archive confirmation
opens. Confirm to archive, or choose **Cancel** to leave the session active.
Entering or canceling a rename keeps the footer controls in place, so clicks
near a button's edge still reach that button.
