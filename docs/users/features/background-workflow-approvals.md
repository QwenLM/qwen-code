# Background workflow approvals

[简体中文](background-workflow-approvals.zh-CN.md)

In the interactive terminal, a background workflow waiting for approval opens
the Background tasks list. Opening the list does not approve the operation;
navigate into the workflow's details to answer the request.

After you move the selection with Up or Down and close an automatically opened
list, routine task updates do not reopen it for approval requests that were
already pending when you closed it. A new approval still opens the list,
including a queued request that becomes visible after the preceding request
leaves the queue.
