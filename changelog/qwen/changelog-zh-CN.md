## CLI 1.0.0-preview.1

- 修复 Qwen 订阅账号登录后无法使用订阅模型的问题。模型目录现在随登录状态自动加载，无需手动配置 provider。
- 同步 Qwen Code 0.27.x 的订阅模型目录与思考预算映射，并优化登录与错误提示文案。
- Qoder 模型支持并行工具调用，多工具任务不再强制串行执行，响应更快。

## CLI 1.0.0-preview

- 发布 Qwen Code 1.0 预览版，融合 Qoder 与 Qwen Code 的 Agent 能力，支持代码理解、功能开发、问题排查和测试执行。
- 支持 Qwen、Qoder 账号及多种模型服务接入，也可配置自定义兼容服务。
- 提供 macOS、Linux 和 Windows 原生安装包，无需单独安装 Node.js。
- 支持会话恢复与非交互运行，方便持续开发和脚本集成。

预览期间，部分接口、配置和行为可能继续调整。
